# Training and Inference Scripts

Run these entry points from the repository root.

```bash
python scripts/train.py --help
python scripts/inference.py --help
python scripts/inference_routed.py --help
python scripts/inference_routed_batch.py --help
```

Legacy 256px and GAN experiments are kept here for reference:

- `train256.py`, `inference256.py`
- `train480.py`
- `train_gan.py`, `inference_gan.py`
