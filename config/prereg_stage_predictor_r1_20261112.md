## 合格の条件(C)

勝ち負けの読み方は E の `refutation` のまま(作品フォルダーで分けた hold-out = 便A で読む)。87行は小さいので、**差は対になった行の食い違い(片方だけ当たった行)の片側の符号検定で読む**(p < 0.05)。

- **C1(本命が棒に勝つ)**: A5 が、87行の的中で **A1・A2・A3 のどれよりも上**で、A2 との食い違いの符号検定で p < 0.05。かつ、名前が何か言う47行で **A1 の 0.7447 を下回らない**
  - 通る → 登録の `beats_both`: 予測列を腕の同定に使ってよい。的中と取りこぼしを必ず添える。他 track に出すなら census を通す
  - A1 にだけ勝ち、A2 に勝てない → 勝ったのは「なし」の埋め方で、統計量ではない。**予測列は出さない**
  - 清書だけで勝つ → 登録の `beats_only_for_seisho`
  - どれにも勝てない → 登録の `beats_neither`: 予測列は使わず、聞き取りを増やす側に戻る
- **C2(統計量が名前に何かを足すか)**: A5 が A4 より上で、食い違いの符号検定で p < 0.05
  - 通らない → **統計量は何も足していない**(条例2)。C1 が通っても、それは名前の手柄として書く
- **C3(あたり)**: 名前の当て方はあたりを1つも当てない(母数0)。A5 が便A のあたり13行のうち1行でも当てれば、的中率と取りこぼしを印字する。**当てなくても失敗とはしない**(学習のあたりは 265層で4、便B でも少ない)。結果は判定保留とあわせて書く
- **この道が間違っていると読む結果**: 便B が全部入っても C1 も C2 も通らないとき、登録の `refutation` のとおり **この道(統計量と名前から段を当てる)を閉じ、聞き取りに戻る**
