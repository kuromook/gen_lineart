## 主の値と層
- **主の値**: 評価の行の的中率(当たり ÷ 行数)
- 並べて印字: 段ごとの的中と取りこぼし / 名前の当て方が何か言う行と「なし」の行 / 作品フォルダーごと / 世代(年代札)ごと(プールした値と並べ、平均はしない)
- **層(読む前に決めた)**: **名前に手がかりの無い層** = 層名が `^(レイヤー|Layer|layer)\s*\d+$`、または数字で始まる(日付・番号の名前)。A4 がそこでどれだけ当てるかを別に印字する(housei の線画の名前の形。R1b では外れの多くがここ)

## 点検(IC)と負の対照(NC)
- **IC1**: 凍らせる時に、R1b の 81行で A4 を同じ器具で学習し直すと **75/81** になること(器具が R1b と同じであることの確認)。ならなければ凍らせない
- **IC2**: 評価の時に、凍らせたモデルの sha256 が下の記録と一致すること
- **NC1(ラベルの層)**: 学習の段を作品フォルダーの中で並べ替えて同じ形で凍らせたモデル。期待 **A2 を超えない**
- **NC2(分け方の層)**: キャンバスの大きさ・層の数・年代札だけのモデルを凍らせる。期待 **A0 程度**。大きく超えたら、評価の作品が学習の作品の写しである疑い → 読みを止めて census に問う

## 合格の条件
- **C1**: A4 の的中が A2 より上で、**片方だけ当たった行の片側符号検定 p < 0.05**。かつ A4 が名前の当て方の何か言う行で A1 を下回らない
- **C2**: A4 の **あたり+下絵 の取りこぼし ≤ 0.30** かつ 的中 ≥ 0.70(R1b の 81行では 0.1154 / 1.0000。A2 は 0.5000 / 1.0000)
- 読み方:
  - **C1 と C2 が通る** → 名前と祖先から3つの段を当てる列として、**的中と取りこぼしを添えて** census に出す候補にする(出すかはユーザー)。名前に手がかりの無い層での値も必ず添える
  - **C1 は通り C2 が落ちる** → 清書 と 段ではない には使えるが、あたり+下絵 の同定には使わない
  - **C1 が落ちる** → R1b の A4 の強さは見た後の行の偶然か、写しの漏れだった。名前の文字から学ぶ道は閉じる
  - **名前に手がかりの無い層で A4 が A0 程度** → 予想どおり。そこには名前以外の手がかり(画素)が要る —— R の本題(housei)の材料として記録する

## この走行で決められないこと

- 名前に手がかりの無い層の段(画素の列が要る。発注はユーザーの承認の後)
