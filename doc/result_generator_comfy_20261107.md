## 3. 判定(登録どおり)

**運用: 「ComfyUI のプールは Forge のプールの代わりに使える(この2モデル・この設定で)」** —— 12軸すべて両モデルで G0。
**ただし既存のプールとは混ぜない**(1つのプールは1つの生成器)。仕分けの箱は動かさない(G1 が無いので添え書きも無い)。

## 4. 印字だけ(判定には使わない)

- **N2 の帯の外に出た Δ が5つ在る**(E: `ink_ratio` / `faint_near_ink_ratio` / `background_ratio`、I: `ink_ratio` / `deep_black_ratio`)。
  どれも \|Δ\| ≤ 0.038 で G0 の内。**`ink_ratio` は両モデルで同じ向き(約 −0.023)** —— 生成器の違いが墨の量に小さく、
  向きを揃えて出ている可能性。**この走行は理由を分けない**(初期ノイズ・プロンプトの解釈・VAE の精度)
- G0 の上限 0.05 は「seed の揺れの目安」として登録した定数で、この走行の \|Δ_seed\| は最大 0.0253
