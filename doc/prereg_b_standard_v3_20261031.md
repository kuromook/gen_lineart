## R6 の実装(**セリフと描き文字を構造で分ける**)

> **`v_layer_kind == 'text'` の層は縁を出さない。**
> **フォルダーの範囲からも、`text` の子孫を除いて作り直す。**
> **除いて空になったフォルダーは縁を出さない**(理由別に印字)。

**この規則が作者の裁定と一致する理由**(**走る前に書く**): **セリフ・ルビはテキストオブジェクト
(`v_layer_kind == 'text'`、`layer_type == 0`)である。描き文字は手で描いたラスタなので、
この規則では<ins>落ちない</ins>** = **裁定どおり「使う」**。**名前は使わない**(条例4)。

**走る前に測った分布**(**T-M29**):

- **6頁の可視・非用紙で `v_layer_kind == 'text'` は 1枚** ——
  `page0019` の **L33 `難しい言葉にはルビを振っておくずら`**(`/text` の中、`layer_type` 0、
  `drawn_ratio` 0.004551)。**これが追補158 §F で `page0019` の 97面すべてを割っていた層である**
- **`text` / `セリフ` / `文字` を名前に含むフォルダーの子孫で、kind が `text` でない可視の葉は 0枚**
  = **この6頁に描き文字の候補は無い。R6 は1枚だけを落として、他に何も落とさない**
- **他の5頁で kind `text` は 0枚** = **R6 は `page0019` 以外では何もしない**

**穴**(条例6): **納品の層種別の表に無い行が在るので、「`text` は1枚」は<ins>表に載っている範囲での</ins>
1枚である。** **走行で再掲する。**

**一般化しない**: **描き文字を構造で同定する列は無い。** 別の頁では、描き文字がどの kind で
入っているか分からない。**R6 は「セリフを落とす」規則で、「描き文字を拾う」規則ではない。**

## Primary value

**頁ごとに読む。プールしない。** **札あり/なしの両方で印字する**(§R7c)。

**副値(全部、頁ごとに印字)**: 閉じた面の数(**全段**)/ 被覆 / 最大の開いた領域 /
**線率の最小・中央・最大**(全段)/ **線率 < 0.5 の面の数と割合** /
**R6 で縁を落とした層の数と、空になったフォルダーの数** / **R8b の4つの量**(92枚ぶん) /
3D の札の付いた頁 / 表に無い行の再掲 / **(a) の島と被覆** / 規律9 の落とした数(理由別)。
