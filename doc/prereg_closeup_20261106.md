## Primary value

軸ごと・モデルごと(k = E, I)に、**A1 と Ekc を 600〜1000 の3ビンで揃えた `AUC_m`**(200回の中央値)。
帰無値 **N1** の中央値 `g0` と帯: **A1 の顔のある窓(大きさを見ない、作品ごとの数を揃え方と同じに保つ)対 既存の Ek の顔のある窓**、
元の絵/元コマ単位、同じ枚数、1,000回。**`s = |g0 − 0.5| − |AUC_m − 0.5|`**(正 = 縮む)。
**N0**: 作品を保たない(NC1 用)。

## Instrument checks

- **IC1**: 既存のプールで絞らない `AUC₁₃`・`AUC₂₃` が第3のプールの表を ±0.0001 で再現
- **IC2**: 新しいプールのタイルが全数、顔の CSV と profile で突き合う。**墨の門で落ちた窓・顔の検出されない元の絵を数で印字**
- **IC3**: 揃えた組でビンごとの数が両側で等しい(全 200回)
- **IC4**: 揃えた数が組ごとに **≥ 150**(下回ったら帯が広すぎて読めない → C5)
- **PC**: 顔の高さの AUC が、N1 の組で ≥ 0.85、揃えた組で 0.40〜0.60(A1×E・A1×I とも)
- **NC1**: N0 の中央 − 顔のある窓全体の値が全軸・両モデルで `|·| < 0.02`

## 副 W: 語そのものの効き(判定に使う関門)

**同じ顔の大きさで、アップの語と既存の語は同じ線を出すか**: Ekc と Ek を、両方の顔のある窓の **250〜600 の5ビン**(前の走行のビン)で揃え、
`AUC(Ekc, Ek)` を軸ごとに出す(200回の中央値)。揃えた数を印字。**どちらか一方でも 1ビンでも数が 0 なら、そのビンを外して印字する。**

## Pass criteria(軸ごと、A1、両モデル)

前の走行(`prereg_face_scale_20261105.md`)と同じ:
- **C2 縮む**: 両モデルで帯の外、`s ≥ +0.10`、0.5 をまたがない
- **C3 開く**: 両モデルで帯の外、`s ≤ −0.10`、0.5 をまたがない
- **C4 向きが反転**: 両モデルで帯の外、`AUC_m` が `g0` と 0.5 の反対側に 0.10 以上 → 判定保留(印字)
- **C1 残る**: 両モデルで帯の中、かつ両モデルで `|g0 − 0.5| ≥ 0.15`
- それ以外 → 判定保留 / 離散2軸 → 判定保留(条例4、相異なる値の数と最大の同値塊)/ `ink_ratio` → 読まない
- **C5**: IC1〜IC4・PC・NC1 のどれかが通らない → 何も読まない

| 結果 | `purpose_sorting` への効き方 |
|---|---|
| **C2** かつ **W が両モデルで 0.40〜0.60** | 「**他(構図のスケール)**」を根拠つきで書く。いま判定保留なら他へ移す。いま他(工程と時期)なら説明を2つ並べ、どちらかは分けていないと書く |
| **C2** かつ W が外 | 「**他(構図のスケール、またはアップの語)**」—— 2つを分けられないと書く。判定保留の軸は他へ移す |
| **C1** | 「**作者の典型の顔の大きさで比べても差は残る**」と書く。**箱は動かさない**(作者由来へは移さない) |
| C3 / C4 / 判定保留 | 何も書き足さない |

**前の走行(250〜600)と判定が違う軸は、両方を名前つきで書く**(どちらも撤回しない)。

**この方向がまちがっている、と読む結果**: PC が通らない、または IC4 で数が足りない —— アップの語で作者の典型の大きさを描かせられていない。

## What this run cannot settle

- **アップの語は顔の大きさだけでなく、画面の中身も変える**(背景が減る、髪と目が増える)。W はその一部を 250〜600 で見るだけ
- 検出器は**画面からはみ出す顔を見逃す**(0-3)ので、Ekc の最も寄った絵は「顔なし」に落ちる
- 作者側の 600〜1000 は**作者の寄りの絵**で、作者の中でも絵柄が偏りうる(作品の比は N1 で保つ)
- モデルの一般性(条例8)/ 線と塗りの混ざり(条例9)
