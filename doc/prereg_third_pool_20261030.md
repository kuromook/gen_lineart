## Primary value

**軸ごとに、3つの AUC**(**タイル1枚**を単位、**tie は 0.5**):

| 記号 | 対 | 向きの定義 |
|---|---|---|
| `AUC₁₃` | **A1 対 A3** | A1 = 1 / A3 = 0(第1版と同じ向き) |
| **`AUC₂₃`** | **A2 対 A3** | A2 = 1 / A3 = 0 |
| **`AUC₁₂`** | **A1 対 A2** | A1 = 1 / A2 = 0(**作者の中の工程差**) |

- **畳まないもの**: A1 の作品(5)、**A2 の札×作品(6行)**、プール、チェックポイント、正規化の有無
- **畳むもの**: タイル(軸×対ごとに AUC 1つ)
- **帯は元の頁/コマ単位の bootstrap で引く。** タイル単位で引くと精度を過大に書く
  (A2 は 694タイル / 102頁 = 約 2.6倍)。**タイル数と頁数を両方印字する**
- **向きは `AUC` と `|AUC − 0.5|` の両方を印字する。** 第1版は判定式が向きを扱えずに
  **判定できなかった**(帰無値 0.1595)。**今回は向きを先に定義する。**

## Pass criteria(**走る前に固定**)

**`null` = その対・その行の `null_shuffle` の中央値(0.5)。帯は `null_shuffle` の 95%。**

| | 条件 | 書く文 |
|---|---|---|
| **C1 工程で説明できる** | `|AUC₁₃ − 0.5| ≥ 0.15` **かつ** `|AUC₂₃ − 0.5| ≤ 0.05` | **「第1版でこの軸が分けていたのは工程の差。作者自身のデジタル線画は外部側と分かれない」** |
| **C2 作者由来の候補** | `|AUC₂₃ − 0.5| ≥ 0.15` **かつ** 向きが `AUC₁₃` と同じ **かつ** `|AUC₁₂ − 0.5| ≤ 0.10` | **「工程を変えても残る。作者由来の候補」**(断定ではない。候補) |
| **C3 作者の中で動く** | `|AUC₁₂ − 0.5| ≥ 0.15` | **「この軸は作者の中の工程/時期を読んでいる。作者固有性の尺度として使えない」** |
| **C4 判定保留** | 上のどれにも入らない / 帯が ±0.15 を超える行 | **「判定保留」と書き、帯の広さを数で添える** |

- **C2 と C3 が同時に立ったら、C3 を優先して書く**(先に決めた)
- **`line_width_p50` / `width_consistency` は C1・C2 のどちらに落ちても判定保留**(門の片側性。上記)
- **判定保留は正直な結論である。「棒に届かなかった」と「判定できなかった」は別。両方書く**

- **アナログ/デジタルの別**。**画素はその語を含まない。工程の札は作者の裁定**
- **外部モデルの一般性**。2モデルはどちらも SDXL 系(条例8)
- **`line_width_p50` の離散性**(12値・単一値に 50.5%。条例4)
- **「どちらの線画が良いか」。この track は絵を判定しない**

## 画素と重みの扱い(常設の制約)

**原稿由来の画素は `data/` 配下、絶対にコミットしない。** 外部側の生成物は `data/external_*` /
`results/external_*`(条例6)。**追跡する画像・重みは許可表に在るものだけ。**
