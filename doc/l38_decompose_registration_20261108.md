## §5 負の対照(NC。**誤りの名前と、いま書く期待値**)

- **NC1** 印の画素数が単位の面積と一致しない切り出しを出す → **0 枚**。器具の中で止める
- **NC2** 輪郭が1画素も無い切り出しを出す → **0 枚**。器具の中で止める

- **NC5** 問いの文に作者の仮説(塗りつぶしが流れ込んだ)を書く → **書かない**。

## §6 機械の腕(腕W)—— **作者の仮説を機械で書く。区分けを集める前に固定する**

面のマスクに距離変換をかけ、**半径 >= r の画素を核**とする。

- **`核の数`** = 核の連結成分(面積 >= 床)の数。**2つ以上なら「線の幅の橋で2つのベタが繋がっている」**
- **`細い残り`** = 核に入らない画素の割合。**高ければ「線の幅のものが付いている」**
- **腕W は `核の数 >= 2` または `細い残り >= t` のとき「分解が要る」と言う**

**r と t は作者の答えで決めない。**

- **r = 線の層から引く**(塗りの面ではなく**線の層**の半幅の中央)。**役割ごとに引き直す**(規律9)。
  引いた値と、引いた母集団(頁数・線の層の数)を**印字する**
- **t = 0.5**(**半分以上が線の幅なら、それはベタではない**)。**この値はいま決めた。後から動かさない**
- **床 = `PIECE_FLOOR`(6,000)。借りた定数であると書いてある**(`l38_units_20261107.py`)

**腕W の採点は別の走行**(チェックの答えが揃ってから)。**ここで固定するのは定義と、r の引き方と、t。**

## §7 棒(C。**どの結末が何を意味するか**)

- **C1 一様標本の「要る」率 >= 25%** → **B2 は広い。面プールの標準を分解後の版に差し替える**
  (= 単位の第3版。前後の数を両方印字する。規律10)
- **C2 枠線を飲んだ11面の率 − 一様標本の率 >= 30 ポイント** → **作者の仮説の枠線側を支持**。
  **帯の覆いが腕2として使える**。下回ったら**枠線は B2 の主な出所ではない**(仮説の片側が落ちる)

- **5〜25% は判定保留。** **その幅を 10 ポイント以下に詰めるのに要る面の数を印字する**
- **C4 答えられなかった率 >= 35%** → 他の棒を読まない。25〜35% は問いの欠陥として記録
- **C5 IC1 が外れた** → **何も読まない**

**C1 と C2 は同時に立ちうる。両方書く。**

## 追補1(2026-11-08、**答えを見た後**。棒は動かしていない)

**C5 が立った。IC1 が外れた**(面積 1,392,416。期待「このままで1つ」、作者は「分解が要る」)。
**登録どおり、この走行の主値・層の率・腕の表は読まない。印字もしない。**
IC2(2,503,898)は一致、**P1(1,317,982)も一致**(作者が「右手・左腕・脇の線がまざってる」と
書いた片は「分解が要る」だった)。

**外れた原因は私の設計の誤りである。** IC は**この工程の外から答が分かっているセル**でなければ
ならない。**IC1 の期待値は私の幾何の見立てから作った** —— 帯の覆い 0、首なし、細い割合 < 0.03、
純黒 > 0.99、半径の中央 > 40。**それは腕W が使う軸そのもの**で、工程の外ではない。
**つまり IC1 は点検ではなく、腕W の予測だった。** 外れたことが意味するのは
「器具が壊れている」ではなく「**作者の分解の要否は、私が選んだ幾何には映っていない**」。

**それでも棒は読まない。** 結果を見た後に「あれは点検ではなかった」と言い換えて通すのは、
**点を見て棒を動かすのと同じ**である(条例1)。**この走行は不読で閉じる。**

**次の登録に効く規則(ここに書いておく)**:
**IC の期待値は、作者の過去の答え・配達・作者の裁定からだけ作る。
自分の軸から作った期待値は IC ではなく腕の予測である(P として書く)。**
