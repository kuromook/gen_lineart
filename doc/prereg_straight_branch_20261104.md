## 0. 走る前に見た事実(人工画像だけ。実データには一度も当てていない)

器具を人工画像で作り、**先に**幅を振った(開発用の台本は scratchpad。器具の本体は下の §器具で固定する):

| 線 | 幅 1 / 2 / 3 / 5 / 7 / 9 | 差 |
|---|---|---:|
| 直線3本 | 1.000 / 1.000 / 1.000 / 1.000 / 1.000 / 1.000 | 0 |
| 斜め2本 | 1.000(全幅) | 0 |
| 十字+円 | 0.541 / 0.540 / 0.539 / 0.541 / 0.540 / 0.541 | 0.002 |
| 波線(振幅80) | 0.000(全幅) | 0 |
| 円弧(半径300) | 0.000(全幅) | 0 |
| 直線を ±0.5 / ±1 / ±2 px 揺らす | 1.000(全幅) | 0 |
| 直線を ±3 px 揺らす | 0.000(全幅) | 0 |

**幅の依存は消えている。** 揺れについては ±2px と ±3px の間に**閾が在る**(RMS 1.0px の規則による)。
これは器具の性質として書いておく —— **わずかに揺れた直線は、揺れの大きさで 1 か 0 に分かれる。**

## Question

**幅に依らない直線らしさで測ると、`AUC₂₃`(作者のデジタル線画 対 外部)のモデル差は、帰無の帯の中に入るか。**
「入らない」と答えられる。

## 器具(固定)

`straight_branch_share(tile)`:
1. `ink = gray < 128`(元の軸と同じ)→ `skimage.morphology.skeletonize`。骨格が 20 画素未満なら 0.0(数を印字)
2. 骨格の画素のうち、8近傍に骨格が **3つ以上**ある画素(分岐点)を外す → 残りを 8連結で**枝**に分ける
3. 画素が 5 未満の枝は捨てる。各枝で主成分を取り、**主軸方向の長さ(ptp)≥ 38px**(= 480 × 0.08、元の軸と同じ最短)
   の枝だけを数える。それより短い枝は分子にも分母にも入れない
4. 長い枝のうち、**主軸からの RMS 距離 ≤ 1.0px** を「直線」とする
5. 値 = 直線の枝の画素数 ÷ 長い枝の画素数。**長い枝が1本も無いタイルは 0.0 とし、数を印字する**

## Arms

第3のプールと同じタイル(生成し直さない)。A2 694 / A1 1,489 / **E6 `animagine` seed2 1,482** / **I6 `illustrious` seed2 1,441**。
E6 と I6 はプロンプトの番号で対になる。

## Primary value

**`G_new = AUC₂₃(E6) − AUC₂₃(I6)`**。比べる相手は元の軸の **`G_orig = +0.1505`**(第3のプール)。
副: `AUC₁₃`、各腕の `AUC₂₃`、`AUC₁₂`(A1 対 A2)。**副は判定に使わない。**

## 帰無値(棒の前に印字)

**N1**: プロンプトごとに E6 と I6 のタイルを確率 1/2 で入れ替えて `G_new` を計算し直す。1,000回、帯 2.5〜97.5%。

## Instrument checks

- **IC1**: §0 の人工画像を本体で測り直す。**直線・斜め・揺れ ±2 以下は全幅で ≥ 0.95 / 波線・円弧は全幅で ≤ 0.05 /
  どの線も幅1〜9の差 ≤ 0.10。** 通らなければ何も読まない
- **IC2**: 元の軸の `AUC₂₃` が E6 0.7532 / I6 0.6027 を ±0.0001 で再現
- **IC3**: 自己 AUC 0.5
- **IC4 離散**(条例4 と同じ扱い): 各プールで**最大の同値塊の割合**と、値 0 のタイル・値 1 のタイルの割合を印字。
  **どれかのプールで最大の同値塊が 50% 以上なら、主値は印字するが判定保留**(AUC が値ではなく tie を読む)

## Negative controls

- **NC1**: 外部2プールを合わせたタイル単位で、`line_width_p50` との Spearman ρ を元の軸と新しい軸で並べる。
  **予想: 新しい軸の |ρ| の方が小さい。** 棒ではない。違えば「幅を消せた」とは書かない
- **NC2**: N1 の中央値 `|·| < 0.02`

## Pass criteria

- **C1 モデル差は線幅だった**: `|G_new| ≤ 0.0753`(= `|G_orig|` の半分)**かつ** N1 の帯の中
- **C2 幅を消してもモデル差が残る**: `|G_new| > 0.0753` **かつ** N1 の帯の外
- それ以外 → 判定保留 / IC4 が発火 → 判定保留 / **C5**: IC1・IC2・IC3・NC2 のどれかが通らない → 何も読まない

| 結果 | `purpose_sorting` への効き方 |
|---|---|
| **C1** | `long_line_ratio` の欄に「**モデル差は線幅で説明できる**(幅に依らない軸で消えた)」と書き、箱を**他(線幅)**へ |
| **C2** | `long_line_ratio` は判定保留のまま。**新しい軸に「モデルで直線の中身が違う」と根拠が付く** |
| 判定保留 | どちらも動かない |

**新しい軸そのものの仕分け(作者由来かどうか)はこの走行ではしない** —— 第3のプールの対照一式(NC1 札で2分・NC4 作品間・
NC3 第2モデル)を当てていないから。`AUC₂₃` と `AUC₁₂` は印字だけ。

**副(添え書き)**: `|AUC₂₃(E6) − 0.5| ≤ 0.05` なら「作者側と外部側の `long_line_ratio` の差そのものも線幅だった」と添える。

**この方向がまちがっている、と読む結果**: IC4 が発火する(タイルの大半が 0 か 1)—— そのときは、480px のタイルには
38px 以上の枝が少なすぎて、直線らしさをこの単位で測れない。
