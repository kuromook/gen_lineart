## 0. 走る前に見た事実(人工画像だけ。実データの点数は見ていない)

`long_line_ratio`(`tools/pair_extraction/tile_region_manifest_480.py`)は、墨に HoughLinesP
(閾値 80・最短 38px・隙間 6)を当て、**見つかった線分を幅 3px で描いた帯が覆う墨の割合**である。
480×480 に描いた人工の線で:

| 線の幅 | 1 | 2 | 3 | 5 | 7 | 9 |
|---|---:|---:|---:|---:|---:|---:|
| 直線3本 | 1.000 | 1.000 | 1.000 | 1.000 | 1.000 | 1.000 |
| 波線(振幅 80・周期 約157px) | **0.124** | 0.771 | 0.883 | 0.910 | 0.924 | **0.942** |

**同じ曲線が、太いだけで「直線」と数えられる**(太い帯の中に長い弦が収まる)。
第3のプールの平均では `illustrious` の方が `animagine` より墨が多く線が太く
(`ink_ratio` 0.1203 対 0.0698 / `line_width_p50` 2.5723 対 2.0291)、`long_line_ratio` も高い
(0.7023 対 0.6217。作者側は 0.75 前後)。**向きは「線幅を読んでいる」と合う。** これが問いの出所である。

## Question

**墨を骨格(幅 1px)にしてから同じ規則で測った `long_line_ratio_skel` では、
`AUC₂₃`(作者のデジタル線画 対 外部)のモデル差が、帰無の帯の中まで縮むか。** 「縮まない」と答えられる。

## 器具(新しい軸を1本だけ作る)

`long_line_ratio_skel`: `ink = gray < THRESHOLD`(元の軸と同じ)→ `skimage.morphology.skeletonize` →
骨格の画素が 20 未満なら 0.0(元の軸と同じ規則。**該当タイル数をプールごとに印字**)→
**HoughLinesP の引数は元のまま** → 幅 3px の帯が覆う**骨格の画素**の割合。
**元の `long_line_ratio` は変えない。** 新しい軸は別の列として足す。

## Arms

第3のプールと同じタイル(**生成し直さない**)。A2 694 / A1 1,489 / **E6 = `animagine` seed2 1,482** /
**I6 = `illustrious` seed2 1,441**。どちらも CFG 6.0・同じプロンプト束・同じ seed 基点なので、**プロンプトの番号で対になる。**

## Primary value

**`G = AUC₂₃(E6) − AUC₂₃(I6)`**(モデル差)を、元の軸 `G_orig` と骨格の軸 `G_skel` で並べる。
**`G_orig` は既知 = 0.7532 − 0.6027 = +0.1505**(第3のプール)。副: `AUC₁₃` で同じもの / 各腕の `AUC₂₃` そのもの。

## 帰無値(棒の前に印字)

**N1 モデルの入れ替え**: プロンプトごとに E6 と I6 のタイルを確率 1/2 で入れ替えて `G_skel` を計算し直す。
1,000回、帯は 2.5〜97.5%。片側にしか無いプロンプトは入れ替えずに元の側に置き、数を印字する。

## Instrument checks

- **IC1 人工画像**: 上の §0 の線を骨格の軸で測る。**直線は全幅で ≥ 0.95**、**波線は幅 1〜9 での最大と最小の差 ≤ 0.10、
  かつ最大 ≤ 0.30。** 通らなければ器具が幅を消せていないので、何も読まない
- **IC2 再現**: 元の軸の `AUC₂₃` が E6 0.7532 / I6 0.6027 を ±0.0001 で再現(第3のプールの表)
- **IC3**: 自己 AUC 0.5

## Negative controls

- **NC1 前提**: タイル単位で、元の軸と `line_width_p50` の Spearman ρ、骨格の軸と同じ ρ を外部2プールを合わせて印字する。
  **予想: 元の軸の |ρ| が骨格の軸より大きい。** 予想どおりでなくても読む(棒ではない)が、そのときは「幅で読む」理由が弱いと書く
- **NC2 入れ替えの中心**: N1 の中央値が `|·| < 0.02`

## Pass criteria

- **C1 線幅で説明できる**: `|G_skel| ≤ 0.5 × |G_orig|`(= 0.0753)**かつ** `G_skel` が N1 の帯の中
- **C2 線幅を消しても残る**: `|G_skel| > 0.0753` **かつ** N1 の帯の外
- **それ以外(半分以下だが帯の外 / 半分より大きいが帯の中)**: 判定保留
- **C5**: IC1・IC2・NC2 のどれかが通らない → 何も読まない

| 結果 | `purpose_sorting` の `long_line_ratio` の箱 |
|---|---|
| **C1** | **「他(線幅) —— この軸は線幅を読んでいた」**。モデル差の説明が「どちらのモデルか」から線幅へ移る |
| **C2** | 「他(どちらのモデルか)」のまま、**「線幅では説明できない、直線の中身の差」と根拠が付く** |
| 判定保留 | 「他(どちらのモデルか)」のまま |

**副(判定ではなく添え書き)**: 骨格の軸で `|AUC₂₃(E6) − 0.5| ≤ 0.05` なら、**作者側と外部側の差そのものも
線幅だった**と添える(作者側の線は太い: `line_width_p50` 中央値 3.82 対 1.91)。

**この方向の仕事がまちがっている、と読む結果**: IC1 が通らない(骨格でも幅が消えない)—— そのときは
「直線らしさ」をこの器具で線幅から切り離せないので、`long_line_ratio` を仕分けから外して判定保留にする。
