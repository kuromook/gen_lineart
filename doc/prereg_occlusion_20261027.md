## Question

**層の重なり順は、どの層のどれだけが隠れるかについて情報を持っているか。**

「持たない」と答えられる —— 頁内で重なり順を置換しても被覆の分布が変わらなければ、
重なり順は情報を持たず、K・L・M が母集団を遮蔽で割る根拠は無い。

## Arms

| 腕 | 入力 | 何のためか |

「手前に層が在るか」とほぼ同じ量になる。**A1 が高く出ることは何の支持でもない。**

## Primary value

**層ごとの被覆率** = (手前の遮蔽範囲に入る描画画素) ÷ (その層の描画画素)。0〜1 の1つの数。
単位は層。

**別々に読む層(畳まない)**:

- 形式(`.clip` / `.lip`) —— `.lip` の読み手は未確認。入れるかは作者待ち(問い3)
- 年(`year_label` そのまま。畳まない。**世代もプールである**)
- `v_layer_kind`
- 前方位置の十分位 —— **閾と向きを母集団の欄に印字する**(T138 の3番目)
- **五分法のクラス** —— 分母が確定するのは class 3・4 だけ。class 1(`body_init=255`・保存 0)は
  0 と読めるが頁全面の可能性、class 5(255・一部保存)は**下限**。
  **この2クラスの被覆率は帯で出す。点で出さない**

**畳むもの**: 同一(形式・年・kind・十分位・class)の中だけ。これを跨いだ平均は出さない。

## Pass criteria

**C1 重なり順は情報を持つか**(主たる問い)。
棒: **線画層の被覆率の中央値が、置換帰無値 A0 の中央値より 0.05 以上大きい。**
向きも先に予測する —— 手前に在るフキダシや white が線画を隠すので、**実測のほうが大きいはず**。

- 超えた → 遮蔽は量として在る。K・L・M は母集団を遮蔽で割れる
- 届かない → **重なり順は被覆について情報を持たない。** T137 の前提(手前の遮蔽物を知らないと
  下の層の途切れの理由が分からない)は、少なくとも**順序からは**支持されない。
  この場合、遮蔽を変数に入れる作業を全部やめる
- 向きが逆 → 定義か実装のどちらかが誤っている。**読まずに戻る**

**C2 画素走行は構造の表に何を足すか。**
棒: **A3(前方位置と kind の頻度表)が層ごとの被覆率を ±0.1 以内に当てる割合が 80% 以上。**
**ただし被覆率 ≥ 0.1 の層に限って読む** —— 0 近傍が多数なら「0 と予測する表」が自動的に当たり、
棒が落ちない棒になる。

- 超えた → **母集団を割る目的には構造の表で足りる。** K・L・M は 18時間を待たずに今日割れる。
  画素の実測は層ごとの真値としては残るが、他の track の待ちは解ける
- 届かない → 画素の実測にしか無い情報が在る。走行は必要だった

**C3 透過するものの別途調査は、先か後か**(作者の留保を測る)。
棒: `O_strict` と `O_wide` の被覆率の差が、**線画層の中央値で 0.05 以上**。

- 超えた → 透過モードの調査が**先**。乗算以外の 4,540層の扱いが結果を動かす
- 届かない → 後回しでよい。どちらの数を引用しても結論は変わらない

**0.05 と 80% の理由**: 既知セルが母集団の 3.0% を占め、class 1・5 の帯がその上に乗る。
この二つより小さく動く差では、母集団を遮蔽で割っても**定義の揺れの中**にいる。
M の既知セルは8頁、L の優先は65頁で、5%未満の層を動かす分割はそこでは何も変えない。

## 改訂1 (2026-10-27、登録と同日。**スコアはまだ1つも存在しない**)

**理由**: Track L の指摘 —— **C2 の 80% に帰無値が付いていない**。被覆率 ≥ 0.1 に限っても、
十分位も `v_layer_kind` も使わない定数予測器が ±0.1 に入る割合は 0 ではなく、被覆率が
0.1〜0.3 に集まっていれば中央値だけで 60〜70% 当たりうる。**棒の前に帰無値を出す**(規律9)。
**書き換えではなく、この節を足す。** C2 の棒 80% は動かさない。

### N0 —— C2 の帰無値(主)

**定数予測器**: 層の素性を一切使わず、全層に**測定された被覆率の全体中央値**を返す。
採点は A3 と同一の母集団(**被覆率 ≥ 0.1 の層**)、同一の許容(±0.1)。

### N0' —— 併記する強い側の帰無値(主ではない)

**頁ごとの中央値を返す予測器。** 主たる帰無値にしない理由を先に書く ——
これは**その頁の測定された被覆率を使う**ので、構造の表だけから作れる予測器ではない。
C2 が問うているのは「**走行なしで手元の表から割れるか**」なので、帰無値は
手元の表しか使わない側に置く。N0' は「どこまでが頁の性質か」を読むために併記する。

**どちらを主にするかは今決めた。** 見てから選べる余地を残すと棒が動く(L の指摘のとおり)。

### N0 が高く出た場合の読み(これが帰無値の仕事)

**定数予測器が 80% に届いたら、C2 は「構造の表で足りる」ではなく C1 側の答になる** ——
被覆率がほぼ一定ということは、**遮蔽で母集団を割っても層が動かない**。
この場合 A3 の 80% は構造の表の功績ではないので、**C2 は読まずに C1 の結論に合流する**。

### L の指摘のうち1点を訂正する

**「走行は要らない、手元の表で数えられる値である」は違う。** 定数予測器も A3 も、
採点には**測定された被覆率**が要る(予測を当てるには真値が必要)。だから N0 の数は
走行の後でしか出ない。**走行前に固定できるのは定義で、数ではない** —— 固定したのはそれで、
それがこの改訂の全部である。

## 改訂2 (2026-10-27、同日。**被覆率のスコアはまだ1つも存在しない**)

**理由**: 乗算を遮蔽物から外すと**失う材料が母集団ごとに違う**ことが分かった。
値2の層の `layer_type` 2 の割合は **色原稿 872頁で 49.4%、それ以外で 87.0%**、
クリップ率は **45.2% 対 7.2%** —— **同じ年の中でも割れる**(2019 で 96.2% 対 20.3%)。
畳むと 12.7%〜99.5% を1つの数にする。**棒は一切動かさない。印字する行を足すだけ。**

### 足す層(strata)

**`色原稿か否か`** を層に加える(色原稿 = M の台帳 `m_colour_page_layers_872.csv` の 872頁、
構造の表と 872/872 で結べることを確認済み)。**年 × この群**で別々に読む。

既に登録してある層(形式・年・`v_layer_kind`・前方位置の十分位・五分法のクラス)は変えない。
**畳むのは同一(形式・年・群・kind・十分位・class)の中だけ。**

### これは棒の変更ではない

**規律9「曝露や母集団を広げるのも棒を動かすこと」に当たらないか**を先に書く ——
**母集団は広げていない**(`.clip` 7,667頁のまま)。**判定の閾も変えていない**
(C1 0.05 / C2 80% / C3 0.05)。**増えるのは行の数だけ**で、各行は同じ棒で読む。
層を増やすと「どこかの行が棒を越える」確率は上がるので、**C1〜C3 の判定は
登録時のまま、層を畳んだ全体の値で下す。** 群ごとの行は**内訳として印字し、
判定には使わない。**

## 改訂3 (2026-10-27、同日。**被覆率のスコアはまだ1つも存在しない**)

**理由**: 作者が問い3 に答えた —— **`.lip` は母集団に入れる**。
そして track `census` が、こちらの書き方が材料と合っていないことを指摘した。

### 母集団

**9,653頁 / 437,561層**(`.clip` 7,667頁・312,898層 + `.lip` 1,986頁・124,663層)。

### **これは走行の拡大ではない**

**`.lip` に画素は1頁も無い。** 便 n4 の `rendered` は全行が空で、抽出側の言明は
**「描けなかったのではなく、描いていない」**。だから:

- **母集団 = 9,653頁**(構造の表の全部)
- **画素走行の対象 = `.clip` 7,663頁**(層のある頁。読めなかった4頁には層が無い)
- **`.lip` 1,986頁は母集団に在るが、被覆は測れない**

「`.clip` のみの走行として固定」「`.lip` を入れるなら改訂」と書いたままだと、
**入れた後も走行範囲は変わらないのに、改訂が走行の拡大と読まれる**(census の指摘)。

### **IC1 の数を引き直した —— これは訂正である**

画素走行が当たるのは `.clip` だけなので、**既知セルの点検に使う数も `.clip` の数**:

| 母集団 | 重なり順を持つ非フォルダー層 | `O_strict` | `O_wide` |
|---|---:|---:|---:|
| **`.clip`(画素走行の対象)** | **230,383** | **7,906** | **7,892** |
| `.lip`(母集団に在るが画素なし) | 98,295 | 2,011 | 2,011 |
| 両形式(構造の表の数) | 328,678 | 9,917 | 9,903 |

**IC1 は `.clip` の 7,906 / 7,892 で読む。** 9,917 / 9,903 を `.clip` の走行に当てると
**必ず合わない**。抽出側へ送った便の数は訂正を出す。

### **2つの腕が別の母集団を持つ**(census の3点目)

**A3(前方位置 × `v_layer_kind` の頻度表)は構造の表だけで回るので両形式に届くが、
A4(画素の実測)は `.clip` だけ。** 採点には測定された被覆率が要るので:

- **C2 の比較は `.clip` に揃える。** A3 を `.clip` の層に絞って採点する
- A3 の `.lip` の行は**内訳として印字し、C2 の判定には使わない**
- **`.lip` は 2012〜2015 に偏る**(census)。だから**形式の差を世代の差と読み分けられない** ——
  形式を層として読むのは、**年と交差させた行でだけ**

### 既に登録した棒は動かさない

C1 0.05 / C2 80% / C3 0.05、N0 の定義、帰無値の単位と回数、すべてそのまま。

### 書かれていなかったことを1つ記録する

構造の表から再現した前方位置の数(`フキダシ` 0.143 / `線画` 0.508 / `rendering*` 0.722 /
前方十分位の種類の内訳)は、**すべて両形式を混ぜた数**だった —— 437,561 = 312,898 + 124,663 で、
「全数」と書いた時点で既に両形式の和である。**どちらの形式の数か、どこにも書いていなかった。**
**作者の決定が変えたのは材料ではなく、書いてあることだった**(T139 の形)。
