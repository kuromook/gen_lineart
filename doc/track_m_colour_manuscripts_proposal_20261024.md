## 1. なぜ新しい木か(作者の判断、2026-10-23)

**この推論は作者のもので、この台帳からは出せなかった**:
**カラー原稿は全ての面に色を置くので、面の分割が「疎」ではなく「完全」になる。**
ベタは髪・トップス・タイツを覆い、それ以外を覆わない。カラーは余白以外の全部を覆う。

ゆえに棚にある中で**最も豊かな面の正解源**であり、**同時に別の問題**である。
**色の面は塗りの面ではなく、学ぼうとしている判断が同じではない。**
この二重性が「別の木」という判断の理由そのものである(作者の判断、2026-10-23)。

**Track L の宿題を引き取るものではない。** L の standing homework は
「モノクロで面の外部標準をどう作るか」で、**この木の出力をその標準に使えるかは
別に登録して問う質問**である。色の面と塗りの面を同一視した瞬間に、L が
2026-10-23 に撤回したのと同じ形(標準の中に自分の選別が入る)になる。

## 2. 閉じた扉 —— 再導出しないため、測定ごと列挙する

- **扉1: 作品単位でカラー/モノクロを判定する道は閉じている。** 抽出側が289作品を
  各5ページ測った結果、**混在が47作品**(全モノクロ214 / 全カラー28)。
  決定的な反例は **`fringe2` が 2/5 でモノクロ側に落ちた**こと —— 作者がカラーと
  言っている作品で、同系列の `fringe` は4/5、`fringe3` は5/5 と割れる。逆向きに
  **`2019_ako8`(モノクロ漫画)の1ページが色画素92%**(表紙と思われる)。
  **どちらの規則も誤るので、選別は `inbox/work_color_mode_pages.csv` を使って
  ページ単位で行う**(抽出側の明示的な指示)
- **扉2: しきい値は較正されていない。** 「彩度24以上の画素が2%以上」の根拠は
  「JPEGのにじみが彩度10程度まで」だけ。**較正はこの木の最初の仕事の一部**であり、
  借りてきた数として使ってはいけない
- **扉3: `fringe3` を試行作品にする道は 2026-10-23 に撤回済み**(作者の知識:
  fringe 系はカラーのために描かれている)。かつ、それを正当化していた control の
  議論は交絡していた —— `fringe` は `ako6` に対して part naming と colour の
  **2軸で同時に違う**ので、どちらの結果も読めなかった。**control は試す1軸だけで
  違うこと**(2026-10-23 の教訓)
- **扉4: 「トーン層が0枚」をカラーの署名にする道は、仮説であって測定ではない。**
  標本では4作品がトーン0(`2022b_hyoui_color` / `2019_fringe` / `fringe2` /
  `fringe3`)、モノクロの koma corpus は15.8〜42.5%。**しかし289作品のうち212作品が
  標本でトーン0**で、理由はトーンがページあたり疎だから(群1は1,724ページ中212で
  検出)。koma corpus 内に限ると6/57作品がトーン0・427パネルで、**示唆であって
  測定ではない**。**先に回す falsifier は既に書かれている**: 作者に十数作品の
  カラー/モノクロのラベルを付けてもらい、トーン比が分かれるかを見る

## 4. 開いている空間 —— 候補であって計画ではない

- **候補1: 色の平坦領域をそのまま面の分割として取る。** 量子化 → 連結成分。
  **面提案器の外部標準として最有力**で、この木の存在理由に最も近い
- **候補2: カラー原稿に線画層があるか。** あれば「線 + 完全な面分割」が同じページで
  揃う。**未確認で、抽出側への照会1件**(層一覧をカラーページに対して1便)
- **候補3: 「どの面を黒く塗るか」は面の分割とは別の判断。** ベタがこの分割の部分集合
  であるという**仮説**は、カラーとモノクロが同じ作品で揃わないと測れない
  (`fringe` 系は全巻カラー)。先に測るものではない

## 5. 自明な腕と帰無値 —— これを下回る腕は読まない

- 自明な腕: **色の平坦領域の連結成分をそのまま面として出す**(学習なし)
- **帰無値はこの木で新規に取る。** Track J/L の region-F1 の床(`blank` 0.0084)は
  **プールが違うので持ち込まない**(規律: プールを跨いで平均しない)

## 7. 何が否定になるか(先に書く)

- 色の平坦領域が**作者の面と一致しない**なら、「カラーは面の分割が完全」は
  原稿の上では成立していない
- 自明な腕(連結成分)に学習した腕が勝てないなら、この木は**標準の供給元としてだけ**
  存在し、学習側の主張はしない
