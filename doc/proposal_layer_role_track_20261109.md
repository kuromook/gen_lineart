# 起案: 層の役割を、統計量・名前・聞き取りから当てる track(**案。立てるかはユーザーが決める**)

起案 2026-11-09 / 共通基盤。発端は census の依頼 `inbox/note_foundation_propose_layer_role_track_20261109.md`。
**ユーザーの指示**(census 経由、逐語): 「基盤に統計量と名前、聞き取りでもって回帰機械学習でそのレイヤの真の役割を当てるタスクを起案するよう」

## 作者の方針(2026-11-09、逐語)

> 聞き取りだけで全部やるようなのは無理がある　回帰や機械学習等で統計量から予想できるようになるべきではある（レイヤ名は必ずしも正しくないが）　現時点では正解ラベルは十分ではないから聞き取りはしっかりやる

## 名前と置き場(案)

**Track Q**、`../lineart-layer-role`、枝 `layer-role`、`foundation` から。

## 問い

**層の統計量(構造・画素)と名前から、作者が答える層の役割を当てられるか。** 当てられた範囲だけ、聞き取りの代わりに使える。

- **最初に当てるもの: 工程の段**(あたり / 下絵 / 清書 / 段ではない)—— 正解ラベルが一番まとまっていて(12頁・265層)、Track E が使う
- 役割の語彙は作者の答えから取る(選択肢の外の記入「ベタ仕上げ」「3D出力の線画」「文字」も在る)。**Claude が語彙を作らない**(規律6)

## なぜ track が要るか(既存のどこにも入らない)

- **census は実験をしない**(条例10)。予測器は track の仕事。census はラベルと列を出し、的中・取りこぼしを表に載せる側
- **規律13 の正面の仕事**: 「近い列で代用しない。使う前に作者の分類を再現すると示し、的中率と取りこぼしを印字する」—— この track はそれを示す器具を作る。示せたら代用が**許される**
- 同じ「名前は役割を再現しない」が各 track に出ている: E(下絵は名前で 的中 0.588 / 取りこぼし 0.333、あたりは 0)、遮蔽(名前 `線画` の層の 20/68 が作者の答えでは線でない)、P(`線画` で線を引いているのは代用と条例に書いた)、M(sketch set の規則 的中 2/129)

## 条例の芯(案)

1. **棒は2本**。下限 = 名前の当て方(census の的中・取りこぼし)。本当の棒 = 作者の判定。**名前の当て方に勝つと示すまで、予測を列として出さない**
2. **出した列は census に載せ、名前に「推測」と書く**(作者の答えの列と混ぜない)。どの層に使ってよいか(的中率 ≥ 何で、どの役割で)を役割ごとに登録する
3. **学習と評価は作品フォルダーで分ける**(同じ作品が両側に入らない。Track P の `split_unit` と同じ考え)。頁・作品ごとに印字、プールしない
4. **帰無値を棒の前に**: 名前の当て方 / 多数派のクラス / 構造の列だけ / 名前だけ。**名前だけのモデルが勝つなら、統計量は何も足していない**
5. **聞き取りは減らさない**(作者「聞き取りはしっかりやる」)。**どの層を次に聞くか(予測器が迷う層など)は track が選び、聞き取りの表は census が作る**。作者の時間は 2.3秒/件(Track E の絶対判定の実測)で見積もる
6. **原稿の情報の列を自分で作らない** —— 構造・画素の列は census から受ける。画素の数え上げ(53,243層)は抽出側が流している
7. **空の層**(描画画素 0)は役割を持たない。census の印で外し、外した数を印字する。**`.lip` は画素が無い** —— 対象に入れるかを登録で決める

## 最初の仕事(学習の前)

1. census から1層1行の表を受ける(ラベル・名前・構造。画素の数は届き次第)
2. 下限の棒を印字する(名前の当て方の的中・取りこぼしを、評価用の作品で引き直す)
3. 登録(`moat-register`): 腕・帰無値・作品で分けた分割・役割ごとの使用の条件・次に聞く層の選び方・人の判定で棒を引き直す時期(規律10)
4. ラベルが足りない規模の見積もり(265層で何が言えて何が言えないか)と、次の聞き取りの案をユーザーに出す

## 決めてもらうこと(ユーザー)

- 立てるか。立てるなら名前(案 `layer-role`)
- 最初に当てる役割は工程の段でよいか
- `.lip`(画素なし)を対象に入れるか —— 登録の中で track がユーザーに聞いてもよい
