## 追補1(2026-11-08、**標本を引いた直後。作者の答えは1つも無い**)

**§3 の「帯の覆い >= 0.5 の層 15 面」は組めなかった。**

**理由は点数と独立である**(規律9-5): **プール 656 のうち覆い >= 0.5 は 11 面しか無く、
その 11 面は全部 11-08 に画面に出した。** 母集団が尽きている。**前後の数を両方書く**:
**11-08 の層2 = 11 面 / この走行の層2 = 0 面。**

**プールでの覆いの分布(作者の答えを1行も読まずに出せる。これは腕B の上界である)**:

| 帯の覆い >= | 面 | 比 |
|---|---|---|
| 0(かすりもしない面は 394 = 60.1%) | — | — |
| 0 より大きい | 253 | **38.6%** |
| 0.05 | 87 | 13.3% |
| 0.1 | 42 | 6.4% |
| 0.5 | **11** | **1.7%** |
| 0.9 | 7 | 1.1% |

**つまり「覆い >= 0.5」を器具にすると、面プールの 1.7% しか触れない。**
11-08 の台で 8/10 が覆い >= 0.53 だったのは、**その標本を枠線側に寄せて引いたから**であって、
**プールがそうだからではない**(狙い撃ちの層は主値に入れない、と登録に書いてあるのはこのため)。
**これは覆いの上界の話で、精度の話ではない。** 精度は答えが来てから。

**棒の差し替え(答えを見る前に書く。前後を両方残す)**:

- **C2 は読めない** —— 層2 が 0 面。**11-08 の 11 面で読み直すこともしない**(見た標本)
- **C2' を代わりに読む**: **一様 60 面の中で、「覆い > 0 の面の率」 −「覆い 0 の面の率」 >= 30 ポイント**
  → **位置の軸は効く**。**両方の n を印字する**(一様標本の中の数で決まる。狙い撃ちしていない)
- **C4 の腕B は「覆い > 0」で読む**(覆い 38.6%)。**「>= 0.05」(13.3%)も併記する**。
  棒は変えない —— **精度 − 基準率 >= 15 ポイント かつ 感度 >= 0.5**
- **主値(C1 / C3)と IC(C5)と C6 は変えていない。** 一様 60 面は1面も動かしていない
