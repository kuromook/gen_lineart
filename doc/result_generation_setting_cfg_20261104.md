## 3. 読み(登録の表どおり)

1. **モデルで揺れた3軸は、CFG では1本も差が埋まらない。**
   `long_component_ratio` と `orientation_entropy` は**動きもしない** → **「モデルの違いは CFG では再現しない」。**
   `long_line_ratio` は**動くが埋まらない**。**3本とも箱は「他(どちらのモデルか)」のまま。**
2. **`deep_black_ratio` だけが C2。** ただし2つ書く ——
   **(a) 外部タイル全体で `ink_ratio` と ρ +0.909** → **墨の量と一緒に動く**(登録 NC2 の添え書き)。
   **(b) E6 の時点で既に `|AUC₂₃ − 0.5|` = 0.049 で、「近い」の 0.05 の内側だった。** CFG 9.0 は 0.5 の反対側(0.3252)へ
   **大きく渡った**ので登録の C2 は文字どおり通るが、**「埋まった」というより、もともと無かった差が
   設定で両側に振れる**、と読む方が正確である。**箱は変わらない**(工程の軸。登録の表)
3. **工程の軸のうち2本(`faint_near_ink` `faint_mean_dist`)も CFG 4.0 で動く**が、差は埋まらない。
   **`faint_of_drawn_ratio` は `AUC₂₃` では動かない**(A2 との分離が 0.0189 と極端なので、動く余地が無い)。
   副の `AUC₁₃` では 4.0 で −0.1432 動いた(**判定に使わない**と登録した値)
4. **判定保留の `components_per_1k_ink_px` は両水準で動くが埋まらない** → 判定保留のまま
5. **C2 を通った軸は1本**(7本以上の「外部側は設定1つでどちらにも置ける」には遠い)

**要するに**: **CFG は12軸のうち6本を帰無の外まで動かす。しかし、作者のデジタル線画との差を埋めたのは
1本だけで、それも墨の量の軸だった。** **作者由来の箱は、この角度では増えも減りもしない**(登録どおり)。
