## 1. この木の問い

**カラー原稿は全ての面に色を置くので、面の分割が「疎」ではなく「完全」になる。**
ゆえに棚にある中で最も豊かな面の正解源であり、**同時に別の問題**である
(色の面は塗りの面ではなく、学ぼうとしている判断が同じではない)。

**Track L の宿題は引き取らない。** この木の出力を L のモノクロの外部標準に使えるかは
**別に登録して問う質問**である。同一視した瞬間に、L が 2026-10-23 に撤回したのと
同じ形(標準の中に自分の選別が入る)になる。

## 3. いまどこにいるか

**登録は閉じ、腕を1つ採点した。棒は満たされていない。** 詳細は追補7・追補10。

- **標準 S1** = クリップの連鎖のベースの8連結成分1つ = 面1つ。**床 = ページ面積の 1e-5**
  (画素数ではない)、**標準側と A0 側で同じ値**。重なりは**面積の小さい成分が勝つ**
- **非表示の層は入れない**(自身が非表示・祖先のフォルダーが非表示を落とす)。
  **標準の名は `standard_visible`** —— **作者が 2026-10-28 に選んだ**(追補111)
- 登録集合(8ページ)で **152ベース → 503成分 → 483面**(`standard_visible`)
  - **`standard_all`(非表示を見ない。183 → 823 → 801)は撤回していない。**
    **別の定義の名前として残す。** 台帳の古い行の「標準」は `standard_all` と読む(追補105 §C)
  - **A0 の帯・recall/precision は全部 `standard_all` の上の値で、測り直し中**(追補111 §D)
- **A0** = プレビューを一様量子化(8段/ch)→ 等しい量子化色の8連結成分 → 床
- **棒**: A0 が **N1 blank / N2 whole_page / N3 grid のすべて**にページごとの
  符号検定で勝つ(両側 α=0.05)。学習した腕は A0 に勝たない限り読まない
- **結果**: A0 対 N1 p=0.125 / N2 0.688 / N3 0.219 —— **どれも満たさない**。
  precision 0.002〜0.068(**分けすぎている**)、recall 0.19〜0.24
- **これは登録集合の数で、主張ではない。** 検定集合 = 872 − 8 ページ
- **A0′**(縮小率を揃えた腕)は**条件つき登録**(§5)

**この木で効いた一般形**(台帳に戻した便は `note_m_consolidated_20261024.md`):

- **帰無値が高い点を取ったら、まず標準を疑う。帰無値は標準の点検でもある**
- **「一覧に無い」は「存在しない」ではない。** 納品の CSV にはフォルダー行が
  `parent_id`/`order_in_parent` つきで入っていて、manifest は落としている。
  **欠落を器具の規則の根拠にした**(z 順)。**2つの一覧を持っているときは

- **器具の中の `continue` も「飛ばした数」を印字する。**
  `clip_bases` は `base is None` の連鎖24本を黙って飛ばしていた
- **正しい規則は材料が揃っているときにだけ正しい**(z 順は CSP の中では正しく、
  export の中では正しくない)
- **既知セルは「1測定に1つ」ではなく「1経路に1つ」**(拡大の経路に IC-M7)
- **器具の安定性で選んだ定数は、標準の完全性で選び直されることがある。優先は後者**
- **器具の精査は「単位」の上でしか働かない**

## 6. 規律(全文は `../lineart/doc/CURRENT.md § Working Discipline`)

- **数値は構成とセットでしか引用できない。** その出力自身の性質も「構成」に含む
- **新しい測定は既知セルを1つ含める。再現しなければ他を読まない**
- **撤回は「項目」ではなく「パス」。** 同じ作業の中で全ての置き場を直し、
  何に置き換わったかを書く。**今日は自分の読みを1つ撤回した**(追補10 §I6)
- **プールを跨いで平均しない。** 行ごとに印字する
- **事前登録。結果を見た後で棒を動かさない。** 曝露や母集団を広げるのも同じこと
- **絵が何を描いているかは作者が決める**(規律6)。疑わしいときはモンタージュで
  論じず**原寸の切り出し**を出す
- 評価のベースラインは常に前処理器(`LineartDetector`)の素の出力
- 判定保留は正直な結論。**所要時間を理由に手法を却下・縮小しない**
- **機構は測定の一部ではない**(教訓15)。機構を言うなら**予測として登録する**
  (この木の P10〜P20 がそれ)
