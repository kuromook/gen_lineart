## 1. 針路(**2026-11-02 に変わった。忘れると混濁する**)

**テーマ(作者 2026-11-01、逐語)**: **「カラーイラストで使われる面から線のまとまりを見つけること」。**
**面は経路で、目的は線のまとまり。** 材料を落とす基準は**「その面から線のまとまりを決められるか」**(器具の理由を基準にしない)。

**変わったこと**:

| | 前(〜2026-11-02) | **今** |
|---|---|---|
| 正解源 | **(b) 線で区切られた閉じた面**(追補149。第3版 `T4`) | **マスクの面**(下の定義) |
| マスク | 腕(原案「塗りの入っていないマスク層だけで面を見つける」) | **正解源** |
| 問い | マスクの面が線の閉じた面に当たるか | **マスクの面を区切る線のまとまりを見つけられるか** |
| (b) | 正解源 | **比べる相手**(撤回しない。規律10) |

**変えた理由(作者の判断。追補197〜199)**:
- K8(追補197): `page0002` でマスクの12面が線の閉じた面に **0 当たり**。標準の閉じた面は **3つ(画布の 0.001〜0.012%)だけ**
- 原寸の切り出し(追補198)を見た作者: **「1 あっている」**(マスクの面は作者の面)/ **「2 とじてない、すきまがある」**(線は面を閉じない)
- → **線が閉じた面は、隙間のある線では作者の面をほとんど持たない。作者の面を持っているのはマスクの側である**

**マスクの面の定義(作者の裁定。追補199、逐語は §2)**:
- **面 = その層のマスクの見える側 − 重なり順で上に在る層のマスクの見える側**
  (作者: 上にマスクが在って隠れる部分は**雑にマスクを作っていることがほとんど** →「かなり当てはまる」)
- **「ほとんど」なので例外が在る。規則で引いた面は作者の目で点検する**
- **マスク1枚の見えている部分 = 線で区切られた複数の面の集まり**(作者「まさしくそのとおり」)。
  **この「集まり」が線のまとまりへの入口である**

## 条例

**針路**(作者 2026-11-02): **正解源はマスクの面** = 層のマスクの見える側 − 重なり順で上の層のマスク
(「かなり当てはまる」= 例外あり。作者の目で点検)。**問いは「その面を区切る線のまとまりを見つけられるか」。**
**線が閉じた面 (b) は隙間で面を落とすので比べる相手に降格**(撤回しない。規律10)。

**上位法**: 規律 `../lineart/doc/CURRENT.md § Working Discipline` / 運用 `../lineart/CLAUDE.md` / 数値 `moat`。
登録の正本 `doc/track_m_registration_20261024.md`、旧版 `doc/track_m_initial_notice_until_20261102.md`。
**作者の判断は測定で覆せない**(規律6)。疑わしいときは原寸の切り出し。

1. **連言の棒は最悪の値で判定する。最良は参考と明記**(T-M25)
2. **幅だけで読まない。頁ごとの列を隣に置く。分母が動いた比は分子も書く**(T-M24・T-M10)
3. **恒等の門は頁ごとに当てる**(T-M23)
4. **層の同定は構造(`clip`/`parent_id`/`order_in_parent`)で。** 作者が名前で語った裁定(線・ハイライト)を名前で引くときは、そう書く
5. **帰無値が高い点を取ったら、まず標準を疑う**
6. **「一覧に無い」は「存在しない」ではない。差の内訳を先に数える**
7. **器具の中の `continue` も飛ばした数を印字する。既知セルは1経路に1つ**
8. **「保留」を書いたらカーソルも止める**(T-M20)
9. **借りない**: ベタの枠組み / L の床 `dr < 0.002` / J・L の region-F1 の床 `blank` 0.0084
10. **原稿の情報の列は自分で作らない。`census` に頼む**
11. **マスクの PNG は反転(`<= 127` が見える側)。向きは門で測る**(T-M46)
12. **裁定や落とす理由が面について主張するなら、標準にも当てる**(T-M48)

**引用してはいけない数**: `standard_visible` の面の数(4頁で 44.3% が `線画` 下地由来)/ `standard_all` の 801 /
A0 の `standard_all` 上の値 / **(b) 標準の面の数を「作者の面の数」として**(`page0002` は3面。隙間で漏れる)。
