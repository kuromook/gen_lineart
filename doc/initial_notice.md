## 1. なぜ在るのか(これを外すと意味が無い)

**重かったのは数を取ることではなく、数に付く但し書きを毎回引き直すことだった。**
2026-10-26 の1日で、同じ形の誤りが14回起きている —— すべて
**「数は取れたが、その数が何の数かを確かめていなかった」。**

> **だから集計は「数の表」ではなく「数と、その数が答えない問いの表」である。**
> **但し書きの無い集計は、重さを1gも減らさない。**

**`doc/census_spec.md` §3-3 がその表の初版。** 器具はこれを**出力に同梱する**(別の文書に
書くのではなく、CSV の隣に置く)。

## 2. 最初の3手

```
1. doc/census_spec.md を読む → §3 の「持つもの」を、いま手に入る材料で埋められるか確かめる
2. 材料の棚卸し(下の §3)。足りないものを基盤に1通で出す ← 抽出側へは基盤が回す
3. 器具を1本書く。公開(A)と全量(C)を同じ集計から同時に出す
```

**UI は 3 の後。** 先に作ると、集計の形が UI に引きずられる。

## 4. 守るもの(全部 2026-10-26 に代償を払って得たもの)

- **数の隣に母集団(述語)を書く。** ファイル数と異なり数は別の量(9,653 と 7,418)
- **`drawn_ratio = 0` は「空」ではない**(T129)。`image_material`・`mask_fill` では特に
- **`visibility` と `layer_type` はビット列。等値比較しない**(T128)
- **`has_mask` は全層 True で何も運ばない**(T87)
- **`canvas_w/h` は行ごとに mm か px。`v_canvas_px_w/h` を使う**(T126)
- **落としたものを理由別に数えて印字する**(規律9)
- **既知セルには、試験対象の器具が作っていない入力を少なくとも1つ入れる**(T132)
- **供給元から取った数は、ここで誰かが測るまで、測った者の名を帯びる**(T132)
- **見出しの時刻は `date` から機械的に差し込む。推定で書かない**
