## 問い

**下絵と線画の対で、両側の特徴量(線の太さ・曲率・勾配・面の面積など)はどう相関するか。どの性質が下絵から線画へ引き継がれ、どれが引き継がれないか。**
目的は**集計を出して置くこと**(他の実験の参照値)。発見を急がない —— 作者も「すぐわかるかどうかはわからない」と言っている。

## 決めること(**この木が登録に書く。数を見る前に**)

1. **単位**: タイル / 頁 / 線(破片)/ 面。**対は位置が緩いので、線や面の単位で対応を取るなら対応の規則そのものが器具になる**(既存の対応の測定を先に読む)。タイル単位なら対応は要らないが、迷い線と残った線を分けられない
2. **変数**: 既に測れる軸の一覧を作ってから選ぶ(候補の在りか: Track N の `measure_lineart_profile.py` の7軸と12軸、Track K/G の線の方程式・曲率・端点、M/L の面の面積、`stroke_decomposition.py` の A/B/C、censusの列)。**選んだ理由を書く。** 借りた定数は役割ごとに引き直す(規律9)
3. **帰無値を棒の前に**: 少なくとも**対を組み替えたもの**(同じ作品・同じ世代の中で入れ替える。作品をまたぐと作品の差が相関に化ける)。CCA なら次元と標本数で偶然の正準相関が出るので、組み替えの分布を必ず隣に印字する
4. **層**: 世代(年代札)・作品を畳まない(世代もプール)。行ごとに印字する
5. **出すもの**: 相関の表(両側の各軸 × 各軸)と、多変量(CCA など)をするなら正準変量の載荷量。**集計なので棒は「帰無値から離れているか」まで**。解釈は作者に返す
