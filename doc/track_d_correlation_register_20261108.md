## 4. 単位の案

### U1 —— 頁(対ごとに両側の単画像の軸)

- 対応を取らないので器具が少ない。**ただし迷い線と残った線は分けられない**
- **測るタイル(ユーザー 11-08)**: 頁を原寸 480 の格子に切り、**下絵(灰<160)と線画(灰<128)の両方の墨が 1% 以上のタイルだけ**。
  落としたタイルを**理由別に数えて印字**する: 下絵だけ / 線画だけ / 両方空 / 頁の端の切れ端(480 に満たない)。
  この数自体も集計の一部(下絵だけに在るもの = コマ枠・書き込み・文字、線画だけ = 下絵の無いコマ・ベタ。smoke の重ね合わせで確認)
- **タイルの集合は閾値の腕によらず固定**(上の規則で一度決める)。閾値 200 の腕も同じタイルで測る —— 曝露を腕ごとに動かさない
- **縮尺が罠**: 既存の器具は読み込みで 480×480 に縦横比を無視して縮める(MLP:152-158)。頁はそのまま入れない。
  案 (a) 頁の中の原寸 480 タイルの平均 / 案 (b) 頁を共通の縮尺(長辺固定、縦横比保持)に直してから測る。
  線幅は縮尺を読む(Track N で AUC 0.98 がサイズの差だった)ので、**縮尺の決め方は構成の一部として印字する**

### U2 —— 線(破片)単位の対応

- 下絵の骨格を区間に割り、各区間から GT の骨格への中央値距離で ≤3 / 3–8 / >8 px に分ける
  (`pair_alignment_strata.py` の精度側と同じ規則。**対応の規則そのものが器具**)
- 「GT に近い下絵の区間」と「GT に対応の無い下絵の区間」(条例2の言葉)で、区間の特徴量(長さ・直線度・
  濃さ・幅)の分布を比べる。**作者の問いに一番近いのはこちら**
- 対は位置が緩い(ラフの墨の約半分は 8 px 以内に GT が無い、8,467 ペアの構成での値。v4 では測り直す)。
  >8 の区間には位置ずれと描かれていない線が混ざる —— **分けられないことを但し書きにする**

## 5. 変数

**方針(ユーザー 11-08)**: 「相関の高いパラメータを探すのだからできるだけいれたい(あとから追加することもあるだろう)」。
**全体の黒白は入れない**(「どうせ合わない」)。**足すもの**: 線の勾配・曲線・線そのものの数・線同士の平均距離。
後から軸を足すのは許される —— **足すたびに、その軸の行を帰無値つきで別に印字し、足した日付を書く。**
足す前の表の「帯の外のセルの数」は足した後の数と**両方、名前を付けて**印字する(規律10)。

### U1(頁)—— 両側に同じ軸。**原寸 480 タイルで測り、頁ごとにタイルの中央値**

|---|---|---|

### U2(線の区間)—— 下絵の側の区間ごと

区間を GT への中央値距離で ≤3 / 3–8 / >8 px に分け、**3群で次の分布を並べる**: 区間長、直線度、曲率、線幅、
区間の濃さ(灰の中央値)、縁の鋭さ、向き(線の勾配)。**>8 が「GT に対応の無い下絵の線」**(条例2)。

### 定数(規律9)

借りた定数(墨 128、ラフ骨格 200、かすれ 128〜220、`min_seg`)は役割ごとに引き直す。
- **下絵の墨: 灰<160 を主、灰<200 を隣に印字**(ユーザー 11-08、smoke の原寸の切り出しを見て)。
  smoke: 鉛筆は 128 で薄い線が消え 200 で太ってつながる / デジタルはどれでも取れ 200 以上で影の調子を拾う /
  ぼかした灰(2016 suc)はどの閾値でも線にならない。**画材が世代・作品で違うので、下絵側の線幅・かすれの軸は画材を読む** —— 但し書き
- **線画の墨: 灰<128**(MLP の既定。線画は役割が同じ)
- **区間の距離の区分 3 / 8 px と `min_seg`**: 9 月の器具の値。主なプール clippairs は全タイル `src_per_out` 1.000(原寸)だったので、
  **原寸タイルでは同じ役割・同じ縮尺**。そのまま使う。U2 の下絵の骨格の閾値は既存器具の 200 だが、**主を 160 に揃え、200 を隣に印字**
- `FILL_HALF_WIDTH_PX = 4`: 480 タイルで較正。原寸の線画の線幅 p50 は 1.9〜8.2 px(smoke)なので、太い線がベタに数えられうる —— `fill_ratio` の読みの但し書き

## 6. 帰無値と棒(数を見る前に固定)

- **帰無値**: 同じ作品 × 同じ年代札の中で、下絵と線画の組を入れ替える(条例4)。1,000 回。
  セルに対が 1 つしかなければ組み替えられないので、落とした数を印字する
- 相関の表(下絵の各軸 × 線画の各軸、Spearman)の各セルに、**実測 r と組み替えの 2.5 / 97.5 百分位**を並べる
- CCA をするなら、**正準相関の組み替え分布を隣に印字**する(次元と標本数で偶然の値が出る)
- **棒は「組み替えの帯の外か」まで。** 多数のセルを見るので、帯の外のセルの数を、**偶然に期待される数(5%)**と並べる
- U2 の帰無値: GT の骨格を 180° 回した腕(既存の器具と同じ)。3群の分布の差がこの腕でも出るなら、それは対応ではなく区間の性質
- **新しい軸 `edge_sharpness_p50` の対照**: 同じ画像を ぼかし(σ=1)で下がること / 2 値化で上がることを smoke で確かめる
- 解釈(何が引き継がれたか)は作者に返す
