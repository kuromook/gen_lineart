# 登録: 生成設定の掃引 —— **CFG を1つだけ動かすと、軸の仕分けが動くか**(2026-11-03)

**状態**: **閉じる前の版はこのコミットで確定。** 走った後に棒・水準・母集団・帰無値を変えるなら、
**時刻つきの修正として、点数を読む前に**この文書の末尾に足す(規律10)。
**きっかけ**: `doc/purpose_sorting_20261103.md` §1-1 と §4-A。ユーザーの選択「A 生成設定の掃引」(2026-11-03)。
**言わないこと**: どちらの線画が良いか(条例の冒頭)。**この角度は絵を判定しない。**

## Question

**`animagine-xl-3.1` で、プロンプト・seed・他の設定をすべて固定し CFG だけを 6.0 から動かしたとき、
軸ごとの `AUC₂₃`(作者のデジタル線画 対 外部)は、seed を変えたときより大きく、帰無の帯の外まで動くか。**
**「動かない」と答えられる。**

## なぜ CFG か(**解像度を選ばない理由**)

- 解像度はサイズと一緒に動く。**サイズは第2版で既に別の角度として測っており、構図のスケールは揃わない**(条例5)。
  解像度を動かすと「設定」と「サイズ」を分けられない
- CFG は解像度・窓・タイラーに触らない。**同じ seed なら構図がほぼ同じまま、描線の強さだけが変わる**ことが期待できる
- **水準は 4.0 と 9.0**。6.0(登録済みの設定)を挟む2点。**走った後に水準を足したり選び直したりしない**

## Primary value

**軸ごと・水準ごとに `Δ_x = AUC₂₃(E_x) − AUC₂₃(E6)`、x ∈ {4.0, 9.0}。**
`AUC₂₃` は第3のプールと同じ定義(A2 = 1 / 外部 = 0、タイル1枚が単位、tie は 0.5)。

- **畳まないもの**: 水準(4.0 と 9.0 を別に読む)、軸(12本を別に読む)
- **畳むもの**: A2 の札(第3のプールの主値と同じく A2 全体で1つ)。**札ごとの行は印字だけ**
- **副**: `AUC₁₃` で同じ `Δ` を印字する。**判定には使わない**

## 帰無値(**棒の前に印字する**)

- **N2 対の入れ替え**: プロンプトごとに、E_x と E6 のタイルを**プロンプト単位で**確率 1/2 で入れ替え、
  `Δ` を計算し直す。**1,000回**。設定が効かないならこの分布と区別できない。**帯は 2.5〜97.5%**
- **N1 seed**: `Δ_seed = AUC₂₃(S1) − AUC₂₃(E6)`。**同じ設定で seed だけ変えたとき動く量。**
  1点の値として印字する(S1 は第1版のプールなので、**第1版の外部側を「既視の腕」として使う**ことを書いておく。
  使うのは差の大きさだけで、S1 の絶対値は読まない)
- **墨の量**: `ink_ratio` の `Δ_x` を全軸の隣に印字する(帰無値の腕。仕分けの候補として読まない)

## Instrument checks

- **IC1 決定性**: 走る前に、E6 の最初の2本を CFG 6.0・同じ seed で生成し直す。
  **既存の E6 の画像との平均絶対差 ≤ 1.0 階調**。外れたら、それを印字して **N1 を主な帰無値として扱う**(この扱いは今決めた)
- **IC2 再現**: この器具で計算した `AUC₂₃(E6)` が、第3のプールの表(`result_third_pool_20261031.md` §4)と
  **12軸すべて ±0.0001**(例 `faint_of_drawn_ratio` 0.0189 / `long_line_ratio` 0.7532 / `ink_ratio` 0.2433)。
  **通らなければ何も読まない**
- **IC3**: 自分自身との AUC が全軸 0.5000
- **IC4**: E4・E9 のタイル数と、門で落ちた数を理由別に印字する(E6 は 1,482 / 門 30 / 割り当て不足 7)

## Negative controls

- **NC1 入れ替えの中心**: N2 の `Δ` の中央値が全軸で `|·| < 0.02`。外れたら対の作り方(器具の層)が壊れている
- **NC2 墨の量**: **CFG を上げると墨が増える向きを予想する**(`ink_ratio` の `AUC₂₃` は E9 で E6 より下、E4 で上)。
  **これは予想で、棒ではない。** C1 を通った軸について、外部タイルを全部まとめた中で `ink_ratio` との
  Spearman ρ を印字し、**|ρ| ≥ 0.7 なら「墨の量と一緒に動く」と添える**(別の名前は付けない)
- **NC3 白点**: 第3のプールと同じ正規化を両側に当てる(条例2)。**この角度では揃えない版を作らない**

## Pass criteria

軸ごと・水準ごとに:

- **C1 設定で動く**: `|Δ_x| ≥ 0.10` **かつ** `Δ_x` が N2 の帯の外 **かつ** `|Δ_x| > |Δ_seed|`
- **C2 設定で差が埋まる**: C1 を通り、さらに `AUC₂₃(E_x)` が **0.5 の反対側に渡る**か **`|AUC₂₃(E_x) − 0.5| ≤ 0.05`**
  (0.05 は第3のプールの `C1_NEAR`。借りた定数なので、ここで「近い」の役割に引き直したと書く)
- **C4 外部側が1回の引きで安定しない**: **`|Δ_seed| ≥ 0.10` の軸が 3本以上** → この走行では仕分けを動かさない(判定保留)
- **C5 器具**: IC2 か NC1 が通らない → 何も読まない

### 各結果が仕分け(`purpose_sorting_20261103.md` §1)に何をするか

| 軸の今の箱 | C2 を通った | C1 だけ通った | どちらも通らない |
|---|---|---|---|
| **他(どちらのモデルか)** `long_line_ratio` `long_component_ratio` `orientation_entropy` | **他(生成設定)** に根拠つきで移る | 「設定で動くが差は埋まらない」と添える。箱はそのまま | 箱はそのまま。**「モデルの違いは CFG では再現しない」と書く** |
| **他(工程と時期)** faint 3軸・`deep_black_ratio` | 「**工程でも設定でも**説明できる」と書く。**箱は変わらない** | 添えるだけ | そのまま |
| **判定保留** `components_per_1k_ink_px` `background_ratio` | **他(生成設定)** に移る | 添えるだけ | そのまま |
| **判定保留(離散)** `line_width_p50` `width_consistency` | **判定保留のまま**(条例4)。tie の構造を隣に印字 | 同左 | そのまま |
| **帰無値の腕** `ink_ratio` | 印字だけ | 印字だけ | 印字だけ |

- **この方向の仕事がまちがっている、と読む結果**: **C4 が発火する。** そのときは、§1 の仕分けの外部側全体が
  1回の引きの上に立っていて、その引きが安定しない。**§1 の表に「外部側は1回の引き」と印を付ける**(撤回はしない)
- **もう1つの読み**: **12軸の大半(7本以上)が C2 を通る** —— 外部側は設定1つでどちらにも置ける。
  **そのとき「外部と比べて差がある/ない」は、どの軸でも設定の選び方の話になる**と書く
- **作者由来の箱は、この角度では増えも減りもしない。** 外部側の設定を動かすだけなので、作者側の性質は測らない

- **他の設定**(steps・サンプラー・解像度・プロンプト・negative)。**CFG で埋まらなくても、設定一般で埋まらないとは言わない**

- **構図のスケール**(条例5)。消していない
- **作者由来かどうか**。この角度は外部側を動かすだけ
- **絵としてどう見えるか**。人の判定は使わない
