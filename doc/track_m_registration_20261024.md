## 0. 順序の出所 —— 測定ではなく作者の知識

**面の分割は合成画素から復元するものではなく、すでに1枚の層として存在している。**
これは **2026-10-24 の作者の判断**であり、この台帳のどの測定からも導けない。
起案の候補1(合成を量子化して連結成分を取る)が本線から**自明な腕に降り**、
候補2(層の構造を見る)が本線に**上がった**のは、この知識を受けたからである。

**この順序は測定に支持されていない。** 支持する/しないを後で測るときに、
順序の出所が測定だったことにしてはならない(教訓15: 機構は測定の一部ではない)。

構成は「**面を示すベース + その上に乗る濃淡レイヤ**」、**例外がいくらかある**(作者)。
**例外の数は測る対象**である。

## 1. 器具の確認 1: ページ単位の選別(在庫で済む部分)

### 1.1 既知セル —— 再現した

`inbox/work_color_mode_pages.csv`(1,348行)から、抽出側の作品単位の判定を手元で再構成:
**色画素率 >= 0.02 のページ数**で分類すると **全カラー 28 / 混在 47 / 全モノクロ 214**、
`測定ページ` `カラーページ` `判定` の3列すべてが **mismatch 0**(289作品)。
2本の CSV は同じ走査であり、**通達に書かれた規則が実際に走った規則である**。

受領の点検(届いたと書いてあるものではなく、届いたもの): 1,348行×6列に欠けなし、
`(年, 作品)` は両 CSV で完全一致、1作品あたりの測定ページは **5が256作品、
4以下が33作品**(合計1,348)。CSV は **UTF-8 BOM** つき(`utf-8-sig` で開く)。

### 1.2 較正できた棒 —— ただし1つだけ

**色画素率の分布には谷が1つだけあり、それは 0 にある。**

| 帯 | ページ | |
|---|---:|---:|
| ちょうど 0 | **1,173** | 87.0% |
| 0 < x < 0.0001 | 1 | 0.1% |
| 0.0001 〜 0.02 | 27 | 2.0% |
| 0.02 以上 | **147** | 10.9% |

**0.001 から 0.05 のあいだに谷はない**(0.0053, 0.0054, 0.0075, 0.0086, … と連続する)。
ゆえに **2% という棒は谷の上に立っていない**。棒を 0.001 → 0.20 に動かすと
カラー側は 171 → 82 ページに動き、**0.001 と 0.02 のあいだでは 171 → 147(24ページ)**。
**棒の任意性が触るのは最大28ページ(走査の 2.1%)**で、それ以上ではない。

**登録する選別**: この在庫が支持する棒は **色画素率 > 0** だけである(1,173ページが
厳密に 0、次の値は 0.0001 未満)。2% は使わず、**0 を使う**。

### 1.3 較正できなかった棒 —— そして、できても足りない

**画素側の棒(彩度 >= 24)はこの在庫からは較正できない。** ページあたりの彩度
ヒストグラムが無く、在庫にあるのは彩度24で切った**後**の割合だけである。
**較正は新しい測定の依頼になる**(§4 の依頼1)。借りてきた数として使わない。

**そして較正できてもこの木の問いには足りない。** 2つの測定:

- **平均彩度は第2の軸ではない。** 色画素率との spearman は **0.9646**
  (色画素率 > 0 の175ページ)、全1,348ページでは pearson 0.9247。
  在庫の軸は**1本**であって2本ではない
- **色画素率は「どれだけ塗り切られているか」を順位づけない。** 測定した5ページ
  すべてが棒を超えた28作品(=全カラー)の70ページで、色画素率は
  **0.0274 〜 0.9726 に広がる(36倍)**。作者が名指しした `2017 illustration`(79p、
  全カラー)は **0.0645 〜 0.3554**、`2018 illust201710`(10p、全カラー)は
  **0.0274 〜 0.1470**。一方 0.5 を超える40ページのうち **15ページは混在作品**にある(全カラー 25)

**読み**: 色画素率が測っているのは「このページに彩度のある画素がどれだけあるか」で、
**「面がいくつあり、それが覆い切っているか」ではない**。淡い肌・白い服・ハイライトは
面でありながら彩度が低い。**合成の彩度は面の数を知らない。**
これは §0 の作者の知識と同じ方向を指すが、**独立な支持ではない**
(同じ対象=合成画素を測っているから)。

## 3. 事前登録 —— 棒はここで立てる

### 3.1 ベース層の同定条件(名前では決めない)

**名前で決めてはいけない**(2026-10-23 に `has_gradation_fill` を「見た目」と読んで
踏んだ事故、台帳 T72 近辺、教訓「名前は点検ではない」)。条件は**測れる量で書く**:

- **B1 平坦さ**: 層の描画画素が少数の色に量子化され、各色が大きな連結面を占める。
  濃淡レイヤは勾配を持つので平坦さが低い
- **B2 覆い**: ベースは**ページの余白以外の大きな割合**を覆う(全ての面を示す層だから)。
  濃淡レイヤは局所的
- **B3 順序**: 同じフォルダの中で、ベースは濃淡レイヤの**下**にある
- **B4 合成**: 濃淡レイヤは乗算・オーバーレイや不透明度の低下を使いやすく、
  ベースは通常・100% である傾向

**B1〜B4 の数値の切り口は、配られた層の分布を読んでから登録する**(分布を読んで
切る位置を決めることが事前登録である。基盤が帯を持ち、この木が棒を立てる)。
**どの腕も採点する前に登録を閉じる。**

**名前は選別器ではなく falsifier として使う**: B1〜B4 だけでベースを同定し、**その後**に
層名と照合して**不一致率を印字する**。名前で選んでから名前と合うことを確認するのは循環。

**例外を数える**: (a) 条件を満たす層が**1枚も無い**ページ、(b) **2枚以上**あるページ。
作者が例外があると言っている以上、**この2つの数がこの段の主要な出力**である。

### 3.2 自明な腕と帰無値(この木で新規に取る)

**標準** = ベース層そのものの面の分割(§3.1 で同定したもの)をラベル地図にしたもの。
**帰無値は Track J/L から持ち込まない**(`blank` 0.0084 はプールが違う)。

| 腕 | 中身 |
|---|---|
| **A0 自明な腕** | 合成カラーラスタを量子化 → 8連結成分 → 面。学習なし |
| **N1 blank** | 面を1つも出さない |
| **N2 whole_page** | ページ全体を1つの面として出す |
| **N3 grid** | **標準と同じ面数**の規則的な格子。region-F1 の面数感受性を制御する |

**N3 が要る理由**: region-F1 は予測面数に敏感なので、面数を合わせた帰無値が無いと
「面数が合っているだけ」を腕の成果と読んでしまう。

**棒(いま登録する。結果を見てから動かさない)**:

1. **A0 は N1/N2/N3 のすべてに、ページごとの符号検定で勝つこと。**
   両側、α = 0.05。**曝露や母集団を広げるのも棒を動かすことと同じ**
2. **学習した腕は A0 に勝たない限り読まない**(起案 §5)
3. **既知セルを毎回含める**: 標準を予測として入れて region-F1 **1.0** になること
   (IC-M3 の実データ版)。再現しなければ他の行を読まない
4. **プールを跨いで平均しない。** ページごと・作品ごとに行を印字する
5. **判定保留は正直な結論。** 所要時間を理由に縮めない

**A0 の量子化の方法と段数は、カラーラスタを見てから登録する**(まだ1枚も無い)。
**登録前に A0 を採点しない。**

### 3.3 Track L の宿題は引き取らない

L の standing homework(モノクロで面の外部標準をどう作るか)に**この木の出力を
使えるかは、別に登録して問う質問**である。色の面と塗りの面を同一視した瞬間に、
L が 2026-10-23 に撤回したのと同じ形(標準の中に自分の選別が入る)になる。

## 5. 何が否定になるか(先に書く)

- **ベース層が同定できない**(条件を満たす層が無いページが多数)なら、§0 の構成は
  原稿の上では一般的でなく、**例外が本体**ということになる
- **A0 が帰無値に勝てない**なら、合成の量子化は面を取れない。これは §0 と整合するが、
  §0 の支持にはならない(同じ対象を測っているから)
- **色の平坦領域が作者の面と一致しない**なら、「カラーは面の分割が完全」は原稿の上では
  成立していない(起案 §7)
