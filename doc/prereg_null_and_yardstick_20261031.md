# 第1部 —— 帰無値を作り直す

## Question(1)

**各クラスの腕の構成を揃えた置換(層化置換)にすると、帰無値は 0.5 の周りに細く戻るのか。**

**「戻らない」が答えになりうる** —— そのときは **test AUC という主値がこの材料に合っていない**ことになり、
**次の走行は主値そのものを変える設計になる。**

## Arms(1)

| 腕 | 中身 | 何のためか |
|---|---|---|
| **N0 いまの置換**(群単位・層化なし) | **既知**: E2 で中央 0.4417、帯 **[0.0535, 0.9597]** | **前後を並べるための、動かさない基準**(規律10) |
| **N1 層化置換**(**本命**) | **腕ごとに別々に札を振る** —— A1 の群の中で擬似クラス1を抽選し、A3 の群の中でも同じ割合で抽選する。**どの擬似クラスにも A1 と A3 が同じ比で入る** | **分離の向きに系統的に乗れなくする** |
| **N2 置換なし** | 主値そのもの(E2 = 0.9274) | **恒等。帰無値ではない。並べて印字するだけ** |
| **N3 信号の無い既知の対に N1 を当てる** | **A3 の H1 対 H2**(NC2 で **0.4932** = 学習できないことが分かっている) | **帰無値の器具が「信号が無いとき 0.5」を返すか** |
| **N4 信号の在る既知の対に N1 を当てる** | **A1 対 A3**(E1 = 0.9908) | **「信号が在るときは帯の外」になるか**(帯を細くしすぎていないか) |

**N1 の実装(先に書く)**: 群の一覧を腕ごとに分け、**各腕の中で `ceil(n_arm × p)` 個を擬似クラス1に抽選**
(`p` = その評価の本当のクラス1の群の割合)。**乱数は `numpy.default_rng(20261031)`、200回。**
**タイルは群に従う。**

## Primary value(1)

**評価(E1・E2・E3・E4)ごと・F9 の、`N1` の中央値と 95% 帯の幅**(`hi − lo`)。
**畳まないもの**: 評価・特徴集合(F9 を主、F10・F12 は 50回で併記)・外部の2モデル。

## Pass criteria(1)(**走る前に固定**)

| | 条件 | **書く文** |
|---|---|---|
| **A1 帰無値として機能する** | **N1 の中央値が 0.5 ± 0.05** かつ **95% 帯の幅 ≤ 0.30** かつ **N3 が 0.5 ± 0.05** かつ **N4 が帯の外** | **「層化置換はこの材料で帰無値として機能する。次の走行はこれを使って登録する」** |
| **A2 細すぎる** | **N4(信号の在る対)が帯の中に入ってしまう** | **「層化置換は信号まで消している。使わない」** |
| **A3 まだ広い** | **帯の幅 > 0.30** | **「test AUC はこの材料に合わない。次は主値そのものを変える」** |
| **A4 判定保留** | 上のどれにも入らない | **「判定保留」と書き、数を添える** |

**`0.30` の出所を先に書く**: 前の角度の棒は 0.60 と 0.75 で、**0.5 からの距離は 0.10 と 0.25**。
**帯の半幅が 0.15 を超えると、0.75 の棒が帯に入る。** **幅 0.30(半幅 0.15)が、棒が生き残る上限である。**
