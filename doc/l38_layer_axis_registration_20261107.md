## 腕(過剰結合を言い当てる道具として並べる)

| 腕 | 中身 | 役割 |
|---|---|---|
| 腕0 **何も言わない** | 全部「1つのもの」 | 自明な腕。差は 0。的中率 = 1 − 過剰結合率 |
| 腕1 **全部「2つ以上」** | 全部「2つ以上」 | 自明な腕。取りこぼし 0、的中率 = 過剰結合率 |
| 腕2 **層の軸** | 層 >= 2 なら「2つ以上」 | **これを試験する** |
| 腕3 **首の軸** | 細い首が在れば「2つ以上」 | 副。対の中で首は釣り合わせてあるので、**群とは無関係に**読める(n=9 では p=1.000) |
| 腕4 **面積だけの頻度表**(学習なし) | 面積が中位より大きければ「2つ以上」 | **安い記述子**。対は面積を合わせてあるので、**対の中で当たったら対の作りが壊れている** |
| 腕5 **枠線の軸** | 帯の被覆 >= 0.5 なら「2つ以上」 | **この束では読めない**(枠線の面は既知セル1つだけ)。束B へ |

**腕0 の的中率は母集団の性質の言い換えである**(過剰結合が少なければ高く出る)。
だから**主値は的中率ではなく、対の中の差で読む**。
