- **C4 外部の床 —— 再現する。** S5(62対)は中央 0.9912 / 最小 **0.9605**(`2016/suc` 対 illustrious)。

  - 登録の文言: 「**読む側のセル(B の距離0 10対 / C の matched 8対)**の帯が1つでも 0.30 を超える、
    またはそのセルが 8対を下回る」。
