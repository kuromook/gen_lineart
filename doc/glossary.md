# 用語集 —— この企画の中だけで通じる言葉

作成: 2026-10-18 / 置き場: 共通基盤 `/home/sh1/deepl/lineart/doc/glossary.md`

**目的**: 通達や work_log に出てくる短い語を、気軽に引けるようにする。
**方針**: 短い語はそのまま見出しにする(長い言い換えに直さない)。各項は「一行の意味」と、
必要なら「なぜこの語が要るのか」。**言い換えの提案ではなく、引くための表**。

更新の規則: 新しい語を使ったら、使った通達と同じ日にここへ1行足す。消さない(古い語も残す)。

## 1. 測り方の語(いちばん頻度が高い)

| 語 | 一行の意味 | なぜこの語が要るか |
|---|---|---|
| **事前登録** | 結果を見る前に、問い・測る量・合否の線を書いて確定させること | 後から線を動かせば、どんな結果でも支持に見える。この企画で最も多く効いている規律 |
| **棒**(bar) | 合否の線そのもの。「支持の棒 1.5」= 1.5 以上なら支持 | 「良かった/悪かった」ではなく数で決めるため |
| **主値** | その測定の主要な数値。これだけで合否を決める | 数値を10個出して良いものを選ぶ(後出しの選択)を防ぐ |
| **副** | 記述として併記する数値。合否には使わない | 捨てるには惜しいが主値にすると選択の自由度が増える数の置き場 |
| **腕**(arm) | 比べる条件の1つ。「全部黒く塗る腕」「前処理器の腕」 | 「手法」だと学習したモデルだけを指しそうになる。自明な比較対象も腕 |
| **自明な腕** | 考えなくても作れる比較対象。例: 何も塗らない / 全部塗る / 現行規則 | これに負ける手法は存在しないのと同じ。最初に置く |
| **器具確認**(IC) | 測る道具自体が正しいかを、答えがわかっている入力で確かめる項目 | 器具が壊れていれば、どんな結論も意味がない。**1つでも落ちたら何も読まない** |
| **陰性対照**(NC) | 本物の信号を1つだけ壊した腕。落ちなければ、元の数値も何も測っていない | 「名前のついた誤り1つに陰性対照1つ」が規則 |
| **帰無模型** | 「切り方や作り方だけが働いている世界」を人工的に作り、そこでの数値を対照にする | 入れ替え(shuffle)では、人工物と信号を一緒に消してしまう場合がある(2026-10-16) |
| **判定保留** | 支持の棒にも反証の棒にも当たらなかった状態 | 「ほぼ支持」と書かないため。K1 の RR 1.487 対 棒 1.5 がこれ |
| **撤回** | 一度書いた数値や結論を、誤りとわかった時点で取り消すこと | 残しておくと他トラックが引き写す。0.2582 の撤回が前例 |
| **単位** | 何を1件として数えるか(画素 / 線 / 面 / タイル / コマ / 顔) | **同じ材料でも単位を変えると答えが変わる**(lesson 11)。表には必ず単位を書く |
| **前処理器** | `LineartDetector`。ラフから線を取り出す既存の道具 | この企画の全モデルがこれに負けている。**評価のベースラインは常にこれ**(lesson 6) |

## 2. 統計の語(そのまま使っている)

| 語 | 一行の意味 |
|---|---|
| **RR**(相対危険度) | P(ある性質 \| 印あり) ÷ P(ある性質 \| 印なし)。1 なら無関係 |
| **MH-RR** | 層別した RR。例: 線の長さで5分位に分け、各層の RR をまとめる |
| **層別** | 交絡しそうな量(長さなど)でグループに分け、その中だけで比べること |
| **AFe** | 曝露群寄与割合 = P(露出\|印あり) × (RR-1)/RR。**関連を因果として最大限に読んでも説明できる割合の上限** |
| **ρ**(スピアマン) | 順位の相関。-1〜+1。量の大小関係だけを見る |
| **KS** | 2つの分布が同じと言えるかの検定 |
| **95%帯** | 帰無模型や対照を何百回回したときの、数値が収まる範囲。実測がこの外に出て初めて意味がある |
| **p** | 偶然でこの差が出る確率。小さいほど偶然では説明しにくい。**大きさの話はしていない** |
| **lift** | 絞り込みの効率。母集団の率に対して何倍の濃さになったか |

## 3. 線と骨格の語(Track F / J / K)

| 語 | 一行の意味 |
|---|---|
| **1px化 / 細線化** | 太さを持つインクを、幅1画素の中心線に落とす処理(`skeletonize`) |
| **骨格** | 細線化した結果。距離変換の「尾根」を辿った線 |
| **節点** | 骨格の交差点。3本以上が集まる画素のかたまり |
| **span** | 節点と節点の間の、骨格の1本つながりの区間 |
| **腕**(この章では) | 節点から外へ出ている span の先端。節点で腕どうしを対にするのが「接続」 |
| **尾根** | 太い交差点の中央にできる、どちらの線にも属さない短い骨格の断片。Track J の呼び名 |
| **橋** | **尾根と同じ物**の Track F の呼び名(2節点を繋ぐ短い span) |
| **畳む**(collapse) | 橋を節点に吸収して、交差点を1つの節点にまとめること。閾値は `max(3.0, 1.5×局所インク幅)` |
| **ヒゲ**(spur) | 細線化が作る、どこにも繋がらない短い枝。剪定して捨てる |
| **ベタ** | 黒く塗りつぶされた面。線ではない |
| **面** | ベタの連結成分。「ベタは面単位で判断する」(Track J) |
| **局所インク幅** | その場所のインクの太さ。距離変換 × 2。**ベタを除くと約2.7pxで、窓の大きさに不変** |
| **ヒステリシス**(インク) | 閾値を2段にする取り方(128 で種、200 まで育てる)。薄い線が点々に割れるのを防ぐ |
| **JOINT** | ストロークにならなかった骨格の残渣(節点・ヒゲ・橋)を保存したトークン |
| **コマ** | 漫画の1コマ。native 解像度は 4000px 級 |
| **タイル** | 学習用に切り出した 480px の正方形 |

## 4. つながりの誤りは2方向(Track K の中心)

| 語 | 一行の意味 | 作者の印 |
|---|---|---|
| **過接続** | 別々のものが1本の線につながってしまっている | **ある**(「解体する線」`broken`、Dキー) |
| **過分割** | 1本の描線が複数の線に切れたまま | **ない**(全部選んで部位名を付けるだけなので記録されない) |

- 作者を止めるのは**過接続**。下流の語を壊すのは**過分割**
- 律速は過分割(線画で腕の 18.7% しかつながらない)
- **損失1 / 損失2**: 畳まれた橋の行き先。損失1 = 短くて消える、損失2 = 独立した1本の線として残る

## 6. 今わかっていることの要点(数は通達が正)

- **前処理器に全モデルが負けている。** 残差は削除(閉)とベタ塗り(J)
- **ベタには前処理器が原理上触れない**ので、ここだけは構造的に負けない
- **線の方程式は破片単位でしか成立しない。** 描かれた線は放物線1本ではなく放物線の短い鎖
- **交差点で線をつなぐとき曲率は役に立たない。** 効くのは接線の一致と横ずれ
- **線画は面をほとんど囲んでいない**(1コマあたり約1.2領域)。だから「面」= ベタの連結成分
- **つながりの失敗の 81.1% は、対にする段階に届く前に落ちている**(J, IC-j7)
- **作者が見たトークンの 21.2% は畳まれた橋の断片**で、その大半はベタの中心軸(K, K4a)

## 7. 既知の罠(対照が生まれつき無意味になる道)

1. 量だけを見ている指標は、位置を壊しても下がらない(転置しても落ちない対照)
2. 器具が自分自身を測っている(較正と測定が同じ集合)
3. 1つのカテゴリが母集団を支配していると、絶対値の差は構成上到達できない
4. **参照の腕自身が落ちる棒**は弁別できない(2026-10-16, J)
5. **信号と一緒に人工物も消す対照**は分離できない。帰無模型を使う(2026-10-16, K)
6. **キャッシュは、データを作った経路と違うことがある。** 作った側の docstring を読む(2026-10-16, K)
7. 人工的な損傷で作った器具は、素材が示さない損傷を原理上含めない(2026-10-16, K)
