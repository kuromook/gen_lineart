# 用語集 —— この企画の中だけで通じる言葉

作成: 2026-10-18 / 置き場: 共通基盤 `/home/sh1/deepl/lineart/doc/glossary.md`

**目的**: 通達や work_log に出てくる短い語を、気軽に引けるようにする。
**方針**: 短い語はそのまま見出しにする(長い言い換えに直さない)。各項は「一行の意味」と、
必要なら「なぜこの語が要るのか」。**言い換えの提案ではなく、引くための表**。

更新の規則: 新しい語を使ったら、使った通達と同じ日にここへ1行足す。消さない(古い語も残す)。

## 1. 測り方の語(いちばん頻度が高い)

| 語 | 一行の意味 | なぜこの語が要るか |
|---|---|---|
| **事前登録** | 結果を見る前に、問い・測る量・合否の線を書いて確定させること | 後から線を動かせば、どんな結果でも支持に見える。この企画で最も多く効いている規律 |
| **棒**(bar) | 合否の線そのもの。「支持の棒 1.5」= 1.5 以上なら支持 | 「良かった/悪かった」ではなく数で決めるため |
| **主値** | その測定の主要な数値。これだけで合否を決める | 数値を10個出して良いものを選ぶ(後出しの選択)を防ぐ |
| **副** | 記述として併記する数値。合否には使わない | 捨てるには惜しいが主値にすると選択の自由度が増える数の置き場 |
| **腕**(arm) | 比べる条件の1つ。「全部黒く塗る腕」「前処理器の腕」 | 「手法」だと学習したモデルだけを指しそうになる。自明な比較対象も腕 |
| **自明な腕** | 考えなくても作れる比較対象。例: 何も塗らない / 全部塗る / 現行規則 | これに負ける手法は存在しないのと同じ。最初に置く |
| **器具確認**(IC) | 測る道具自体が正しいかを、答えがわかっている入力で確かめる項目 | 器具が壊れていれば、どんな結論も意味がない。**1つでも落ちたら何も読まない** |
| **陰性対照**(NC) | 本物の信号を1つだけ壊した腕。落ちなければ、元の数値も何も測っていない | 「名前のついた誤り1つに陰性対照1つ」が規則 |
| **帰無模型** | 「切り方や作り方だけが働いている世界」を人工的に作り、そこでの数値を対照にする | 入れ替え(shuffle)では、人工物と信号を一緒に消してしまう場合がある(2026-10-16) |
| **判定保留** | 支持の棒にも反証の棒にも当たらなかった状態 | 「ほぼ支持」と書かないため。K1 の RR 1.487 対 棒 1.5 がこれ |
| **撤回** | 一度書いた数値や結論を、誤りとわかった時点で取り消すこと | 残しておくと他トラックが引き写す。0.2582 の撤回が前例 |
| **単位** | 何を1件として数えるか(画素 / 線 / 面 / タイル / コマ / 顔) | **同じ材料でも単位を変えると答えが変わる**(lesson 11)。表には必ず単位を書く |
| **前処理器** | `LineartDetector`。ラフから線を取り出す既存の道具 | この企画の全モデルがこれに負けている。**評価のベースラインは常にこれ**(lesson 6) |

## 2. 統計の語(そのまま使っている)

| 語 | 一行の意味 |
|---|---|
| **RR**(相対危険度) | P(ある性質 \| 印あり) ÷ P(ある性質 \| 印なし)。1 なら無関係 |
| **MH-RR** | 層別した RR。例: 線の長さで5分位に分け、各層の RR をまとめる |
| **層別** | 交絡しそうな量(長さなど)でグループに分け、その中だけで比べること |
| **AFe** | 曝露群寄与割合 = **(RR-1)/RR**。**曝露した側の中での**割合。「全体のどれだけ」ではない |
| **PAF**(集団寄与割合) | **完全な修理が印全体から取り除く割合**。p(RR-1)/(p(RR-1)+1) = p_case(RR-1)/RR。**2式は粗い RR でのみ一致し、その一致が枠組みの検査**。層別した RR では一致せず、採るのは後者(Miettinen 型) |
| **精度** | P(印 \| 曝露)。**そこに手を入れて当たるか**。PAF が「問題のどれだけがここに在るか」で、精度が「手を入れて当たるか」。曝露が普通で転帰が稀なとき大きく乖離する |
| **向き** | どちらを曝露、どちらを転帰に置くか。**P(性質\|印) と P(印\|性質) は別物**で、後者だけが寄与割合の式に入る。向きを取り違えると値が3通りに割れる(2026-10-19 に実例) |
| **帰無値** | 対照が「関連が無いとき」に返す値。**統計量ごとに違う**。層内で置換すると MH-RR は 1 に戻るが素の RR は戻らない。登録では**帰無値と統計量を対で書く** |
| **クラスタ** | CI を計算するときの独立の単位。顔の中の線は互いに従属なので、顔を単位にブートストラップする |
| **取り分け**(保留集合) | 答えを見る前に外しておく材料。`labels/holdout_plan.json`(2026-10-04、seed 20261004)に test_panel(同じ作品の別コマ)と test_series(10作品を丸ごと)の2本 |
| **棄権条件** | 読む前に「この材料で棒に届くか」を計算し、届かなければ**読まない**という規則。帰無のもとではなく**支持と反証の両方向で**届くかを見る |
| **ρ**(スピアマン) | 順位の相関。-1〜+1。量の大小関係だけを見る |
| **KS** | 2つの分布が同じと言えるかの検定 |
| **95%帯** | 帰無模型や対照を何百回回したときの、数値が収まる範囲。実測がこの外に出て初めて意味がある |
| **p** | 偶然でこの差が出る確率。小さいほど偶然では説明しにくい。**大きさの話はしていない** |
| **lift** | 絞り込みの効率。母集団の率に対して何倍の濃さになったか |

## 3. 線と骨格の語(Track F / J / K)

| 語 | 一行の意味 |
|---|---|
| **1px化 / 細線化** | 太さを持つインクを、幅1画素の中心線に落とす処理(`skeletonize`) |
| **骨格** | 細線化した結果。距離変換の「尾根」を辿った線 |
| **節点** | 骨格の交差点。3本以上が集まる画素のかたまり |
| **span** | 節点と節点の間の、骨格の1本つながりの区間 |
| **腕**(この章では) | 節点から外へ出ている span の先端。節点で腕どうしを対にするのが「接続」 |
| **尾根** | 太い交差点の中央にできる、どちらの線にも属さない短い骨格の断片。Track J の呼び名 |
| **橋** | **尾根と同じ物**の Track F の呼び名(2節点を繋ぐ短い span) |
| **畳む**(collapse) | 橋を節点に吸収して、交差点を1つの節点にまとめること。閾値は `max(3.0, 1.5×局所インク幅)` |
| **ヒゲ**(spur) | 細線化が作る、どこにも繋がらない短い枝。剪定して捨てる |
| **ベタ** | 黒く塗りつぶされた面。線ではない |
| **面** | ベタの連結成分。「ベタは面単位で判断する」(Track J) |
| **局所インク幅** | その場所のインクの太さ。距離変換 × 2。**ベタを除くと約2.7pxで、窓の大きさに不変** |
| **ヒステリシス**(インク) | 閾値を2段にする取り方(128 で種、200 まで育てる)。薄い線が点々に割れるのを防ぐ |
| **JOINT** | ストロークにならなかった骨格の残渣(節点・ヒゲ・橋)を保存したトークン |
| **コマ** | 漫画の1コマ。native 解像度は 4000px 級 |
| **タイル** | 学習用に切り出した 480px の正方形 |

## 4. つながりの誤りは2方向(Track K の中心)

| 語 | 一行の意味 | 作者の印 |
|---|---|---|
| **過接続** | 別々のものが1本の線につながってしまっている | **ある**(「解体する線」`broken`、Dキー) |
| **過分割** | 1本の描線が複数の線に切れたまま | **ない**(全部選んで部位名を付けるだけなので記録されない) |

- 作者を止めるのは**過接続**。下流の語を壊すのは**過分割**
- 律速は過分割(線画で腕の 18.7% しかつながらない)
- **損失1 / 損失2**: 畳まれた橋の行き先。損失1 = 短くて消える、損失2 = 独立した1本の線として残る

## 6. 今わかっていることの要点(数は通達が正)

- **前処理器に全モデルが負けている。** 残差は削除(閉)とベタ塗り(J)
- **ベタには前処理器が原理上触れない**ので、ここだけは構造的に負けない
- **線の方程式は破片単位でしか成立しない。** 描かれた線は放物線1本ではなく放物線の短い鎖
- **交差点で線をつなぐとき曲率は役に立たない。** 効くのは接線の一致と横ずれ
- **線画は面をほとんど囲んでいない**(1コマあたり約1.2領域)。だから「面」= ベタの連結成分
- **つながりの失敗の 81.1% は、対にする段階に届く前に落ちている**(J, IC-j7)
- **作者が見たトークンの 21.2% は畳まれた橋の断片**で、その大半はベタの中心軸(K, K4a)
- **作者の「解体する線」の印は、畳まれた橋を通るトークンに集中する**(K)。
  PAF 0.4855 [0.3245, 0.6400]、**10作品を丸ごと外した取り分けで支持**。機構は絵柄に固有ではない
- **しかしその規則では直せない**(K, K17)。曝露の**精度が約4%**で、費用の棒(壊した数 ÷ 直した数 < 1)が
  要求する**50% から13倍離れている**。比は代数的に (1-精度)/精度 で、閾値でも幅の門でも動かない
- **条件のない緩和は作者のラベルで棄却**(K, K10)。答えられる隙間 40 件のうち **22 件が意図的な飛ばし線**で、
  到達距離を伸ばす修理は取りこぼしを拾う率と同じ率で**意図した隙間を壊す**
- **頬のハッチ(`face.other`)は「かすれ」で、飛ばし線とは別物**(K)。作者の目視・箱B率 0.782・
  作者の判定 7/7 が同じ行を指した
- **ペア(ラフと線画)は両方向に緩い**(D, 2026-10-19、8,467ペアの全数)。
  **最終線の 2〜3割には下に何も無く(`gt8` 0.198〜0.315)、ラフの墨の約半分には
  上に何も無い(`prec_gt8` 0.464〜0.660)。** 位置の情報は両方向に実在するが部分的で、
  精度側は再現率側の約半分(`aligned` 0.092〜0.169 対 0.174〜0.301、対ごとに >0 が 91〜97%)。
  **ただし「作家の入力の半分が未使用」と読むのは言い過ぎ** —— `gray<200` が鉛筆のグレインを
  短い断片に骨格化しているので、未照合の一部はグレインであって置き違えた線ではない

## 7. 既知の罠(対照が生まれつき無意味になる道)

1. 量だけを見ている指標は、位置を壊しても下がらない(転置しても落ちない対照)
2. 器具が自分自身を測っている(較正と測定が同じ集合)
3. 1つのカテゴリが母集団を支配していると、絶対値の差は構成上到達できない
4. **参照の腕自身が落ちる棒**は弁別できない(2026-10-16, J)
5. **信号と一緒に人工物も消す対照**は分離できない。帰無模型を使う(2026-10-16, K)
6. **キャッシュは、データを作った経路と違うことがある。** 作った側の docstring を読む(2026-10-16, K)
7. 人工的な損傷で作った器具は、素材が示さない損傷を原理上含めない(2026-10-16, K)
8. **帰無値は研究ではなく統計量に属する。** 正しい帯を間違った統計量に当てると、材料でも帯の幅でもなく
   **対の取り違え**で落ちる(2026-10-18, K7)
9. **片方向にしか動かない修正には、やりすぎを捕まえる標的が要る。**
   これは実際に偽の合格を捕まえた —— 4行が 30/30 で、足した1行が 21/30(2026-10-18, K)
10. **自分の入力の一方を整合条件から逆算した検査は、常に合格する。**
    検査の入力はすべて観測から来なければならない(2026-10-18, 基盤の誤り)
11. **頑健性の腕は、自分の中に修理を持ってはいけない。**
    厳しくするための腕が優しくなっていたら、それは腕ではなく2つ目の主値(2026-10-18, K)
12. **追記式のログは、行の集合ではなくキーごとの最新として読む。**
    行数と一意キー数を並べて印字する(2026-10-18, K)
13. **寄与割合の棒は、修理を**議論する**資格を与えるだけ。作れるかは精度が決める**(2026-10-19, K)
14. **PAF は曝露を広げれば上がる。** 棒を越えるために曝露を広げるのは、棒を事後に動かすのと同じ。
    曝露は**修理が変えられるもの**でなければならない(2026-10-19)
15. **掃く前に、目的の指標が既に測った量の代数的な関数でないかを確かめる。**
    関数である部分は既に答えが出ている(2026-10-19)
16. **比に置いた棒は、試したい機構が起きていても否定される。**
    比を反対向きへ動かす**第二の機構**が同じ比の中に隠れる。機構を試す基準は、比ではなく
    **数え上げの分解**を名指しすること(2026-10-19, J の IC7: 棒 `npred/ngt < 0.90` に対し
    実測 1.777 で否定、しかし融合は起きていた —— GT 領域の 14.2% が融合した部品の中にいた。
    隠していたのは 500px フィルタを跨ぐ膨張済みの小塊で、予測領域の 57.5%)。
    **判別子は「越えた/否定された」ではなく、第二機構の向きと結論の関係**(2026-10-19 に J が訂正。
    基盤が先に書いた「越えた棒は強い」は**偽**で、IC7 自身が反例: 第二機構が比を下へ押す設計だったら
    棒は**越えて**、起きていない融合を「起きた」と結論していた —— 同じ統計量、同じ罠、判定だけ逆)。
    **棒が頑健なのは、その統計量を動かすと名指しできる第二機構が、すべて結論と反対向きに動かすときだけ。**
    例: K の PAF は希釈がすべて MH-RR を 1 に引く = 結論と反対向き → 頑健。
    J の IC-j12(越えた棒)は第二機構が比を下げる = 拒否を発火させる向き = 結論と反対向き → 頑健。
    K の費用の比は、比が (1-精度)/精度 と**1つの数え上げの単調関数**で、引き離す分子と分母が無い → 頑健
17. **一般化は、根拠にした議論より先に進んではいけない**(2026-10-19, 基盤の誤り)。
    K の PAF が頑健なのは「希釈がすべて MH-RR を 1 に引く = 結論と反対向き」という向きの議論から。
    そこから「越えた棒は強い」へ広げた瞬間に偽になった。**議論は健全、一般則は偽** —— 同日に J が反例で止めた
18. **格子点を固定するのと、棒を固定するのは別**(2026-10-19, J)。測る点を
    「表が出る前に書かれていた値」で固定するのは正当(IC7 登録の d=8.485、IC6 共有半径の d=4.000)。
    しかし**今日出た数(0.142 / 0.575)をそのまま棒にするのは、通したい1つの数を通すと
    分かっている許容値**で、事後に棒を置くのと同じ。**棒は機構から導いて、脚を走らせる前に計算する**
19. **ある量の中央値が別の量の中央値と一致したら、名前の取り違えを先に疑う**
    (2026-10-19, K が基盤の誤りを訂正)。「細線化の引っ込み 10.8px」は実測 **0.5px** で、
    10.82px は同じログの別の節にある**隙間長の中央値**だった。向きは正しく、**大きさが10倍違った**。
    台帳の本体に置かれて F・G・J に配られていたので、**配った数は配った側が引き直す**
20. **定数は、前回の値ではなく前回の理由から引き継ぐ**(2026-10-19, K)。
    錨の `ANCHOR_MIN_GAP=8.0` をそのまま持ってくると、本番が短い標本(2.24〜7.81px)では
    **作者が長さだけで錨を見分けられる** —— 対照の向きが逆になる。提示も同じで、
    **半径9の赤丸が隙間そのものを覆っていた**(本番の隙間中央値 5.92px)。
    前回その提示が合格したのは隙間が長かったからで、値ではなく**条件が合格させていた**
21. **「判断できない」と答えられた項目を、反復の棒の中で採点しない**(2026-10-19, 基盤)。
    反復は器具の安定性の検査で、**作者が決められないと宣言した項目が動くのは漂流の証拠ではない**。
    完全に一貫した作者が未決定の2件を 50/50 で答えるだけで、**8/8 は 4回に1回しか出ない**。
    前回の 8/8 を期待値として持ち越すと、理由のない不合格を 3/4 の確率で作る
22. **回転で作る帰無の高さは、回す側の構造の密度で決まる。測る側の区間長では決まらない**
    (2026-10-19, D が基盤の登録した予測を否定)。機構は確認されたのに予測は外れた ——
    ラフの区間は 2.2〜3.1 倍多く短いが、帰無は**平均で下がった**(0.0334 対 0.0523)。
    再現率側は**ラフ(GT の 1.4〜2.5 倍の長さ)を回す**ので、密な構造は偶然で近くに落ちる。
    **同じ構造を回していない2方向の帰無は、そのままでは比べられない**
23. **数と条件は同じ行に載せる**(2026-10-19, K と基盤が同じ失敗の両側で踏んだ)。
