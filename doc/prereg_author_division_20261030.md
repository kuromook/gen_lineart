# 修正 1(2026-10-30 18:0x。**判定を1問も集める前に書いた**)

**理由**: 登録を書いた後、器具を作るために材料を調べて、**設計に効く事実が3つ**出た。
**棒(C1〜C3)は1文字も動かさない。** 変えるのは**見せ方と、印字する義務**である。

## 1-A. **A0 の境界は縮小側の格子で、標準は原寸である**

`m12_score_a0_nulls.py` の登録(既存)が言うとおり、**A0 の入力は `CanvasPreview`**
(一様量子化 `floor(v*8/256)` → 等しい量子化色の8連結領域)。採点は
`pair_counts_upsampled(pred_small, s, gt)` で、**A0 を `s` 画素のブロックに拡大して
原寸の標準と比べている**(`s = 4`。preview は画布の約 1/4)。

→ **原寸 1024x1024 の窓に描くと、A0 の境界だけが 4 画素のブロックになる。**

**決めたこと**: **A0 はそのまま(近傍拡大)で見せる。滑らかにしない。**
理由は第1条 —— **描かれた絵は解き明かした像そのもの**であり、
**滑らかにすると A0 が出していない像を作者に見せることになる。**
**画面に1行書く**: 「**A は縮小側の格子で作られているので、境界が 4 画素の段になります**」。

## 1-B. **交絡の申告 —— 作者が「境界の粗さ」で選ぶかもしれない**

1-A の帰結として、**作者が分割の良し悪しではなく境界の粗さで A を退ける道が在る。**
**これは `p_A0` を下げる方向の交絡で、走る前に分かっている。**

**印字する義務を1つ足す**(これが修正の実体):
**`T`(一言)の自由記述を全問で集め、理由に「段・粗い・ガタガタ・ジャギ」等の
境界の質を指す語が出た窓を数えて、`n_edge_reason` として別に印字する。**
**`p_A0` の隣に必ず並べる。** これで**交絡が効いたかを後から読める。**
**語の一覧は先に固定する**(後から足すと、都合のよい語だけ数えることになる):
`段 / 粗 / ガタガタ / ギザギザ / ジャギ / カクカク / 荒い / ブロック`。

**`n_edge_reason` が判定の付いた窓の 1/3 を超えたら、`p_A0` を「交絡つき」と書く。
その場合も撤回しない** —— **両方印字して、読み手に渡す。**

## 1-C. **A0 の格子は原寸と端で揃わない。窓は余りを避けて取る**

preview は画布の厳密な 1/4 ではない(例: 画布 7016x6543 に対し preview 1754x1635。
**1754×4 = 7016 で横は揃うが、1635×4 = 6540 で縦は 3 画素余る**)。
採点側は `ps[:g.shape[0], :g.shape[1]]` で切り落としているので点数は影響を受けていないが、
**窓を右端・下端に取ると、A0 の格子が原寸と揃わない帯が窓に入る。**

**決めたこと**: **窓は `s*floor(preview辺/s)` の範囲の内側からのみ取る。**
**余りの画素数を頁ごとに印字する**(`remainder_x` / `remainder_y`)。
**種 `20261030` は変えない** —— 範囲が狭まるので引きは変わるが、**狭めたことを印字する**
(**範囲も棒の一部である**。結果を見る前に狭めている)。
