## この角度を今やる理由(**第2便の答えが「いいえ」だったから**)

**第2便の問いは「2016〜2021 にアナログ線画の作品が在るか」で、答えは「無い」だった。**

## Question

**作者の裁定した「下絵の工程」(混在 / アナログ)と「機材」(iPad と明記 / 未記載)は、
線画の工程と時期を固定しても、同じ抽出・同じ器具の中でタイルを分けるか。**
—— **「いいえ」と答えられる**: 対の距離が作品ラベルを交換した帰無の帯に収まれば「いいえ」。

## Arms(= 対の群。**軸ごとに、他の2軸を固定した母集団で読む**)

札の順序は**第1段で固定したものをそのまま使う**(動かさない):
`2015, 2016, 2017, 2018, 2019, 2019b, 2020, 2020b, 2021, 2022, 2022b, 2023b, 2024, 2024b, 2024c`
(索引 0〜14)。**時期距離 = 索引の差の絶対値。** 第2便の20作の札はすべてこの一覧の中にあり、
**札を1つも足していない**(= 定規を動かしていない)。

| 軸 | 母集団(固定したもの) | ラベル | **ちがう**対 | うち距離≤3 | **うち距離0** | **同じ**対 | 距離≤3 | 距離0 |
|---|---|---|---:|---:|---:|---:|---:|---:|
| **A 線画** | 31作(固定なし) | アナログ4 / デジタル27 | 108 | 10 | **0** | 357 | 211 | 48 |
| **B 下絵** | **21作**(線画=デジタル・機材=未記載) | 混在12 / アナログ9 | 108 | 88 | **10** | 102 | 89 | 33 |
| **C 機材** | **15作**(線画=デジタル・下絵=アナログ) | iPad 6 / 未記載 9 | 54 | 8 | **0** | 51 | 48 | 11 |

- **B の距離0の10対**(= 2017 の中だけ): `ako5` と `running`(下絵アナログ)× `gakusai1-3DL`
  `pink` `kacho` `copy` `stoptime`(下絵混在)。**線画の工程では一度も作れなかった対比。**
- **C の距離≤3 の8対**: `UNI`×(`nurse` 1 / `akogoods` 2 / `akokate` 2 / `hero` 2)、
  `nurse`×(`ben` 3 / `fringe` 3 / `fringe3` 3 / `succor` 3)。**下絵はどちらもアナログ。**
- **A は距離0の対が1つも無い**(アナログ線画は 2024 系だけ)。**だから A は名乗らない**(C3)。
- **機材と下絵は互いに交絡している** —— 下絵混在の12作は**すべて機材未記載**、
  iPad の6作は**すべて下絵アナログ**。**だから軸ごとに他方を固定する。**
  固定したものは測れない(= この走行は「混在 × iPad」について何も言わない)。

**既定の腕(moat-register の既定)をこの題材に写したもの**:
- **何もしない** = **NC1 自己 AUC**(同じ作品を両側に置く)。**恒等で 0.5000 ちょうど**
- **全部やる** = **S5 外部との対**(31作 × `animagine` / `illustrious` = 62対)。**天井の参照**
- **既存の道具だけ** = **単軸 AUC 12本**(多変量を使わない読み)。各対で最大 |AUC−0.5| を印字
- **学習なしの頻度表** = **時期距離だけの線形回帰**(NC4)。作品の属性を1つも使わない
- **新しい床** = **NC5 同じ作品を2つに割った対**(下記)。**「作品」という単位自身の対照**

## Primary value

**対ごとの多変量 AUC** —— F9 の9軸・L2 ロジスティック回帰・**群単位の5分割**
(群 = 小領域、`digest_mod` で固定。`multivariate_transfer.py` の `multi_cv` をそのまま使う。
`C` は実データの折の中で選び、**帰無には実データが選んだ `C` を渡す**)。**プールしない** ——
対ごとに1行、セルごとに中央・最大・最小を印字する。

**軸ごとに読む差**: **D = 中央(ラベルがちがう対) − 中央(ラベルが同じ対)**。
**3通りすべて印字する**: **距離0 / matched(距離≤3) / 素(全対)**。
**名乗るのは B は距離0、C は matched だけ。素の D からは何も名乗らない。**

## 帰無値(**棒の前に印字する**。2段ある)

1. **対ごとの帯** —— 群単位でラベルを置換(多変量 50回、`C` は実データのもの)+ 群単位の
   bootstrap(1,000回)。**帯の幅が 0.30 を超えた対は「帯が足りない」と印字**(第1段と同じ境)
2. **セルの差の帰無 = 作品ラベルの交換**(**裁定は作品ごとに与えられたので、作品が単位**)。
   **3軸すべて厳密に数え上げる**(近似しない。AUC を再計算しないので費用はゼロ):
   - **A** 31作から4作をアナログに選ぶ **C(31,4) = 31,465 通り**
   - **B** 21作から12作を混在に選ぶ **C(21,12) = 293,930 通り**
   - **C** 15作から6作を iPad に選ぶ **C(15,6) = 5,005 通り**
   - **距離0 / matched / 素 のそれぞれで同じ交換を当てる。**
     **どちらかのセルが空になる割り当ては「外し」として数えて印字する**(第1段で 165→164 が
     黙って落ちた形。規律9)
   - **実測の順位から片側 p**(= (帰無 ≥ 実測 の数 + 1)/(通り + 1))

## Instrument checks(IC)

- **IC1** 同じ作品を両側に置いた AUC。**期待 0.5000 ちょうど**。外れたら走行全体を読まない
- **IC2** **走行の外から既に知っている値**: `doc/result_ako_series_20261031.md` の
  **学祭編どうしの多変量 中央 0.8947 / 最大 0.9972**。同じ器具・同じ CSV の A2 行で再計算し
  **許容 5e-4 で一致**
- **IC2b(新)** **第1段の55対の多変量 AUC が 1e-9 で再現する。**
  `multi_cv` は乱数を使わないので**決定的**であり、プールを作り直しても同じ値が出るはずである。
  出所は `results/process_within_20261031/process_within.json`。
  **再現しなければプールか器具が変わったので、走行を読まない。**
  これが**この走行の最強の点検**である(帯と帰無は乱数列が延びるので一致しない。**一致を求めない**)
- **IC3** 31作のタイル・群・頁が裁定の表と一致する(第2便は 2,651 / 959、第1段は 2,947 / 981)
- **IC4** **門で落ちた数を作品ごとに印字する**(`ink_ratio < 0.011992`)。**門は動かさない**
- **IC5** 正規化の前後で紙の水準(最小・中央・最大)を作品ごとに印字

## Negative controls(NC。**それぞれ名のある1つの誤り**と、**いま書く期待値**)

- **NC1 恒等** —— 同じ作品を両側に置く。誤りの層: 対の構成。**期待 0.5000**
- **NC2 群を壊す** —— ラベルをタイル単位で置換。誤りの層: 独立性の単位。
  **期待(第1段の実測に合わせて縮めた): 帯が 0.30 より狭くなる。それだけ。**
  第1段では帯は狭くなったが**帰無の中央は 0.5 から上にずれなかった**ので、
  **中央のずれは期待に入れない。** 期待を実測に合わせて直すのは**走る前に書くときだけ**正当
- **NC3 枚数** —— 対の多変量 AUC を **log10(小さい側のタイル数)** だけで線形回帰。
  誤りの層: 枚数の偏り。**期待: AUC は枚数に不変なので R² < 0.20。**
  **R² ≥ 0.20 なら、主値を枚数で2層(小さい側の枚数の中央で分割)に割って D を両層に印字する**
  —— **この再読もいま登録する**(後から思いつく読みにしない)
- **NC4 時期だけ** —— 対の多変量 AUC を**時期距離だけ**で線形回帰(465対)。
  誤りの層: 属性を使わない予測。**期待: 傾きは正。**
  **R² > 0.30 なら、素の D は時期の言い換えだと結論に書く**(第1段は 0.2557 だった)
- **NC5 同じ作品を2つに割る(新)** —— `2017/gakusai1-3DL`(583)・`2019/succor`(491)・
  `2018/ako6`(483)を**群の `digest_mod 2` の偶奇で2つに割り**、その対の多変量 AUC を測る。
  誤りの層: **「作品」という単位そのもの。** 同じ作品・同じ工程・同じ札・同じ機材なので、
  **分かれる理由は「群の集合がちがう」以外に無い。**
  **期待 ≤ 0.80。0.90 を超えたら、器具は任意の群の集合を分けている** ので
  **この走行のどの軸も名乗れない**(下の「倒れる行」)

## Pass criteria(C。**それぞれの結末が何を意味するかまで書く**)

- **C1 下絵が見える** —— **距離0 の D(下絵) ≥ 0.05** かつ **交換の帰無の 97.5% を超える**
  → **「同じ年の中でも、下絵の工程で線画のタイルが分かれる」。**
  線画の工程はデジタルに、機材は未記載に固定してあるので、**残る交絡は作品そのもの**で、
  **その単位が交換の帰無**である。**届かなければ「下絵は映らない」**(それも答え)
- **C2 機材が見える** —— **matched の D(機材) ≥ 0.05** かつ **帰無の 97.5% を超える**
  → **「iPad と明記された作品は分かれる」。** 距離0 が0対なので
  **時期と完全には切れていないことを必ず添える**(距離の中央を隣に印字する)。
  第1段で NC3 として発火した読み(+0.1774、p=0.0423)の、**下絵を固定した再試験**である
- **C3 線画は名乗らない** —— matched の D(線画) と帰無を**印字はする**が、
  **どちらに出ても「工程」とは名乗らない。** 距離0 が0対・距離の中央が10 で、
  **第2便の答えが「いいえ」だった時点で、この母集団では名乗れないと決まっている。**
  **印字する理由は、第1段(+0.2762、p=0.0244)が31作でどう動くかを記録に残すため**であって、
  棒に当てるためではない
- **C4 外部の床** —— **min(S5) ≤ max(作者どうし)** なら、`ako` 系の **C-D** が
  31作・抽出固定でも再現する → 「作者の中の距離が、作者と外部の距離を超えることがある」
- **C5 判定できない** —— **読む側のセル(B の距離0 10対 / C の matched 8対)の帯が
  1つでも 0.30 を超える、またはそのセルが 8対を下回る** → **その軸は「判定保留」**と書き、
  **次に何作足せば足りるかを数で書く**
- **この行で全体が倒れる結末**: **NC5 が 0.90 を超える** →
  **器具は「群の集合」を分けているだけなので、軸で仕分ける計画そのものを取り下げる**
