## 問い(3つ)

1. **文字の層は、面の境界に使いますか。**
   (`page0019` の 97面は全部これです。**納品の列に `text` という種別が在る**ので、
   「使わない」なら構造で引けます)

2. **3D の `rendering_*` 層は、面の境界に使いますか。**
   —— **`bg`(背景)フォルダーの中に在り、名前は `rendering_lineart` / `rendering_shadow` /
   `rendering_base` です。** 納品の種別では3枚とも `raster`。
   **`rendering_lineart_middle0001` は「描画色」が入っている** ので、
   **この企画の原案(塗りの入っていないマスク層)が材料にしている側の層です。**
   - 補足して伺いたいこと: **これは 3D から起こした背景ですか。**
     **`rendering_lineart` は 3D の輪郭線ですか** —— **そうなら「線」側ですか、
     それとも背景の素材で面の境界にはしませんか**

3. **クリップでない `color` / `MASK` 層は、面の境界に使いますか。**
   (`page0005` の `color` 4枚・`MASK` 4枚、`skima12H` の `color` 1枚。
   **クリップの付いた層はすでに「境界にしない」で落としています** ——
   あなたの「クリップ層は自分の下地を遮蔽しない」という既裁定と地続きなので。
   **残っているのはクリップが付いていない同名の層です。**
   **「落とす版」を `T3c` として隣に出してあります**: `page0005` は面 482→404、
   `skima12H` は 363→360。**どちらも線率はほとんど動きません**)
