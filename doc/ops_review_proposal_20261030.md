## 3. フックの案 —— **「入れるとこうなる」**

**止める hook と警告だけの hook を分ける。** 誤発火でユーザーの作業が止まる形が最悪だから、
**止めるのは、判定が器具の側で確定するものだけ**にした。

書いた器具は4本。**全部、負の対照を回して発火を確かめてある**(§3 末尾)。

### 止める(deny を返す)

| | 事象 / 条件 | 走るもの | 入れるとこうなる |
|---|---|---|---|
| **H1** | `PreToolUse` / `Bash`、`if: "Bash(git add *)"` | `tools/hooks/guard_forced_add.py` | `git add -f` が `data/` 配下か監視対象の拡張子を足そうとしたら**止まる**。広い指定(`-f .` / `-f -A`)も止まる。`-f` が無ければ**何も起きない**。`-f` 付きで無害なら**警告だけ**。**器具が無かった2つの規則に初めて器具が付く** |
| **H2** | `PreToolUse` / `Bash`、`if: "Bash(git commit *)"` | `tools/hooks/guard_public_artifacts.py block` | 表に無い追跡画像・追跡重みが index に在れば commit が**止まる**。無ければ**沈黙**(0.19 秒) |
| **H3** | **git の `pre-commit`**(Claude の hook ではない) | `tools/hooks/pre-commit` | **16 の木が共有する `.git/hooks` に1つ置けば全部に効く**(`git rev-parse --git-common-dir` が同じ所を指す)。ユーザーが端末で打った commit、別のセッション、`!` 前置きの実行も覆う |

**H2 と H3 は重ねる。** 理由は H2 だけでは覆えないものが在るから:

- Claude の hook は **Claude が打った道具呼び出ししか見ない**。`if` は前置き一致なので
  `cd x && git commit` のような複文も、`!` で打った commit も通る
- 逆に `pre-commit` は **`--no-verify` で素通りし**、**`.git/hooks` は git が追跡しない**ので
  **clone にも別クローン2つにも付いて来ない**(`lineart-panel-generation` /
  `lineart-face-words` はそれぞれ別の `.git` を持ち、**どちらも hook は空**)
- **どちらも門ではない。2枚あって初めて、1枚の穴がもう1枚で埋まる形になる**

### 警告だけ(止めない)

| | 事象 | 走るもの | 入れるとこうなる |
|---|---|---|---|
| **H4** | `SessionStart` | `tools/hooks/session_brief.py` | 起動時に **立場(基盤 / track)**と、`foundation` なら **audit の件数と先頭3件**、表の門の件数が context に入る。**規律4 が「Claude が思い出して回す」から「ハーネスが回す」に変わる。** track では audit を**回さない**(器具は自分の親を基盤と見るので、track で回すと無意味) |
| **H5** | `PostToolUse` / `Edit`\|`Write`、`if` を `CLAUDE.md` に絞る | `wc -l` 一発 | `CLAUDE.md` が 150 行を超えたら**その場で言う**。いま 150 行なので、**次の1行で鳴る**。誤発火は構造上あり得ない |
| **H6** | `Stop` | `guard_public_artifacts.py warn` | ターン終わりに表の門を回す。**経路を問わず**、そのターンで追跡画像が増えていたら言う。止めない。**覆う範囲が一番広く、害が一番小さい。採るなら最初の1本はこれ** |

### 却下したもの(**理由ごと残す**)

- **`push` を見る hook(基盤が他人の枝を push するのを止める)** —— 書けるが、**いま誰も踏んでいない**。
  規則の表に入れるのは踏んだ後でよい。(規律9: 落としたものを理由別に数える)
- **`inbox/`・`outbox/` への書き込みを見て「文書は `doc/` に置く」と言う hook** ——
  **誤発火が高い。** `outbox/reply_*.md` と `outbox/push_*.md` は**そこに置くのが正しい**。

### 器具が走れなかったときの振る舞い(**ここが一番大事**)

4本すべて、**器具が走れなかったら「一致」と読ませない**。

**沈黙が正常動作の点検を足すときは、沈黙が「点検した」も意味するように作ってはいけない。**
