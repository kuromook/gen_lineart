## 2026-11-20 登録 S1(走る前に書いた。smoke の前)—— 下絵→線画の4分類の第1版

**問い**: 対(厳しい門の492頁)の線画の線を 残した/動かした/足した に、下絵の線を 捨てた に分けると、作品ごとにどれだけか。**定義は Claude の仮説**(条例2)で、本当の棒は作者の目。

**前処理(役割ごとに定数を引く。規律9)**
- 灰に直して墨 = 1 − 明るさ。**二値化の閾は頁×側ごとの Otsu**(明るさ < 243 の画素で)。線画は灰 ~90、下絵は灰 ~180 になる(running 3頁で確認)。閾は行ごとに印字
- 面積 < 8 画素の連結成分は塵として落とし、数を印字。骨格は `skimage.morphology.skeletonize`。量は**骨格の長さ(画素)**(破片の単位は使わない。Track K)

**腕**
- **A(下限の棒 = 自明な腕)**: 位置合わせなし、距離の閾だけ
- **B(主)**: 下絵を線画に**頁全体の平行移動**で合わせてから同じ閾。移動は 1/4 縮小の墨のぼかしの位相相関、±64px で打ち切り、値と応答を印字

**分類**(線画の骨格の各画素 p、下絵の**墨**(骨格でなく)までの距離 d。線幅は墨の側に吸わせる)
- 残 d ≤ r1 = 6px / 動 r1 < d ≤ r2 = 40px / 足 d > r2
- 下絵の骨格の画素 q で、線画の墨までの距離 > r2 → 捨
- r1・r2 は 600dpi 前後の頁で 0.25mm・1.7mm の仮置き。**作者の語で引き直す**(条例2)。頁の大きさを行に印字

**主値**: 腕B の、線画の骨格の長さに占める 残/動/足 の割合と、下絵の骨格の長さに占める 捨 の割合。**頁ごとに印字し、作品ごとに中央値**。作品・年をプールしない(作品フォルダーごとに1行)

**帰無値と対照**
- **N1 ずれの上界**: 512px の区画ごとに、±r2 の平行移動を区画単位で許して分け直す(区画ごとに 残 が最大になる移動)。残 の増分 Δ = 局所のずれで説明できる量の**上界**(区画まるごとの描き直しもここに吸われるので上界)
- **N2 偶然の重なり**: 同じ作品の別の頁の下絵と組ませる(腕B と同じ手順)。このときの 残 = 偶然なぞったように見える床
- **C1 陰性の対照**: 線画をそれ自身と組ませる → 残 ≈ 100%・足 ≈ 0 のはず。外れたら器具が壊れている

**結果の読み方(先に書く)**
- 頁の 残(腕B)が N2 の 残 + 10 ポイントに届かない頁は**判定保留**(偶然と分けられない)。数を印字
- N1 の Δ が 動 の半分以上なら、その頁の 動 は「ずれで大半が説明できる」とし、動 は上界として書く
- 4分類が作者の目に合うかは、smoke の原寸の切り出しを**まずユーザーに見せて**決める(聞き取りの前。条例6)。合わなければ定義を作者の語で直し、**S2 として登録し直す**(S1 の結果は撤回しない。規律10)
