### 隣接の定義 —— 結果を読む前に決めて印字する

- 線の 16 点折れ線を **1.0 px 刻み**で標本化する
- `d(点)` = `~fill` の Euclid 距離変換。ベタの**内側は 0**(= Track J の「ベタの中心軸」を含める)
- **主**: `ADJ_PX = 4.0`(J の `FILL_HALF_WIDTH_PX` と同値、native px)、
  `ADJ_FRAC = 0.25` —— 標本点の 1/4 以上が `d <= ADJ_PX` なら「ベタ隣接」
- 感度(副、主張には使わない): `ADJ_PX ∈ {2, 4, 8, 16}` × `ADJ_FRAC ∈ {0.10, 0.25, 0.50}`

### 主要評価指標と合否(先に書く)

2x2 は「印あり/なし」×「ベタ隣接/非隣接」。主値は
**RR = P(隣接 | 印あり) / P(隣接 | 印なし)**、併記に Fisher 正確検定(両側)。

- **K1 支持** = `RR >= 1.5` **かつ** `p < 0.01` **かつ** 実測 RR が NC-k1 の 95% 帯の外
- **K1 反証** = `RR <= 1.2` かつ 95% 帯の中。このとき原因は細線化一般の側にあり、
  ベタ近傍の輪郭取得では済まない(通達どおり直し方が変わる)
- 1.2 < RR < 1.5 は**判定保留**とだけ書く。結果を見てから基準を動かさない

副: **K1-strat**。長い線ほど印が付きやすく、同時にベタに触れやすい(交絡)。
線の長さの 5 分位(対象の線をプールして決める)で層別し、Mantel-Haenszel の RR を併記する。
**層別後に RR が 1.2 を割るなら、K1 は「長さの別名」だったと書く**。
