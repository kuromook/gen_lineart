  ベタ近傍の輪郭取得では済まない(通達どおり直し方が変わる)

グループ外 4,816 本の 92.4%)。→ 主脚の差は「グループ内の損失 2 はベタでない方だから」
という説明では消えない。ベタの外だけに絞った行(RR 0.5293)でも同じ大きさの差が残る。

### これで言えること / 言えないこと

- **言える(記述)**: 作者がパーツとしてまとめた線の中で、畳まれた橋由来のトークンは
  グループ外の**およそ半分の率**しか現れず、グループが小さいほど率は下がる。
  偽グループの帯の外なので偶然の配置では出ない
- **言えない**: 「ベタ由来の屑はグループに入らない」を**支持**とは書けない(RR 0.5154)。
  第 2 脚は不支持
- 大きさとの単調関係は**交絡の候補が残っている**: 多数本に割れた部位は太いインク・ベタ近傍で
  描かれやすいので、「大きさ」と「ベタ近傍さ」が同じ方向に動く。ベタの外に絞っても
  勾配は残るが(1〜2 本で 0%、3 本以上で 1.413%)、層別は登録していないので**ここでは測らない**

### A6-3: 「率」の定義を**結果を見る前に**固定する(NC-k2 の 2.0 倍判定に必要)

登録は「同じ部位の率が、またぐ率の 2.0 倍以上」とだけ書いてあり、分母を決めていなかった。
**箱ごとに**次で固定する:

- **分母** = その箱の**構造条件**を満たす対の数
  - 箱 A: 畳み込み後の同じ節点に出ている腕の対(F の `arms` そのまま。橋 span は F が
    除いているので除いたまま = 現行規則が実際に見た候補集合)
  - 箱 C: 両端が節点付きで**節点が別**な tip の対、tip 間距離 <= `GAP_MAX = 24px`
  - 箱 B: **自由端どうし**の tip の対、tip 間距離 <= 24px
- **分子** = 分母のうち門を通った対(角 30 度以内 **かつ** 横ずれ 3.0px 以内、
  箱 B はさらに**線分上の墨画素数 0**)
- **同じ部位** = 2 つの token が作者の**同じグループ**に入っている対。
  **またぎ** = 2 つの token が**別のグループ**に入っている対。
  **どちらのグループにも入っていない線は分母にも入れない**(K2 の問いは部位の中の話なので)
- **同じ token の中の対は数えない**(既に 1 本なので取り逃がしではない)

### A6-4: 条件 (d)「現行規則が対にしなかった」が実際に効くのは箱 A だけ

現行規則は**同じ(畳み込み後の)節点に出ている腕の対**しか作らない。したがって
箱 C(節点が別)と箱 B(自由端)の対は**定義上すべて「対にされていない」**。
→ 条件 (d) で絞られるのは箱 A のみ。**箱間で数の意味が揃っていないことの明示**であり、
これも合算してはならない理由の 1 つ。箱 A は「門は通るのに規則が落とした対」、
箱 C と B は「規則がそもそも見ていない対」である。
