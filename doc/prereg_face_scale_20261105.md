## Primary value

軸ごと・外部プールごと(k = E6, I6)に **`AUC_m(A1, E_k)`** と、帰無値 N1 の中央値 `g0` と帯。
読むのは **`s = |g0 − 0.5| − |AUC_m − 0.5|`**(正 = 揃えると 0.5 の側へ縮む)。

## 帰無値(棒の前に印字)

**N1**: 1,000回。回 t は揃え方の t mod 200 回目と**同じ枚数**を、**顔の検出された窓全体(大きさを見ない)**から引く。
作者側は**作品ごとの数を揃え方と同じに保ち**、作品の中で**元コマ単位**(元コマの窓はまとめて入る。数に達したら
最後の元コマから無作為に削る)。外部側は元の絵単位で同じ総数。`AUC₁₃` を計算。中央値 `g0` と帯 2.5〜97.5%。
**N0**(NC1 用): 同じだが作品を保たない。

  **N1 の中央値 − 顔のある窓全体の値 = 作品の比が動かす分**として軸ごとに印字する(棒ではない)

## Pass criteria(軸ごと、A1、両モデル)

- **C2 縮む**: 両モデルで `AUC_m` が N1 の帯の外、`s ≥ +0.10`、かつ 0.5 をまたがない
- **C3 開く**: 両モデルで帯の外、`s ≤ −0.10`、0.5 をまたがない
- **C4 向きが反転**: 両モデルで帯の外、`AUC_m` が `g0` と 0.5 の反対側に 0.10 以上 → 判定保留(印字)
- **C1 残る**: 両モデルで帯の中、かつ両モデルで `|g0 − 0.5| ≥ 0.15`(もともと差がある軸だけ)
- それ以外 → 判定保留 / `line_width_p50`・`width_consistency` → 判定保留(条例4、相異なる値の数と最大の同値塊を印字)/
  `ink_ratio` → 帰無値の腕なので読まない
- **C5**: IC1〜IC3・PC・NC1 のどれかが通らない → 何も読まない

## What this run cannot settle

- 外部側は作品の比を持たない(プロンプトで顔の大きさが決まるなら、プロンプトの比も動いている)
- 縮んだとき、それが**画面の中の人の大きさ**か、**引きの絵に付く描き方**(背景が多い等)かは分けない
- モデルの一般性(条例8)/ 線と塗りの混ざり(条例9)
