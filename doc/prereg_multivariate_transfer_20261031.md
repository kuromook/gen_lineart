`doc/result_third_pool_20261031.md`)/ **上位法**: `../lineart/doc/CURRENT.md § Working Discipline`、
条例は `doc/initial_notice.md ## 条例`

**この登録は、閉じるまでは素案である。閉じた後に中身を選び直したら、向きがどちらでも棒を動かしたことになる。**
**これを閉じる前に、どの点数も計算しない**(単軸の AUC は前の走行で既に見ているので、§IC で
「既知の値」として使う —— **新しい証拠としては使わない**)。

## Question

**12軸を同時に入れた判別器は、作者・アナログ主体(A1)と外部(A3)で学習した後、
作者自身のデジタル線画(A2)を「作者側」に置くのか。**

**「置かない」が答えになりうる** —— そのときは**多変量でも学習しているのは工程である。**
前の角度は**軸を1本ずつしか試していない**(結果 §8)。**1本ずつでは残らなかった組み合わせの信号が
在るのかどうかは、まだ一度も測っていない。**

**なぜ移植の形にするか**: 同じプールの中で当てさせると、**「作者側」と「外部側」を分ける境界が
工程の差でできていても点数は高く出る。** **学習に使っていない工程(A2)で試して初めて、
境界が作者のものか工程のものかが分かれる。**

### 器具(**ここで固定する**)

- **ロジスティック回帰、L2**。`scipy.optimize.minimize`(L-BFGS-B)で自作する ——
  **この venv に sklearn は無く、共用の venv に入れない**(他のセッションの足元が動く)。

  **プールごとに標準化し直さない** —— **それは測ろうとしている差そのものを消す操作である**

- **乱数は使わない。分割は群名の SHA-1 の剰余で決める**(seed の選び直しという自由を塞ぐ)

## Pass criteria(**走る前に固定。棒は F9 にだけ当てる**)

**前提の棒 P** —— **E1(内部)の平均 test AUC ≥ 0.75。**
**根拠**: 単軸の最良(門と帰無値の腕を除く)が `faint_mean_dist_to_ink` 0.8635 だった。
**9軸を同時に入れて内部で 0.75 に届かないなら、1本に負けている。** そのときは **C1〜C3 を読まない。**

| | 条件(**F9**) | **書く文** |
|---|---|---|
| **C1 工程で説明できる** | **P を満たし**、かつ **E2 の test AUC ≤ 0.60** | **「A1 対 A3 で引いた境界は、作者自身のデジタル線画を作者側に置けない。多変量でも学習しているのは工程である」** |
| **C2 作者由来の候補** | **E2 ≥ 0.75 かつ E3 ≥ 0.75**(**両向き**)かつ **E4 ≤ 0.70** | **「12軸の組み合わせは工程を跨いで作者側を拾う。作者由来の候補」**(**断定ではない。候補**) |
| **C3 片側だけ立つ** | **E2 と E3 の片方だけが 0.75 以上** | **「片側でしか移植できない。どちらの向きで立ったかを名指しし、判定保留と書く」** |
| **C4 判定保留** | 上のどれにも入らない(**E2 が 0.60〜0.75 の間**を含む)/ **帯が足りない行** | **「判定保留」と書き、帯の広さを数で添える** |

**0.60 の出所を先に書く**: 前の角度の C1 は単軸で `|AUC − 0.5| ≤ 0.05` だった。
**学習した判別器は 9個の自由な係数を持ち、向きも選べるので、帰無値の帯は単軸より広い。**
**だから 0.05 を 0.10 に広げて 0.60 とした。** **`null_label` の 97.5% がこれを越えていたら、
上に書いたとおり「帯が足りない」と印字して読まない。**

### **この道が間違っていると言う結果**(先に書く)

**P を満たさない(E1 < 0.75)**= **この12軸をどう組み合わせても、この材料では判別器にならない。**
そのときに書く文: **「12軸の組み合わせという道は、この材料では閉じる。次に試すのは軸の追加ではなく、
軸そのものの作り直しか、画素を直接入れる形である」**(**その場合、1本ずつの結果は動かない**)。

### **飾りの判定にしないための宣言**(2つ)

1. **IC-5 のとおり、`faint_of_drawn_ratio` 単軸で `AUC₁₂` は既に 0.9900。**
   **だから E4(作者の中)が高く出ることは、ほぼ確実に分かっている。**
   **E4 が高いことは新しい証拠ではない** —— **だから E4 を単独の「発火」として書かない。**
   **E4 は C2 の条件(`≤ 0.70`)としてだけ使う** —— **つまり C2 は最初から通りにくい。それを承知で置く**
2. **M4(F12)の test AUC は、門の片側性と帰無値の下駄を含むので部分的に恒等である。**
   **M4 が高く出ても C2 は立たない**(棒は F9 にだけ当たる)

## What this run cannot settle

- **別のモデル族**(木・近傍法・神経網)**なら移植できるのかどうか。** **ロジスティック回帰しか試さない**
- **画素そのもの。** 入れるのは**12個のスカラーだけ**で、**タイルの画素は一度も入れない**
- **塗りの側。** どちらの作者プールも塗りをほとんど含まない(A1 は墨の 99.8% が線、A2 は塗りが
  墨の中央値で 0.1%)
- **アナログ/デジタルの別。** **画素はその語を含まない。工程の札は作者の裁定である**
- **外部モデルの一般性。** 2モデルはどちらも SDXL 系(条例8)
- **因果。** **どの軸が効いたか**は係数から読めるが、**係数の大小は軸の尺度と相関に依存する。**
  **係数の順位を「重要度」として書かない**(印字はする)
- **「どちらの線画が良いか」。この track は絵を判定しない**

## 棒が動いたと見なす形(**先に書く**)

走った後に、**特徴集合を選び直す(F9/F10/F12 のどれを主値にするか)/ 軸を足す・抜く /
`C` の格子を変える / 標準化をプールごとにやり直す / 変換(log・順位化)を入れる /
分割の式(SHA-1 の剰余)や `H1`/`H2` の役割を変える / 学習と試しの向きを結果を見てから選ぶ /
A2 の行を足す・抜く / `0.75` `0.60` `0.70` のどれかを動かす / 正規化・門・白点を動かす** ——
**どれも、向きがどちらでも棒を動かしたことになる。**

**反証条件**: **ユーザーが母集団(どの作品がデジタルか)か曝露を裁定し直したとき。**
そのときは**前後の棒を両方、名前を付けて印字する**(規律10)。**過去の結果は撤回しない。**
