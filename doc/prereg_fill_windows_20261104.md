## Question

**作者側の窓を「塗りを含む窓」に替えると、12軸の `AUC₁₃`(作者 対 外部)は、線の窓のときから帰無の帯の外まで動くか。**
「動かない」と答えられる。

## Arms

## Primary value

軸ごと・外部プールごとに **`Δ_k = AUC₁₃(A1F, E_k) − AUC₁₃(A1L, E_k)`**(k = E6, I6)。
**A1F と A1L は同じ切り方・同じ5作品で、違うのは塗りの有無(と、塗りのある元コマかどうか)だけ。**

## 帰無値(棒の前に印字)

**N1**: 作品ごとに、元コマ単位で A1F / A1L の札を入れ替える(元コマの窓はまとめて動く。作品ごとの F 元コマ数は保つ)。
`Δ_k` を計算し直す。1,000回、帯 2.5〜97.5%。

## Instrument checks

- **IC1**: IC5 の分け方の再現 —— A1 の 200枚(seed 20261030)で塗りの割合の中央値が **0.002 ± 0.0005**(§0-2 で 0.0017)
- **IC2**: A1 の `AUC₁₃` が第3のプールの表(E6・I6 とも 12軸)を ±0.0001 で再現
- **IC3**: 自己 AUC 0.5
- **IC4**: 新しい JPEG の量子化表が A2 のタイルと一致(A2 は A1 と一致を確認済み)
- **PC**(陽性対照): **`fill_ratio`(器具に元から在る塗りの軸)の `Δ_k` が両モデルで ≥ +0.20。**
  **これは選び方からほぼ自明に出る数で、発見ではない。** 出なければ選び分けが効いていないので何も読まない

## Negative controls

- **NC1**: N1 の中央値が全軸・両モデルで `|·| < 0.02`

## Pass criteria(軸ごと)

- **C2 塗りが入ると動く**: 両モデルで `|Δ_k| ≥ 0.10`、**同じ符号**、**両方とも帯の外**
- **C1 塗りが入っても動かない**: 両モデルで `|Δ_k| ≤ 0.05`、**両方とも帯の中**
- それ以外 → 判定保留 / `line_width_p50`・`width_consistency` → 判定保留(条例4、tie 構造を印字)/
  `ink_ratio` → 帰無値の腕なので読まない
- **C5**: IC1〜IC4・PC・NC1 のどれかが通らない、または台帳に無いタイルが在る → 何も読まない

| 結果 | `purpose_sorting` への効き方 |
|---|---|
| **C2** | §3「線と塗りの混ざり」の行に、**その軸は作者側の窓に塗りが入ると作者対外部の AUC が動く**と根拠つきで書く。**今の差は線の窓でしか言えない**、と各行に添える |
| **C1** | 同じ行に、**その軸は塗りの窓でも同じ**と書く |
| 判定保留 | 何も書き足さない |

**どの結果でも §1 の箱は動かさない。** 理由: 今の箱は線の窓どうし(外部側も線)で決めた。
この走行は**作者側だけ**を替えるので、「作者と外部の差が混ざり方から来る」とは言えない ——
言えるのは「**作者側の窓の選び方で、その差の大きさが変わるか**」まで。

**先に書く予想(機械的に動くはずの軸)**: `deep_black_ratio`(塗りは純黒 97〜99%、§10-2)・`background_ratio`・
`ink_ratio` は**塗りの画素そのものを数える**ので、C2 に落ちても「塗りの画素を数えた」以上のことは言わない。
**意味があるのは、塗りの画素を直接は数えない軸**(`faint_*` 3軸・`long_*` 2軸・`orientation_entropy`・
`components_per_1k_ink_px`)**が動くか動かないか**。結果文書では2群を分けて書く。

**副(判定に使わない)**: `A1L − A1`(新しい切り方と既存のタイラーの門の差)、A1F と A1 で `AUC₁₃` が 0.5 のどちら側か。

**この方向がまちがっている、と読む結果**: PC が通らない(塗りの窓を選んでも器具の塗りの軸が動かない)——
そのときは「塗りの窓」をこの距離の規則で作れていない。
