# Track S 報告: 下絵から線画へ —— 作者が清書で何をしているか(2026-11-19〜11-27)

枝 `cleanup-delta`。経過と逐語の記録は `doc/work_log.md`(この報告はその要約で、数の出所は各節の見出しの日付で引ける)。
**この報告の数は、それぞれの器具の版と母集団の中での値**(規律1)。器具の版を名前で書く。

## 1. 問い

対(同じ頁の下絵と線画)の線を **残した(なぞった)/ 動かした(近くで描き直した)/ 足した(下絵に無い)/ 捨てた(下絵だけ)** に分け、**作品・年ごとに**数える。次に、動かした・足した線が**何のためか**を作者に聞く。

発端: 線画は下絵の墨の部分集合ではない(台帳 lesson 10)が、何を・どこで・どれだけ変えたかは測られていなかった。Track D の「下絵の墨の約半分は 8px 以内に線画が無い」が、位置のずれか作者の変更かも分けられていなかった。

## 2. 答え(短く)

| 問い | 答え | 確かさ |
|---|---|---|
| 作品ごとの 残/動/足/捨 | 出した(コマの単位、S4)。作品の中央値で 残 0.22〜0.83 | 「下絵の在る/無い」の区分は作者の区分を 18/20 で再現(H3、棒 16) |
| 年ごと | **答えられない** | 対が 2015〜2018 に偏る。2019 以降は作品ごとに 1〜30コマ、2020・2023 は 0頁 |
| ずれか変更か | 局所のずれで説明できる量の**上界**は 残 で +0.05〜+0.10(多くの作品)。「動」の大半はずれでは説明できない | **上界には作者の意図した位置の移動も入る**(HB・HB2)。純粋なずれは分けていない |
| 何のためか | あたり(下絵は位置だけ)/ 清書(形の確定)/ 細部の描き足し / 形・構図の変更、に**位置の移動**が組み合わさる | 作者の答え 40コマ(HB 20・HB2 20)。年の傾向は言えない |
| 4分類の境目 | **まだ作者の語で決めていない**(r1 6px・r2 40px は仮置き) | 条例2 のやり残し |

## 5. 結果

### 5.1 頁の単位(S1)
- 保留 139頁(床と分けられない 125・床が測れない 14)。使えた 353頁の 残 の四分位 0.41 / 0.49 / 0.56
- 頁全体の位置合わせはほとんど効かない(腕A と腕B の 残 の差は大半の作品で 0.01 未満)
- **頁の単位は問いに合っていなかった**: 作者(H1)「下絵レイヤには部分的に下絵が入ってるだけのコマが散見される」。20頁中 8頁で一部のコマ・人物に下絵が無い。下絵の無い所の線は全部「足した」に化ける → コマの単位へ

### 5.2 コマの単位(S2 → S4)
- S2: 下絵の在るコマ 1,781・無い 102。H2 で 17/20。外れ方は2つ —— **薄い鉛筆の下絵を Otsu が落とす**(「無い」に倒れる)/ 線でない墨・別の構図で「在る」に倒れる
- S3(薄い下絵を拾う二値化だけを替える)は登録の規則に届かず止めた。薄い墨を拾うと、面の骨格・少ない線で K が膨らむ
- S4(T1 × C): 在る 1,625・無い 258・線の少ない 45。T1 は下絵の墨を頁の中央値で 6割前後多く拾った(**S1/S2 は下絵の墨の大半を落としていた**)。偶然の床は 0.19 → 0.31、保留のコマ 527 → 280、頁の 残 の中央値 0.43 → 0.63
- **H3 18/20**(棒 16)。S2 から区分が変わった 10 のうち 9 が作者と合う。外れ2つは C が閾の近く(0.47・0.41)で、作者の一言はどちらも「あたり」

### 5.3 作品ごと(S4、下絵の在るコマ・保留を除く、中央値)
- 多くの作品(2015〜2016 の10作品、gakusai1-3DL・running・comics4 ほか): 残 0.66〜0.76・動 0.20〜0.25・足 0.03〜0.09・捨 0.16〜0.28
- 変更の多い作品: copy 残 0.22・足 0.42 / china2 0.33・動 0.43 / succor 0.34・足 0.29 / fitness 0.38・動 0.44 / pink 0.40 / hamlabi 0.44 / underworld 0.45 / 2024c_ako 0.50
- 下絵の無いコマの割合が大きい作品: ako6 0.63・succor 0.62・copy 0.50・avbu 0.34・comics4 0.32
- 局所のずれの上界 N1Δ: 多くの作品で +0.05〜+0.10、fitness +0.21・2024c_ako +0.20・hamlabi +0.14
- **年として読まない**(作品が年を代表しない。2019 以降はコマが少ない)

### 5.4 なぜ変えたか(HB・HB2、作者、各20コマ)
「動+足」の多い上位25% のコマから、年の層ごとに4つ。2回は選択肢が違うので合算しない。

| 主な理由 | HB | HB2 |
|---|---|---|
| 下絵があたり程度で、形は線画で決めた | 7 | 7 |
| 清書で形を整えた | 4 | 7 |
| 下絵に無い細部を描き足した | 4 | 3 |
| 形・構図を変えた | 4 | 1 |
| どれでもない / 分からない | 0 / 1 | 1 / 1 |
| 色分けの誤り(器具の失敗) | 0 | 0 |
| 札「位置を移動した」(組み合わせ) | —— | 4(3 はあたりと) |

- HB の「変えた」4 のうち 3 は一言で位置の移動(「下絵の移動」「位置が少し移動」「わずかに位置を移動」)。HB2 で位置の移動を札に分けると「変えた」は 1 になった
- 2018 の層は 2回で 8 中 7 が「あたり」。ほかの層の傾向は言えない(4コマずつ)
- 札の付いたコマは N1Δ が大きい(0.128 対 0.099)が、「動」そのものも大きく(0.465 対 0.330)、分けられない(n 4)

## 6. 届かなかったもの・置いたもの

- **構図違い(別の絵の下絵)の検出**: S5(コマの中の 64px 格子の相関 G)の下位から作者に聞いた H4 で、「別の絵」1/14(棒 4)。G は別の絵を集めず、描き直し・あたりのコマを集める。抽出側の QC も別文書を検出できないと自ら書いている。**検出器は作らず置いた**
- **あたり・ラフ・下絵の境**: ユーザー「境界は常に曖昧であり聞き取りをしてもおそらくぶれる、その追求はあとの課題」。C の 0.4〜0.8 は「あたり程度の下絵」の帯(Claude の読み)
- **年ごとの比較**: 厳しい門の対の偏りで届かない

## 7. 途中で見つけた、他に効くこと

- **`(work_id, page)` は対の QC 表で一意でない**(91 鍵・214 行が重なる)。名で引いて別の頁の絵を出した(H1 の h04・h18、撤回済み)。行は `source_path` か `line` で引く
- **薄い鉛筆の下絵は頁ごとの Otsu で落ちる**。下絵の墨を数える器具はどれも当たる可能性がある
- **対の不具合の候補 4**(作者の一言): riko p9(線画が黒いかたまり)・ng p17(半コマのずれ)・pink p30(線画が効果線だけ)・fitness p30(線画の側がベタの描き足し)。前の3つは census へ通知済み
- 下絵は頁に1層だけ(census)。下絵の無いコマは「同じ頁の別の層」か「紙に描いて残っていない」(作者の推測)
- 聞き取りの画面に、主な答えと組み合わせる**札**を足した(E がまとめて `foundation` に入った)
- **予測器は E に渡さない**(E は決定論の判定だけ。ユーザー 11-27)。理由のラベルは S の手元にある(`data/hb*_*/`、追跡しない)
