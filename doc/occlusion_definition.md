# 覆いの定義 —— 正本

作者が 2026-10-27 に確定。依頼8 の画素走行(全頁・全層の被覆の実測)はこの定義で走る。
**進行状態や到達点はここに書かない**(正本は `doc/CURRENT.md`)。ここは定義だけ。

## 1. 作者の答(2026-10-27、原文)

> 非表示レイヤーは含めない　不透明度が0でなければ遮蔽物　クリップ層は下地と合わせて
> 遮蔽範囲を決める　乗算は遮蔽物ではない、透過するものも調査は別途必要　
> レイヤーマスクはマスクが有効化されているなら適用後の範囲が遮蔽範囲

## 2. 実装の形

母集団は**非フォルダーで頁内の重なり順(`z_global`)を持つ層 328,678**(9,649頁)。
`z_global` は**大きいほうが手前**(抽出側 v2 の訂正。隣接兄弟 335,454組で例外 0)。

ある層 L が覆われている画素 = L の描画画素のうち、**L より手前の遮蔽物の遮蔽範囲**に
入るもの。被覆率 = その画素数 ÷ L の描画画素数。

### 遮蔽物に数える層

| 条件 | 作者の答 | 当たる層 |
|---|---|---|
| 表示 | **非表示は含めない**(`visibility` の低位ビットが 0 を外す) | 外れる 8,663 |
| 不透明度 | **0 でなければ遮蔽物**。重みづけも閾値もしない | 外れる 2 |
| 合成モード | **乗算は遮蔽物ではない** | 乗算と見られる値 2 が 19,042 |
| クリップ | 遮蔽物に数える。ただし**遮蔽範囲は下地との共通部分** | 20,559 |
| マスク | **有効なら適用後の範囲**が遮蔽範囲 | 読み手側で未確認 |

### 遮蔽範囲の作り方

1. アルファ > 0 の画素。**閾値を置かない**(置くと薄い層を黙って落とす。規律9)
2. クリップ層は **自分のアルファ ∩ 下地のアルファ**(T-M3)
3. レイヤーマスクが有効なら、**適用後**のアルファ

### 二組を同じ走行で出す

作者は乗算を外すと答え、**他の透過モードは「調査は別途必要」**と留保した。
後からの第二の走行(さらに18時間)は落ちるので、**一度の走行で両方の数を出す**:

- `O_strict` = 表示 ∧ 不透明度>0 ∧ **合成が通常(0)のみ**
- `O_wide`   = 表示 ∧ 不透明度>0 ∧ **合成が乗算以外すべて**

通常以外の合成は 23,582層(乗算 19,042、残り 4,540 が 15種)。

## 3. 読み手側に残っている3つ(作者の問いではない)

- **どの `composite` の値が乗算か。** 対応表はこちらの文書のどこにも無い。値 2 と見ているが
  **未確認**で、19,042層がこれに乗っている。違っていれば §4 の数は全部変わる
- **「下地」の同定規則。** CSP は連続するクリップ層をひとまとめに、その下の非クリップ層へ
  切り抜く。読み手がどう辿っているかは未確認
- **マスクの有効・無効のフラグが読めるか。** 構造の表の15列には無い。読めないなら
  「常に適用」か「常に無視」のどちらかに倒すことになり、**それは定義の変更**である

## 4. この定義で動く数

- **既知セル**(上に遮蔽物が無い層 = 被覆は 0 でなければならない):
  `O_strict` で **9,917層**、`O_wide` で **9,903層**。
  定義前の 9,649(上に層が1枚も無い)と 9,887(表示×不透明度だけ)から更新
- 非表示の層 8,663 は**測る側からも外す**。ただし**落とした数を理由別に印字する**(規律9)
