## 3. 読み

1. **モデル差の約3割は線幅だった**(0.1506 → 0.1051)が、**残りは幅に依らない直線の中身の差**である。
   **`illustrious` の方が直線の枝の割合が高い**(平均 0.5948 対 0.5052)。登録の表どおり ——
   **`long_line_ratio` は判定保留のまま、新しい軸に「モデルで直線の中身が違う」と根拠が付く。**
2. **向きの反転(副。判定に使わない値)**: 元の軸では作者側の方が「長い直線」が多かった(`AUC₂₃` 0.75)。
   **幅に依らない軸では逆で、作者側の方が直線の枝が少ない**(`AUC₂₃` 0.3764 / 0.2713、平均 A2 0.4146 対 E6 0.5052)。
   **元の軸の「作者の方が長い直線が多い」は、作者の線が太い(`line_width_p50` 中央値 3.82 対 1.91)ことを読んでいた可能性が高い。**
   **ただしこの走行は新しい軸の作者由来を仕分けない**(対照一式を当てていない)ので、反転は事実として置くだけ
3. **この軸の「直線」は ±2px の揺れまで**(§0 の閾)。手で引いた線の揺れが 2〜3px を越えるなら、作者側の値が低いのは
   **揺れの大きさ**を読んでいるのかもしれない。**閾を動かして確かめることはしていない**(別の登録)
4. A1(アナログ主体)は平均 0.3012 で A2(デジタル)0.4146 より低い(`AUC₁₂` 0.3613)。印字だけ
