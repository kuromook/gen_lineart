## Question

**線画の層の、遮蔽物に覆われている描画画素は、遮蔽物の輪郭のすぐ内側に集まっているか。**

- 集まっている → その層は**遮蔽物を知って描いた**(食い込みだけが覆われている)
- 奥まで一様に広がっている → **知らずに描いた**(予定外の遮蔽物の下に線が在る)

層ごとにどちらかが言えれば、K・L・M は「線が途切れている理由」を層単位で割れる。

## 量の定義

ある線画の層 L について:

- **遮蔽範囲** = L より手前の `wide` 遮蔽物の遮蔽範囲の和(`_v4` の規則そのまま。作業用の層は入れない。
  クリップは今の読み手のまま = 合成しない。下の但し書き)
- **覆われた画素** = L の描画画素(アルファ ≥ 26)のうち遮蔽範囲に入るもの。**その数は `_v4` の `cov26_wide` と1画素も違わないこと**(IC1)
- **深さ d** = 覆われた画素から、**遮蔽範囲の外の最も近い画素**までのユークリッド距離(画素の中心どうし、px)。
  輪郭に接する画素が d = 1。**キャンバスの端は輪郭に数えない**(全面の遮蔽物の下は d = 「輪郭なし」)
- **層の主値 `near_T`** = 覆われた画素のうち d ≤ T の割合
- **T = 16 px を主にする**。8 と 32 を隣に印字する。**T の理由**: 線の太さは数 px で、「いくらか食い込む」を
  その数倍と置いた。**作者の数ではない** —— 下の「動く錨」で引き直す
