前の走行の被覆率(線画の層の中央値 0.0614)は、**食い込み**と**予定外の遮蔽物の下に描いた線**の和で、
両者を分けない。**この走行は両者を分ける。** 描かなかった線は画素が無いので、ここでも測れない(下の「決められないこと」)。

## Question

**線画の層の、遮蔽物に覆われている描画画素は、遮蔽物の輪郭のすぐ内側に集まっているか。**

- 集まっている → その層は**遮蔽物を知って描いた**(食い込みだけが覆われている)
- 奥まで一様に広がっている → **知らずに描いた**(予定外の遮蔽物の下に線が在る)

層ごとにどちらかが言えれば、K・L・M は「線が途切れている理由」を層単位で割れる。

## 量の定義

ある線画の層 L について:

- **遮蔽範囲** = L より手前の `wide` 遮蔽物の遮蔽範囲の和(`_v4` の規則そのまま。作業用の層は入れない。
  クリップは今の読み手のまま = 合成しない。下の但し書き)
- **覆われた画素** = L の描画画素(アルファ ≥ 26)のうち遮蔽範囲に入るもの。**その数は `_v4` の `cov26_wide` と1画素も違わないこと**(IC1)
- **深さ d** = 覆われた画素から、**遮蔽範囲の外の最も近い画素**までのユークリッド距離(画素の中心どうし、px)。
  輪郭に接する画素が d = 1。**キャンバスの端は輪郭に数えない**(全面の遮蔽物の下は d = 「輪郭なし」)
- **層の主値 `near_T`** = 覆われた画素のうち d ≤ T の割合
- **T = 16 px を主にする**。8 と 32 を隣に印字する。**T の理由**: 線の太さは数 px で、「いくらか食い込む」を
  その数倍と置いた。**作者の数ではない** —— 下の「動く錨」で引き直す

## Arms

| 腕 | 中身 | 何のためか |
|---|---|---|
| **R 実測** | 実際の遮蔽範囲で d を数える | 本番 |
| **S 帰無値(主)** | **L の遮蔽範囲を平行移動**して同じ量を数える。5回、移動量は向きが一様・長さが 64〜512 px で一様。seed を記録する。キャンバスの外に出た範囲は捨てる | 線と輪郭の**位置合わせ**だけを壊す。線の形と遮蔽物の形は保つ |
| **U 解析的な期待値(併記、主ではない)** | 遮蔽範囲の中の全画素の d の分布(線がそこに一様に在ったら) | S と U が大きく違えば、線の分布そのものが寄っている印 |

**S と U を同じ「帰無値」の語で並べない**(改訂5 §4 の教訓)。採点の表に、どれかを列で書く。

## Pass criteria

**E1 覆われた線は輪郭に寄っているか**(主)。
棒: **層ごとの `near_16`(R) − `near_16`(S の5回の中央値)の、層の中央値が +0.10 以上。**
帰無値は S。**S の5回のどれかで届かなければ判定保留**(前の記録21 §1 の形)。

- 超えた → 覆われた線の多くは食い込みである。作者の工程の前半(知っていれば描かない)と合う
- 届かない → 覆われた線は輪郭に寄っていない。**作者の工程の否定ではない** —— 描かなかった線は測れないので、
  「知って描いた層」が少なく、覆われた画素の多くが予定外の遮蔽物の下に在る、とまでしか言えない
- 向きが逆(R が S より輪郭から遠い)→ **まず器具を疑う**(d の符号・輪郭の取り方)。読まずに IC を見直す

**E2 層は2つの群に分かれるか**(記述。棒ではない)。
層ごとの `near_16`(R)を **≥ 0.8 / 0.2〜0.8 / ≤ 0.2** の3帯で数えて印字する。
**この帯は作者の確認の前の仮の名前**(「知って描いた」「知らずに描いた」と呼ぶのは第2段の後)。

**0.10 の理由**: 前の走行の棒 0.05 の2倍。S の5回の散らばり(走行の後に印字)より小さい差は読まない。

## 但し書き(走行の前に書く)

1. **クリップを合成しない**: 測る層の 49.9% に効く。範囲が広すぎるので、**輪郭が実物より外に在り、d は大きく出る側** —— E1 に不利な向き。届かなかった場合は、クリップを含まない層の行で読む
2. **描かなかった線は測れない**: この走行が見るのは描かれた線だけ。「知って描かなかった」の量は出ない
3. **遮蔽物の正体は問わない**: 予定外かどうかは第2段で作者が決める(規律6)

## 決められないこと

- 作者が描くのを省いた線の量(画素が無い)
- 遮蔽物が描く前から在ったか後から足したか(制作の順。ファイルに無い)。第2段の問いはこれを作者に聞いている
