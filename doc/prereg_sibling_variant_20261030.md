## Question

**兄弟ファイルで空になった層の集合は、構造の上でまとまっているか** ——
すなわち**別案の系統(兄弟フォルダー)が丸ごと空になる形**か、それとも**散っている**か。

**「いいえ」で答えられる。** 散っていれば、削除は系統の選択を記録していないので、
**(b) は正解源にならない。**

## Primary value

**まとまり率 `agg`**(対ごとに1つ):

```
emptied = { layer_id : base で n_drawn26 > 0 かつ var で n_drawn26 == 0 }
whole   = { emptied のうち、親フォルダーの「base で描かれた子孫」が全部 emptied に入るもの }
agg     = |whole| / |emptied|
```

- **層で数える。面では数えない**(この測定の単位は層である)
- **対ごとに印字する。プールしない** —— **作品でプールしない / 年でプールしない**
  (世代もプールである)。**中央値を書くときは対ごとの列を隣に置く**(規律12)
- **層が計測の対象外のものは分母にも分子にも入れない。理由別に数えて印字する**(条例 項7)

### 恒等の申告

**「全部やる」腕の `agg` は 1.0 になる。** フォルダーを粗くすれば必ず上がるので、
**`agg` 単独では良し悪しが決まらない。** だから **C1 は帰無値との差で判定し、
`agg` の絶対値だけでは合格にしない。**

## Pass criteria

**N1(置換の帰無値)**: base で描かれた層から **`|emptied|` と同じ数を無作為に選び**、同じ式で
`agg_null` を出す。**対ごとに 1,000 回**。棒は **`agg` > `agg_null` の 95 パーセンタイル**。

- **C1 —— 構造のまとまり。** **S1 の全対で、`agg` が N1 の 95 パーセンタイルを超え、
  かつ `agg` > 0.5。** **判定は最悪の対で行う**(**規律11: 連言の棒は最悪の値で判定する**。
  最良は「最良」と名乗らせる)
  - **超えた** → **削除は系統の選択を記録している。(b) は正解源として進める**
  - **超えない(`agg` が帰無値の中)** → **削除はフォルダー単位ではない。(b) は正解源にならない** ——
    **書き出し画像の道も 6/8 で届かないので、差分の正解は手元のデータからは取れないと書く**
  - **`agg` > 0.5 を満たさないが帰無値は超える** → **「まとまりは在るが支配的ではない」。
    判定保留。(b) を単独の正解源にはしない**
- **C2 —— 覆う範囲。** **S1 の対が乗る頁が 20 頁以上。**
  - 理由: **登録集合は8頁**で、**差分だったのは5頁**。この道が登録集合を直せるには、
    **少なくとも登録集合と同じ桁の頁に乗っていなければならない。**
    20 は「8頁の倍以上」で、**走る前に書いた**
  - **満たさない** → **(b) は `P0444`/`P0446` の個別の説明に使えるだけで、
    標準の作り直しには使えない。** `census` に全頁の構造の列を頼むかを別に決める
- **C3 —— 既存の道具だけの腕。** `visibility` の腕の再現率が **0.05 未満**であること。
  - **満たさない** → 追補129 の「`visibility` に組は記録されていない」が揺らぐので、
    **先にそれを測り直す**(この走行の読みは止める)

**どの結果でも何も変わらないなら、測る前にやめる** —— 上の3つは、**(b) を正解源にするか・
`census` に発注するか・差分の正解を諦めるか**を分ける。
