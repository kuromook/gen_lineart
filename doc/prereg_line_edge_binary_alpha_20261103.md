# 登録 —— 線の縁(アンチエイリアス)は、原稿の層のアルファ2値から来ているか(2026-11-03)

**この角度を今やる理由**: 第2段の後の下見(`doc/result_process_stage2_20261101.md` §5)で、
**線画タイルの灰の中間画素(128〜220)がほぼ無い作品が8作**見えた。`census` の答え
(`inbox/reply_n_line_binary_alpha_20261102.md`)は **「8作の線画層はアルファ2値の層を多く持つ。
ただし頁ごと2値の頁はほぼ無い」**。**ユーザーの指示(2026-11-03)**: 「マスク(=面)調査にも効く
要素なので調べてほしい」。**判定の単位はタイル1枚。絵は判定しない。良さは言わない。**

## 既に見たもの(**走る前に見えていたことを書く**)

- **作品ごとの** `faint_of_drawn_ratio` の中央と「0 のタイルの割合」(31作。結果 §5 の表)
- **作品ごとの**「アルファ2値の層の比 / 2値の層の画素の比 / 縁の画素の比」(`census` の表1)
- **だから作品の間の対応(8作は両方で寄っている)は、もう見てしまった。棒には使わない。**
  **主値は作品の中の、頁の間の対応**にする —— こちらは**どちらの側も頁単位では見ていない**
- 結合の数だけは数えた(点数は見ていない): 下の IC3

## Question

**同じ作品の中で、線画の層のうちアルファ2値の層が描く画素の割合が高い頁ほど、
その頁から切ったタイルに灰の縁が無い(`faint_of_drawn_ratio = 0`)か。** —— 「いいえ」で答えられる。

## 材料

- **x(頁)** = `census` の層の表(`line_binary_alpha_layers_for_n_20261102.csv`、43,501行、sha256 添付)で、
  その頁の線画層について **Σ(2値の層の `n_px_alpha_gt0`) / Σ(全層の `n_px_alpha_gt0`)**
- **x2(頁)** = **Σ`n_px_partial_alpha` / Σ`n_px_alpha_gt0`**(縁の画素の比。x の裏側)
- **y(頁)** = その頁から切った線画タイル(第2段のプール、白点を揃えた後)のうち
  **`faint_of_drawn_ratio == 0` の割合**。値は第2段の `profile_s2.csv` をそのまま使う(測り直さない)
- **結合**: タイルの (作品, 頁ファイル名, 群名の中のサブフォルダー) ⇄ 層の表の `page_path`。
  サブフォルダーは群名の `__<sub>__<page>` を `\`→`_`、根を `root` として突き合わせる

## Primary value

**作品ごとに、頁の間の Spearman ρ(x, y)。読む値 = ρ の作品の中央。プールしない。**
**母集団 = 結合できて、タイルのある頁が 8 以上、かつ y が頁の間で一定でない作品。**
(y が全部 0 か全部同じ作品では ρ が定義できない。**外した作品は理由ごとに数えて印字する**)

## 帰無値(**棒の前に印字する**)

**作品の中で x を頁の間で置換**(作品をまたがない)、**10,000回**、同じ読む値を作る。
片側 p = (帰無 ≥ 実測 の数 + 1)/(10,001)。作品ごとの ρ にも同じ置換で 2.5〜97.5% を付ける。

## Instrument checks(IC)

- **IC1 走行の外から知っている値(x の側)** —— 結合する前の層の表から、作品ごとに
  **「2値の層の画素の比」**を全頁で計算し直すと、`census` の表1と **±0.001** で一致する
  (`ako5` 0.225 / `copy` 0.551 / `pink` 0.240 / `ako6` 0.156 / `ben` 0.038 / `fringe` 0.053 /
  `fringe3` 0.063 / `succor` 0.029)。**外れたら走行を読まない**
- **IC2 走行の外から知っている値(y の側)** —— 作品ごとの「0 のタイルの割合」が結果 §5 と
  **±0.005** で一致する(`copy` 0.63 / `pink` 0.68 / `ako5` 0.45 / `ako6` 0.65 / `ben` 0.74 /
  `fringe3` 0.55 / `succor` 0.59 / `fringe` 0.40)
- **IC3 結合の数**(下見で数えた、点数ではない): 2016〜2019 の19作は**ほぼ全部結合する**
  (`2017/ako5` は 448 のうち **34枚が頁名の形が違って結合しない** —— 数えて外す)。
  **2020 以降の11作は層の表に頁が無い**(`census` の材料の範囲外)→ 外して数える。
  `2024b/fitness` は結合する(226)。**結合しなかった枚数を作品ごと・理由ごとに印字する**
- **IC4 縮小が灰を作っていない** —— タイルの `src_per_out` は**31作 5,597枚すべて 1.0**(下見)。
  **タイルの段では再標本化が無い**ことを走行の中でも数えて印字する。**コマを切る前の段は分からない**(下記)

## Negative controls(NC。**名のある1つの誤り**と**いま書く期待値**)

- **NC1 墨の量** —— x の代わりに **頁の線画層の画素の総数 Σ`n_px_alpha_gt0`**。
  誤りの層: 素性の取り違え(「2値」ではなく「描いた量」を見ている)。
  **期待は書けない。読み方を先に書く**: **|ρ(NC1)| ≥ |ρ(主)| なら「2値」とは名乗らない**
- **NC2 頁をずらす** —— 作品の中で頁を番号順に並べ、**x を隣の頁のものに付け替える**。
  誤りの層: 結合。**期待: 主より小さい。** 主と同じ大きさなら、**対応は頁ではなく
  「何頁かまとまった単位」(章・作業の時期)の話**で、頁の単位では名乗らない
- **NC3 裏側** —— x2(縁の画素の比)で同じ読み。**期待: 主と逆向き(負)**。
  同じ向きなら器具か結合が壊れている → 走行を読まない

## Pass criteria(C。**結末の意味まで書く**)

- **C1 対応が見える** —— **読む値 ≥ 0.30** かつ **帰無の 97.5% を超える** かつ NC1・NC3 が上の条件を満たす
  → **「タイルに灰の縁が無いのは、原稿で線画の層がアルファ2値の頁で起きる」。**
  **書き出し・抽出で灰が落ちたのではない側の証拠**として書く。
  **この track での仕分け**: `faint_of_drawn_ratio`(と `faint` 系の軸)は**「道具・層の性質」で
  説明できる側**に入れる —— **作者の線の情報として読まない**
- **C2 届かない** → **「頁の単位では対応が見えない」**まで。**「2値の層とは無関係」とは書かない** ——
  頁の中で2値の層と縁の在る層が混ざっているので(`census`)、**タイルの範囲にどちらが描いているか**
  まで降りないと届かない可能性が残る。**次の手は層の範囲(bbox)を `census` に頼むこと**
- **C3 墨の量だった** —— NC1 が主以上 → **「描いた量」**と書き、2値とは名乗らない
- **C4 器具が壊れている** —— NC3 が主と同じ向き、または IC1/IC2 が外れる → 何も読まない
- **C5 判定保留** —— 母集団が **6作未満**、または作品ごとの ρ の帯が 0.60 を超える作品が半分以上
  → 「判定保留」と書き、**何頁・何作足せば足りるかを数で書く**

## 費用

結合と集計だけ。**AUC は使わない。数秒。CPU のみ。**

## What this run cannot settle

- **コマを切る前の段で縮小されたかどうか** —— 作者側のタイルは**縮小した元コマから切った**(条例5)。
  タイルの段で 1.0 でも、その前に再標本化があれば灰は作られうる。**この走行は頁の中の対応しか見ない**
- **ペンの設定そのもの** —— ラスタの層にブラシの参照は残らない(`census`)。**「アンチエイリアス無しのペン」
  とは名乗らない。** 名乗れるのは **「層のアルファが2値」**まで
- **タイルの範囲にどの層が描いているか** —— 頁単位の x は、タイルの外の層も含む(減衰する)
- **2020 以降の11作**(層の表に無い)
- **マスク(面)の層** —— この材料は**線画の層だけ**。**面の調査に効くかは、同じ表を面の層について
  `census` に頼まないと言えない**(ユーザーの指摘。照会は別便で出す)
- **「作者の線画の方が良い」とは言わない。** 縁の有無は良さではない
