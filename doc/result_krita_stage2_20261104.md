## 4. 事後の探り(**登録に無い。棒を持たない。判定を変えない**)

原寸の切り出し(`results/krita_stage2_20261104/_crops/`、C4 の 15 タイルは避けた)で、`sketchy_inv_s1` は
**線を書き直すのではなく、ラフ全体を薄くぼかしているように見えた**(Claude の読み。何が描かれているかは作者が決める)。
D は出力のエッジ地図(Canny 45/135)で数えるので、**一様に薄くするだけで、薄い線から先にエッジが消える**かもしれない。
そこで、ラフのコントラストを一様に落とす腕 `255 − (255 − g)·k` を、同じ分解・同じ帰無の相手で採点した。

| lineart 系 | D′ | a | c | neither |
|---|---:|---:|---:|---:|
| fade k = 0.7 | 0.0797 | 0.702 | 0.623 | 0.031 |
| **fade k = 0.5** | **0.1139** | 0.537 | 0.425 | 0.014 |
| fade k = 0.35 | 0.0757 | 0.218 | 0.144 | 0.006 |
| fade k = 0.25 | 0.0068 | 0.015 | 0.008 | 0.027 |
| (比較)`sketchy_inv_s1` | 0.1099 | 0.555 | 0.445 | 0.018 |

housei では、どの k も D′ は負(−0.004〜−0.020)。

**読み**: 登録の C1 を満たした `sketchy_inv_s1` の値は、**モデルを使わない画素ごとの減光で再現される**(k を 4 つ振った中の最良なので、
ここにも選択がある)。したがって、C1 の文言が通過に与えた意味「**前処理器の線を選んで消している**」はこの値からは支えられない。
**言えるのは一段弱いこと**: lineart 系では、**GT に無い前処理器の線(C)はラフの中で薄い**。濃さだけで A と C が部分的に分かれる。
これは Krita についてではなく、**手元の対の性質**である(housei では成り立たない)。
**登録の不備として記録する**: 自明な腕に「濃さの一様な変換」を入れていなかった。線の誤りの条項(`rough` / `rough_otsu` が C1 を満たす)は
**発動していない** —— 減光は条項に名前が無いので、条項を後から広げて発動させることはしない。両方をここに書く。

## 5. 判定(登録の言葉で)

- **lineart 系**: 見出しの2腕は**保留**(D′ 0.061 / 0.056、8/8)。`sketchy_inv_s1` は **C1 と C2 を満たし、C3 は満たさない**
  (b 0.057 は帰無の 0.136 より低い → 想定どおり、21 px では B を描かない)。**ただし §4 により、通過の意味は「選んで消す」ではなく
  「一様に薄くするのと同じ」**。保留帯の値は NC2(壊れた向きの出力)と減光でも出るので、保留の腕はどれも区別がつかない

- **段3 の根拠**: 登録上は lineart の `sketchy_inv_s1` が根拠になりうる(21 px の Sketchy で通過)。しかし §4 で、
  **受容野 0(画素ごと)の減光で同じ値が出る**。Krita の重みが減光の上に足したものは、この主値では見えない。
  **段3 に進むかはユーザーの判断**(基盤経由)。Claude の推奨は、**この主値のままでは段3 の根拠にしない**こと
