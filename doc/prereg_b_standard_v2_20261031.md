## R3 の実装(**資料の判定。フォルダー段は足さない = R5**)

> **資料の層 = `v_layer_kind == image_material`**
> **∨(`layer_type & 4096` でない ∧ 矩形度 >= 0.95 ∧ 外接箱が全画布でない)**

**矩形度 = 覆いの面積 ÷ 外接箱の面積**(アルファ >= 26)。**分布は測ってある**(追補155 §A、**`T-M29`**):
葉 420 の矩形度は**最小 0.000 / 中央 0.316 / 最大 1.000**、**>= 0.95 は 110 枚、

**取りこぼしは 1 枚**(`<資料>` の `レイヤー 1`。追補156 §C)。**R5 により拾いに行かない。
落ちた1枚は走行で印字する。**

**穴**(条例6): **6頁の可視・非用紙の層のうち、納品の層種別の表に当たらない行が 93**。

## R4 の実装(**案イ**)

> **`下絵` / `sketch set` / `下描` を名前に含むフォルダーの子孫を除外する。**
> **ただし `線画` の層(作者の分類)は除外しない。**

**理由**(追補157 §B): **`page0002` の `線画` の可視の葉 6枚が全部 `sketch set` の中に在る。**
**丸ごと除外すると、その頁は線画0枚になり母集団から落ちる。**
**案イ なら線は残り、中の資料だけ落ちる。**

**走行で印字する**: 除外した層の数(頁ごと)/ **`線画` だから除外しなかった層の数**。

## Primary value

- **分布は走る前に測ってある**(追補153 §D、**`T-M29`**。**9面しか見ていない**):
