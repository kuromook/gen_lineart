# 登録: 生成器を Forge から ComfyUI に替えると、軸は動くか(2026-11-07)

**状態**: このコミットで閉じる。変えるなら点数を読む前に、時刻つきの修正として末尾に足す(規律10)。
**きっかけ**: ユーザーが画像生成を ComfyUI に寄せたい(2026-11-07)。同じ設定・同じ seed で ComfyUI は Forge と別の画像を出した
(`work_log` 2026-11-07、画素の相関 0.008〜0.024)。ユーザー:「一応測っておこう 合わせられるなら扱いやすいはずだ だめならだめでいい」。
**言わないこと**: どちらの線画が良いか。どちらの生成器が良いか。**作者由来の箱には、この走行のどの結果でも入れない。**

## Question

**同じチェックポイント・プロンプト・seed・サンプラー・step・CFG・解像度で、生成器だけを Forge から ComfyUI に替えたとき、
軸ごとの `AUC₂₃`(作者のデジタル線画 対 外部)は、seed を変えたときより大きく、帰無の帯の外まで動くか。**
「動かない」と答えられる。**運用の問い**: ComfyUI のプールを、Forge のプールの代わりに基準の外部側として使ってよいか。

## 器具(固定)

  **ComfyUI 側の設定(ノイズの作り方・プロンプトの重みの解釈など)を、点数を見てから合わせ直さない。** 合わせ直すなら別の角度として登録する
- **切り出し以降は第3のプールと同じ道**: `build_external_tiles.py`(同じ窓と割り当て、墨の門 `0.011992`)→
  `prepare_normalized.py`(白点を揃える。条例2)→ `measure_lineart_profile.py`
- **読み取り**: `tools/external_standard/generator_angle.py`。CFG の角度の `cfg_angle.py` と同じ作り(N2・N1・判定式)を2モデルに広げたもの

## Primary value

**軸ごと・モデルごと(k = E, I)に `Δ_g = AUC₂₃(Gk) − AUC₂₃(Fk)`**(Gk = EC/IC、Fk = E6/I6)。定義は第3のプールと同じ
(A2 = 1 / 外部 = 0、タイル1枚が単位、tie は 0.5)。**モデルは畳まない。軸も畳まない。** 副: `AUC₁₃` の Δ と、`AUC(Gk 対 Fk)` そのもの。

## 帰無値(棒の前に印字する)

- **N2 対の入れ替え**: プロンプトごとに、Gk と Fk のタイルをプロンプト単位で確率 1/2 で入れ替え、Δ を計算し直す。1,000回、帯 2.5〜97.5%
- **N1 seed**: `Δ_seed = AUC₂₃(S1k) − AUC₂₃(Fk)` —— 同じ生成器で seed だけ変えたときに動く量(1点)

## Instrument checks

- **IC1 決定性**: 本番の先頭2本(2モデル)が、2026-11-07 の確認で作った ComfyUI の画像(`data/external_comfy_check_20261107/gen_*_comfy/`)と画素で一致。
  外れたら印字し、**N1 を主な帰無値として扱う**(CFG の角度と同じ扱い。今決めた)
- **IC2 再現**: この器具の `AUC₂₃(E6)`・`AUC₂₃(I6)` が第3のプールの表(`auc_three_arms_*.txt`「軸ごと」)を 12軸すべて ±0.0001
- **IC3**: 自分自身との AUC が 0.5000
- **IC4**: EC・IC のタイル数と、落ちた数を理由別に印字する
- **PC 陽性対照**: 同じ器具で `Δ(E9) = AUC₂₃(E9) − AUC₂₃(E6)` の `deep_black_ratio` が CFG の角度の値 **−0.2239** を ±0.0001 で再現し、
  かつこの角度の C1 の式で ○ になる(設定の違いを器具が見えることの確認。**発見ではない**)
- **NC1**: N2 の中央が全軸・両モデルで `|·| < 0.02`

## Pass criteria(軸ごと・モデルごと)

- **G1 生成器で動く**: `|Δ_g| ≥ 0.10` かつ N2 の帯の外 かつ `|Δ_g| > |Δ_seed|`(CFG の角度の C1 と同じ式)
- **G0 揃う**: `|Δ_g| ≤ max(0.05, |Δ_seed|)`。0.05 は第3のプールの `C1_NEAR` を借りた定数で、ここでは
  **「seed の揺れの大きさの目安」**の役に引き直す(CFG の角度で `|Δ_seed| ≤ 0.026`)
- その間 → **小さく動く**(印字のみ)
- **C4 外部側が1回の引きで安定しない**: `|Δ_seed| ≥ 0.10` の軸が 3本以上(どちらかのモデル)→ 判定保留
- **C5**: IC2・IC3・PC・NC1 のどれかが通らない → 何も読まない

### 運用の判定(ユーザーの問い)

| 結果 | 書くこと |
|---|---|
| **12軸(`ink_ratio` を含む)すべて、両モデルで G0** | **「ComfyUI のプールは Forge のプールの代わりに使える(この2モデル・この設定で)」**。ただし既存のプールと混ぜない(1つのプールは1つの生成器) |
| G1 が1本以上 | **「代わりに使えない」**。ComfyUI のプールは別の生成器として、自分の基準点と一緒にだけ使う。動いた軸を名前で書く |
| G1 は無いが G0 でない軸がある | **「近いが同じではない」**。代わりには使わず、その軸を名前で書く |

**離散2軸**(`line_width_p50`・`width_consistency`)も運用の判定には数える(仕分けではないので条例4の除外は掛けない)が、tie の構造を隣に印字する。
