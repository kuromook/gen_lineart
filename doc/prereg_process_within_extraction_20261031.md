# 事前登録 —— **同じ抽出の中で、線画の工程は編より大きくタイルを分けるか**

書いた日: **2026-10-31**(**どの数も見る前**)。走る器具: `tools/external_standard/process_within_extraction.py`。
材料: 抽出 `line_clip_pairs_v3_koma_20260826` の **11作 2,947枚**(作者の段階ごとの裁定つき、
`doc/author_process_rulings_20261031.md`)+ **既に測ってある外部2プール**。
**判定の単位はタイル1枚。この track は絵を判定しない**(条例)。

## Question

**作者の裁定した「線画の工程」(アナログ / デジタル)は、同じ抽出・同じ器具の中で、
「編」や「作品」より大きくタイルを分けるか。** —— **「いいえ」と答えられる**:
工程をまたぐ対と工程が同じ対の距離が、作品ラベルを入れ替えた帰無の帯の中に収まれば「いいえ」。

## 抽出を1本に固定する理由

いままでの比較(`doc/result_ako_series_20261031.md`)では **編・工程・時期・抽出経路が一緒に動いていた**。
この走行は**抽出経路を `clip_pairs_v3` の1本に固定**して、交絡を1つ減らす。
**時期は固定できない**(下の §交絡)。

## Arms(= 対の群。腕は「対」であって「モデル」ではない)

11作のすべての対 **55対**を、**作者の裁定だけ**で4つのセルに分ける。
工程 = 線画の段階。デジタル8作 / アナログ3作。編 = `census` の編の表(系外は「未割り当て」)。

| セル | 定義 | 対の数 |
|---|---|---:|
| **S1** | **工程が同じ・編が同じ** | **9** |
| **S2** | **工程が同じ・編がちがう** | **22** |
| **S3** | **工程がちがう・編が同じ** | **10** |
| **S4** | **工程がちがう・編もちがう** | **14** |
| **S5** | **外部との対**(11作 × `animagine` / `illustrious`) | **22** |

**既定の腕(moat-register の既定)をこの題材に写したもの**:
- **何もしない** = **NC1 自己 AUC**(同じ作品を両側に置く)。**恒等で 0.5000 ちょうど**
- **全部やる** = **S5**(外部との対)。**天井の参照**で、作者どうしがここに届くかを見る
- **既存の道具だけ** = **単軸 AUC 12本**(多変量を使わない読み)。各対で最大 |AUC−0.5| を印字
- **学習なしの頻度表** = **時期距離だけの線形回帰**(NC4)。作品の属性を1つも使わない

## Primary value

**対ごとの多変量 AUC** —— F9 の9軸・L2 ロジスティック回帰・**群単位の5分割**
(群 = 小領域、`digest_mod` で固定。`multivariate_transfer.py` の `multi_cv` をそのまま使う。
`C` は実データの折の中で選び、**帰無には実データが選んだ `C` を渡す**(第3プール登録 §費用))。
**セルごとの中央値**を主値とし、**プールしない**: 対ごとに1行、セルごとに中央・最大・最小を印字する。

**読む差は2つ**:
- **D(工程) = 中央(S3) − 中央(S1)**
- **D(編) = 中央(S2) − 中央(S1)**

## 時期の交絡と、**matched の部分集合**(先に書く)

**アナログ線画の3作はすべて 2024 系**なので、工程をまたぐ対は時期も離れている。
**札の順序を先に固定する**: `2015, 2016, 2017, 2018, 2019, 2019b, 2020, 2020b, 2021, 2022, 2022b, 2023b, 2024, 2024b, 2024c`(索引 0〜14)。**時期距離 = 索引の差の絶対値。**

- **時期距離の中央(走る前に数えた)**: **S1 = 2 / S2 = 6 / S3 = 4 / S4 = 10**。
  **S2 も S3 も S1 より時期が離れている** —— **編の差も時期と交絡している**
- **だから素の D で工程も編も名指ししない。** 名指しに使うのは **matched = 時期距離 ≤ 3 の対だけ**:
  - **S1m 9対**(S1 はもともと最大3)
  - **S3m 3対** —— `akocultB × ako3B` 1 / `akocult × ako3B` 2 / `akocultB × 2024c/ako` 3
  - **S2m 6対** —— `ako5 × running` 0 / `running × ako6` 1 / `ako6 × succor` 1 /
    `ako3B × fitness` 1 / `fitness × 2024c/ako` 1 / `ako5 × succor` 2
- **3対・6対しかないことを結論に必ず書く。** 足りないなら「判定保留」に落とす(§Pass criteria C5)

## 帰無値(**棒の前に印字する**。2段ある)

1. **対ごとの帯** —— 群単位でラベルを置換(多変量 50回、`C` は実データのもの)+ 群単位の bootstrap
   (1,000回)。**帯の幅が 0.30 を超えた対は「帯が足りない」と印字**(`ako` 系の走行と同じ境)
2. **セルの差の帰無 = 作品ラベルの交換**(**この題材の正しい単位。裁定は作品ごとに与えられた**)
   - **工程**: 11作のうち3作を「アナログ」に選ぶ **全 165 通りを数え上げる**(近似ではなく厳密)。
     **編と時期は動かさない。** 各通りで D(工程) を再計算し、**実測の順位から片側 p を出す**
   - **編**: 編の多重集合 {学祭2, fanbox6, 系外3} の **全 4,620 通りを数え上げ**、D(編) について同じ
   - **matched も同じ交換で**(時期距離 ≤ 3 の対だけを使って D を計算する)
   - **対ごとの AUC は再計算しない** —— ラベルの交換はセルの割り当てだけを変えるので、費用はゼロ

## Instrument checks(IC)

- **IC1** 同じ作品を両側に置いた AUC。**期待 0.5000 ちょうど**。外れたら走行全体を読まない
- **IC2** **この走行の外から既に知っている値**: `doc/result_ako_series_20261031.md` の
  **学祭編どうしの多変量 中央 0.8947 / 最大 0.9972**。同じ器具・同じ CSV の A2 行で再計算し、
  **許容 5e-4 で一致**(既知値は4桁で印字されている)。一致しなければ器具が変わったので読まない
- **IC3** 11作のタイル数・群数・頁数が裁定の表と一致する(448/483/229/188/130/247/192/83/491/230/226、群 981)
- **IC4** **門で落ちた数を作品ごとに印字する**(`ink_ratio < 0.011992`)。**門は動かさない**
- **IC5** 正規化の前後で紙の水準(最小・中央・最大)を作品ごとに印字

## Negative controls(NC。**それぞれ名のある1つの誤り**と、**いま書く期待値**)

- **NC1 恒等** —— 同じ作品を両側に置く。誤りの層: 対の構成。**期待 0.5000**
- **NC2 群を壊す** —— ラベルをタイル単位で置換(小領域をまたいで混ぜる)。
  誤りの層: 独立性の単位。**期待: 帯が 0.30 より狭くなり、帰無の中央が 0.5 から上にずれる。**
  発火が正常 —— これが群単位で測る理由の対照
- **NC3 機材** —— デジタル8作を **「iPad と明記」4 / 「未記載」4** で分け、同じ交換検定を当てる。
  誤りの層: 工程というラベルの中身。**期待は書けない(分からない)。だから先に読み方を書く** ——
  **発火したら「工程」の読みは機材と交絡する**と結論に書き、工程の名指しを取り下げる
- **NC4 時期だけ** —— 対の多変量 AUC を**時期距離だけ**で線形回帰。傾き・R²・p を印字。
  誤りの層: 属性を使わない予測。**期待: 傾きは正**(札が離れると遠い)。
  **R² が 0.30 を超えたら、素の D(工程) は時期の言い換えだと結論に書く**
- **NC5 枚数** —— タイル数が最小(`2024/ako3B` 83)と最大(`2019/succor` 491)の対。
  誤りの層: 枚数の偏り。**期待: AUC は枚数に不変なので、この対が特別高くはならない**
  (高ければ器具が枚数を読んでいる)

## Pass criteria(C。**それぞれの結末が何を意味するかまで書く**)

- **C1 工程が見える** —— **matched の D(工程) ≥ 0.05** かつ **工程の交換の帰無の 97.5% を超える**
  → **「同じ編・近い時期でも、線画の工程でタイルは分かれる」。** NC3 が発火していないときだけ
  「工程」と名乗る(発火していれば「工程または機材」)
- **C2 編が見える** —— **matched の D(編) ≥ 0.05** かつ **編の交換の帰無の 97.5% を超える**
  (素の D(編) も印字するが、名乗るのは matched の側)
  → **「工程を固定しても編は見える」。** `ako` 系の C-A(+0.1037)の、交絡を1つ外した再試験
- **C3 どちらも帯の中** → **判定保留。** **この設計では作者の裁定が画素に映らない** ——
  **その場合に疑うのは、裁定ではなく器具と母集団の側**(12軸は工程を映す軸を持っていないかもしれない)
- **C4 外部の床** —— **min(S5) ≤ max(作者どうし)** なら、`ako` 系の **C-D** が抽出を固定しても再現する
  → **「作者の中の距離が、作者と外部の距離を超えることがある」**。超えなければ C-D は抽出経路の産物
- **C5 判定できない** —— **matched の対の帯が1つでも 0.30 を超える、または S3m が3対のまま**
  → **「工程については判定保留」**と書き、**次に何作足せば足りるかを数で書く**。**編も同じ(S2m 6対)**
- **この行で全体が倒れる結末**: **C3 かつ NC4 の R² > 0.30** →
  **「12軸は工程ではなく時期を読んでいる」** ので、**工程を軸の仕分けに使う計画そのものを取り下げる**

## 費用

対 55 + 外部 22 = **77対**。1対あたり 単軸帰無 1,000回・多変量 5折・bootstrap 1,000回・
多変量帰無 50回。`ako` 系の 31対が 1,242秒だったので **見込み 60〜90分、CPU のみ、GPU 不要**。
**ラベル交換の帰無(165 + 4,620 通り)は AUC を再計算しないので費用はゼロ。**
