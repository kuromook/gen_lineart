# L39 登録 — **線の層だけから、作者の塗りの面を取り出せるか**(学習した腕。2026-11-08、走る前)

**初期の問い**(起案 §1、逐語):
> **人は輪郭を見てどの面が塗られるか分かる。安価な閉じ処理では取り出せない。
> では何なら取り出せるかは未測定。**

**この登録はその問いへの腕を1本だけ立てる。** 腕の種類はユーザーが選んだ(2026-11-08、
「線→ベタの学習モデル」)。**10-23 以降に採点したのは汚れを見つける腕だけで、
どの面が塗られるかを当てる腕はこれが L18 の後で初めてである。**

## §1 問い

**線の層(塗りの層を含まない)だけを見せた分割モデルは、作者の塗りの面を取り出すか。**

- 単位: **面**。標準は **分離後の面プール 656**(`results/l38_faces_separated_20261108.json`、
  ako6 212 / ako7 444。16 頁 + 24 頁、コマ枠ファイル 50 + 36)
- **面の床 6,000 は予測の側にも当てる**(予測の連結成分が 6,000 未満なら小片。**捨てない。数を印字する**)
- これで決まること: **輪郭だけで面が取り出せるなら、塗りの面は輪郭の側に情報として在る。
  取り出せないなら、この規模・この定式化ではそれを示せない**(どちらも §6 の形で書く)

## §2 腕(**全部同じ面・同じ照合で採点する**)

| 腕 | 中身 | 何のため |
|---|---|---|
| **腕0 塗らない** | 予測なし | **帰無値**。recall 0 |
| **腕1 全部塗る** | コマ成分そのものを1つの予測とする | **自明な腕**。コマの大半を占める面だけが当たる |
| **腕C 写す** | 入力(線の層の墨)に `fill_mask(radius=4)` を当てた成分 | **入力に塗りが既に在るか**。線の層に紛れた塗り(`keep4` の門の下)はここで拾われる |
| **腕M 学習** | 線の層 → 塗りの U-Net(下)。**作品を跨いで学習と試験** | **本体** |
| 天井 | 標準 `F ∩ P` そのもの(2値の面) | **2値のマスクで届く上限**。割った片 105 は親の中で隣り合うので、2値では分けられない。**棒ではない。上限として印字する** |

**腕M の中身(全部ここで固定する)**:

- **入力**: `arms('gated')` の **line 側の層**の墨(`< 128`)の和。**fill 側の層は1枚も入れない**
  (`keep4` の二分なので交わらない。交差の数を印字し、0 でなければ走らない)
- **標的**: `arms('gated')` の fill 側の層の `fill_mask(radius=4)` の和 `F`(= 面プールの作り方そのもの)
- **解像度**: 頁を **1/4** に縮める(`INTER_AREA`。入力は墨の濃度として連続値、標的は 0.5 で2値化)。
  **線の半幅の中央は 2 画素**(`l38_line_halfwidth_20261108.py`)なので 1/4 で幅 1 画素前後の濃淡として残る。
  **閉じるための縮小ではない**(扉3 は縮小で輪郭が閉じるかを測った)
- **損失**: コマ成分の中だけで BCE + soft Dice(コマの外は無視)
- **網**: 素の U-Net(5段の縮小、基底 32 チャンネル、BatchNorm、ReLU)。**事前学習の重みは使わない**
- **学習**: 384×384(1/4 尺)の切り出し、バッチ 8、**8,000 歩**、AdamW lr 1e-3・余弦減衰・
  重み減衰 1e-4、fp16。増強は**左右反転だけ**(上下は絵の向きを壊すので入れない)。
  切り出しの位置はコマ成分の外接矩形の中で一様
- **選ばない**: **最後の歩の重みを使う。** 試験頁で歩数・閾値・種を選ばない。
  学習側から 2 頁を監視用に分けて損失を印字するが、**何も選ばない**
- **推論**: 頁全体を一度に通す(32 の倍数に詰める)→ 確率を原寸へ双線形で戻す → **閾 0.5** → `∩ P`
- **組(fold)**: **ako7 で学習 → ako6 で試験** / **ako6 で学習 → ako7 で試験**。
  学習に使うのは**相手の作品の現行の素の頁だけ**(`done*` は面プールと同じ規則で外す)。
  **作品の中で頁を分けない** —— 頁の複写から次の頁を描き始めた例(L24)があり、
  作品の中の頁は互いに素である保証が無い
- **種**: **3 つ**(20261108 / 20261109 / 20261110)。**組 × 種 = 6 本**。
  所要時間で減らさない

## §3 主値と照合

- **照合**: コマ成分ごとに、予測の8連結成分(**面積 >= 6,000**)と、そのコマの面プールの面を
  **IoU >= 0.5 で貪欲に1対1**(J の `region_metrics.match` と同じ規則。**面プールの面は重なりうる**
  ので、標準の側はラベル画像ではなく面ごとのマスクで持つ)
- **主値 = 面の再現率** `R` = 当たった面 / 試験側の面の数。**作品ごとに1行。畳まない**
- 併記: **精度** `Pn` = 当たった予測 / 予測の数(**面の無いコマも母集団に入れる** —— 面の無いコマの
  予測は全部外れ。面の在るコマだけの精度も別の行で印字)
- **得** `G = R(腕M) − max(R(腕0), R(腕1), R(腕C))`。**コマを単位にブートストラップ 1,000 回**
  (種 20261108)で 95% 区間
- 併記(棒なし): IoU の閾 {0.25, 0.5, 0.75} の感度表 / 画素の micro IoU(**腕1 の micro IoU は
  面積比そのもの**)/ 面の大きさ別(コマの <5% / 5〜25% / 25〜75% / >=75%)/
  小片側の予測成分の数 / 割った片と元のままを分けた再現率

## §4 器具の点検(IC。**工程の外の値だけを使う。どれか外れたら走らない / 読まない**)

- **IC1 面の復元** —— 面プールを器具で作り直し、**656 面・kept 551 / piece 105、鍵と面積が JSON と全行一致**
- **IC2 照合器** —— 面プールの各面のマスクを、そのまま予測として渡す → **R = 1.000、Pn = 1.000**
- **IC3 層の交差** —— 入力の層と標的の層の交差 **0**
- **IC4 平行移動の器具** —— 天井(標準そのもの)を NC1 と同じ量だけずらす → **R が天井の 0.2 倍以下**
  (ずらしが本当に位置を壊しているか)

## §5 負の対照(NC。誤りの名前と、いま書く期待値)

- **NC1 予測の平行移動**(量を採点していないか。扉6 の誤り) —— 腕M の予測を、コマ成分の中で
  **幅の 1/3・高さの 1/3** だけ巡回させてから照合する。**期待: R が腕1 の R + 0.05 以下**
- **NC2 入力の漏れ** —— **面の画素のうち入力の墨である割合**を作品ごとに印字する。
  高ければ腕C が上がる(腕C が得 `G` の基準に入っているので、漏れは得から差し引かれる)
- **NC3 作品を跨ぐ共有頁** —— L24 の `ako6 done4/ako6-18 ↔ ako7 page0073` は `done*` なので
  学習に入らない。**学習頁と試験頁の層 PNG のバイト一致の数を印字する**(0 のはず)
- **NC4 試験頁が学習に入る** —— 学習頁の集合と試験頁の集合の交差 **0** を印字する

## §6 棒(C。**どの結末が何を意味するか**。各組・各種で読み、作品ごとに書く)

- **C1 取り出せる**: `R >= 0.50` かつ `Pn >= 0.50` かつ `G >= 0.20`
  → **線の層だけで作者の塗りの面が取り出せる**(その作品で)
- **C2 運ぶが届かない**: C1 でなく、`G >= 0.10` かつ 95% 区間の下端 `> 0`
  → **線は塗りの面の情報を運ぶ。取り出せる水準ではない**
- **C3 この定式化では運ばない**: 95% 区間の上端 `< 0.10`
  → 見出しは **「この定式化ではどの腕も面を取り出さない」**(腕1 / 腕C の点を同じ文に置く。条例2)。
  **「線に情報が無い」とは書かない**(この規模・この網・この解像度の話である)
- **上のどれでもない** → **判定保留**。区間を 0.10 の片側に寄せるのに要るコマの数を印字する
- **C4 NC1 が落ちた**(平行移動した予測の R > 腕1 の R + 0.05) → その組は**何も読まない**(量を採点している)
- **C5 IC が1つでも外れた** → **何も読まない**
- **C6 種が割れた** → 組ごとに3種の判定を全部印字し、**3種が同じ判定のときだけ見出しにする**。
  割れたら見出しは**判定保留**

**2つの作品で判定が違ってよい。違ったら両方書く**(世代もプールである)。

## §8 第2の棒(人の判定。**この走行の後。出す前にユーザーに伺う**)

**本当の棒は人の判定である**(第1条)。機械の棒を読んだ後、**各作品 6 コマ**(試験コマから
種 20261108 で一様に。**点を見て選ばない**)の原寸の切り出し(線の層 / 予測の塗り)を作者に出し、
**「この塗りは、この線画に作者が塗る面として読めますか(読める / 一部 / 読めない)」** と聞く。
**「読める」が 6/12 以上** → **人の棒も立つ**。
**作者の実際の塗りは並べない**(並べると問いが「合っているか」に変わる。それは機械の棒が測った)。

## §9 この走行が決められないこと

- **何を学んだか**(意味か、線の密度か)。点が出ても**機序は言えない**
- **作品の中の汎化**(作品の中で頁を分けないので、同じ作品の別の頁での点は測らない)
- **小片の側**(面の床の下は採点しない。数だけ印字する)
- **重ね塗りの疑い 4 面**と **(b) 読みとしての分割**。標準の作り方は変えない
- **網や解像度を変えたらどうなるか**。**変えて走り直すなら新しい登録**(棒を後から動かさない)
