## Question

**`ako` 系の中で、編の違う対(FANBOX編の `ako5` 対 学祭編の `ako7`〜`ako10`)は、
編が同じ対(学祭編どうし)より離れるのか。そして、どちらも外部(SD 2モデル)との対と比べてどうか。**

**「離れない」が答えになりうる** —— そのときは**編は軸の上では見えない**ことになる。
**さらに、`ako` どうしの最大が `ako` 対外部の最小を超えたら、「作者の中の差が、作者と外部の差を
上回る対が在る」**という、第1版以来の読みを覆す形になる。**それも先に書いておく。**

## **先に書く: この対では編と工程と時期と抽出経路が一緒に動く**

**`ako5ver2koma`** は **FANBOX編 / 2025 / アナログ作画が主体(作者の裁定)/ `line_combined_koma_20260729` 由来**。
**`ako7`〜`ako10`** は **学祭編 / 2018〜2022b / デジタル(作者の裁定)/ `line_clip_pairs_v3_koma_20260826` 由来**。
**4つが束になっているので、差が出ても「編の差」と名指しできない。** **この走行は距離を測るだけである。**

## Primary value

**対ごとに2つ**(**タイル1枚**を単位、**tie は 0.5**):

- **単軸**: **12軸それぞれの `|AUC − 0.5|`**、その対にわたる**中央値と最大値**
- **多変量**: **F9(9軸)のロジスティック回帰、群分割5折の平均 test AUC**
  (器具・`C` の格子・標準化・分割は `doc/prereg_multivariate_transfer_20261031.md` のまま)

**向き**: 単軸は `|AUC − 0.5|`(対称)。多変量は**表の上の行を 1、下を 0**(外部との対は **`ako` 側を 1**)。
**畳まないもの**: 行・対・軸・外部の2モデル。**畳むもの**: タイル。
**帯**: 群単位の bootstrap 1,000回(多変量の対のうち、**群が 15 未満の行を含む対は帯を必ず添える**)。

## 帰無値(**棒の前に出す**)

1. **`null_shuffle`** —— 対ごとに**群単位でラベルを置換**。**単軸 1,000回 / 多変量 50回**。
   **中央値 0.5。95% 帯が ±0.15 を超えた対は「帯が足りない」と印字して判定しない**
2. **既知のものさし**(**今日の走行。動かさない**): **A1 の作品間 最大 `|d|` 0.2783** /
   **A2 の行間 最大 `|d|` 0.4832、多変量の中央 0.8947・最大 0.9972**

## Pass criteria(**走る前に固定**)

**`M(編またぎ)`** = 1 の5対の多変量 AUC の中央値。**`M(編同じ)`** = 2 の10対の中央値(既知 0.8947)。

| | 条件 | **書く文** |
|---|---|---|
| **C-A 編が見える** | **`M(編またぎ) − M(編同じ) ≥ 0.05`** | **「編(と、それに乗っている工程・時期・抽出)をまたぐ対は、同じ編の中の作品差より離れる」** |
| **C-B 編は埋もれる** | **`≤ 0.02`** | **「編の違いは、同じ編の中の作品差に埋もれる。軸の上では編は見えない」** |
| **C-C 判定保留** | 0.02〜0.05 / 帯が足りない対 | **「判定保留」と書き、数を添える** |
| **C-D 作者の中が外部との差を超える** | **`ako` どうしの対の最大 AUC > `ako` 対外部の対の最小 AUC** | **「作者の中の2行の方が、作者と外部より離れる対が在る」—— 名指しして両方の数を書く** |
| **C-E 超えない** | 上が成り立たない | **「作者と外部の差は、`ako` の中のどの対よりも大きい」** |

**`0.05` と `0.02` の出所を先に書く**: 本日のものさしで、**学祭編どうしの10対は 0.5563〜0.9972 に散る**
(中央 0.8947)。**その散らばりの中で「編の差」と呼べるのは、中央値を少なくとも 0.05 押し上げる場合**とした。
**0.02 は、同じ器具を2回回したときの折の取り方による揺れの目安**(本日 NC4 で、折を群からタイルに変えた
ときの対ごとの差の中央が **+0.0008**、最大 +0.0730 だった)。
